# 旧代码边界说明

生成时间：2026-07-23

## 结论

- 旧 `backend` 和 `frontend` 目录继续作为阶段0基线和迁移对照。
- 阶段1新工程不得直接导入旧 `backend/server.js`、旧浏览器全局变量或旧SQLite数据库。
- 旧代码只接受基线测试修复，不接受新架构、新功能和大范围格式化。
- 真实业务迁移必须进入 `apps` 和 `packages` 的目标模块，并补齐测试。

## 当前状态

| 目录        | 阶段1处理方式          |
| ----------- | ---------------------- |
| backend     | 保持现状，不改业务逻辑 |
| frontend    | 保持现状，不迁移页面   |
| apps/api    | 新接口骨架             |
| apps/worker | 新任务骨架             |
| apps/web    | 新前端骨架             |
| packages    | 新共享能力和契约       |
