## 六、不纳入本合集的范围

- `docs/legacy`：仅用于历史边界说明，不作为 V3 日常维护入口。
- `docs/stage-records`：阶段过程记录、演练报告和交付说明默认保留在原目录，按需追溯，不作为一线操作手册。
- `deliverables/*`：热修复包、补丁包和发布包资料保留在交付包目录，按具体版本追溯。
- 根目录历史 V2 静态入口、旧后端、旧脚本和旧升级包：不再作为 V3 新需求和维护入口。

## 七、维护规则

1. 新增 V3 维护、迁移、备份或使用文档后，必须同步补充到本索引。
2. 文档优先链接 V3 主线目录：`apps/web`、`apps/api`、`apps/worker`、`packages/*`、`deploy/single-server`。
3. 涉及登录入口、角色落点、移动端落点和认证响应的说明，必须与 `apps/web/src/router/entry-target.ts`、`apps/web/src/api/auth-client.ts` 保持一致。
4. 涉及业务扩展的说明，必须与 [V3 业务平台底座与业务扩展实施交付方案](../V3业务平台底座与业务扩展实施交付方案.md) 保持一致。
