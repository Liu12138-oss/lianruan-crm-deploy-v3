## 八、维护规则

1. 新增资料时，先判断是否属于 V3 正式文档或 V3 兼容资料；不满足则不要加入本合集。
2. 含 V2 字样的资料只有在服务 V3 迁移、兼容接口或兼容测试时才能加入。
3. 调整登录入口、角色落点、移动端落点或认证响应时，必须同步核对 `apps/web/src/router/entry-target.ts` 和 `apps/web/src/api/auth-client.ts`。
4. 调整迁移规则时，必须同步核对 `database/mapping`、`scripts/migration`、`apps/api/src/v2-compat-routes.ts` 和 `apps/api/tests/v2-compat.test.ts`。
