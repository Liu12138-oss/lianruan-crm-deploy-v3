# 产品价格比例功能测试指南

## 功能概述

**实现目标**：超级管理员可为产品设置价格比例（0%-200%），一级和二级渠道商提报价时自动匹配对应价格。

**核心价值**：
- 简化价格管理：无需手动设置每个价格阶梯
- 提高准确性：自动计算避免人为错误
- 灵活调整：一键修改价格比例

## 已完成功能

### ✅ 后端功能

#### 1. 数据模型扩展

**新增字段**：
```javascript
{
  "priceRatioPrimary": 1.0,     // 一级渠道商价格比例（1.0 = 100%）
  "priceRatioSecondary": 1.1,   // 二级渠道商价格比例（1.1 = 110%）
  "priceRatioUpdatedAt": "2026-04-16T10:00:00Z"
}
```

**自动计算字段**：
- `priceForPrimary`：一级渠道商价格（基础价格 × priceRatioPrimary）
- `priceForSecondary`：二级渠道商价格（基础价格 × priceRatioSecondary）

#### 2. API接口增强

**PUT /api/features/:id**（更新产品）

新增支持：
- 接收价格比例参数（priceRatioPrimary, priceRatioSecondary）
- 自动计算渠道商价格
- 比例范围限制（0-2，即0%-200%）
- 价格四舍五入到整数

**请求示例**：
```json
{
  "priceRatioPrimary": 1.0,
  "priceRatioSecondary": 1.1
}
```

**响应示例**：
```json
{
  "success": true,
  "data": {
    "id": "FEAT-001",
    "name": "桌面管理模块",
    "priceRatioPrimary": 1.0,
    "priceRatioSecondary": 1.1,
    "priceForPrimary": [
      { "min": 10, "max": 19, "price": 150 }
    ],
    "priceForSecondary": [
      { "min": 10, "max": 19, "price": 165 }
    ]
  }
}
```

## 常见问题

### Q1：价格比例设置后，旧报价单会更新吗？

**答**：不会。已创建的报价单价格已锁定，仅新报价单使用新价格。

### Q2：价格计算支持小数吗？

**答**：比例支持小数（如95.5%），但最终价格四舍五入到整数。

### Q3：二级渠道商价格必须高于一级吗？

**答**：不强制。但通常二级价格应 ≥ 一级价格，建议设置≥100%。

### Q4：硬件产品支持价格比例吗？

**答**：支持。硬件产品的固定价格同样适用价格比例计算。

### Q5：价格比例可以按产品单独设置吗？

**答**：是的，每个产品可以单独设置价格比例。

### Q6：套餐产品如何处理？

**答**：套餐价格独立设置，不受功能模块价格比例影响。
