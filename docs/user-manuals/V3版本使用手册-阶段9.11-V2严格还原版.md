# V3版本使用手册：阶段9.11 V2严格还原版

文档日期：2026-07-28  
适用系统：联软CRM V3  
适用对象：联软总部管理员、区域管理员、渠道管理员、渠道员工、测试验收人员  
账号策略：V2旧密码不恢复，V3使用初始化密码

## 1. 登录入口

本地验收地址：

```text
http://127.0.0.1:5173/login
```

HexHub发布后地址：

```text
http://10.20.3.10/login
```

直接打开 `/login` 会先看到 V2 风格的两个入口：

1. 厂商管理入口：超级管理员、区域管理员使用。
2. 渠道合作伙伴入口：渠道管理员、渠道员工使用。

如果未登录时直接访问 `/admin`，系统会自动显示厂商管理登录卡。  
如果未登录时直接访问 `/partner`，系统会自动显示渠道合作伙伴登录卡。

阶段9.11补充批次已去掉登录卡上的非 V2 页签，只保留账号登录主体和入口切换链接。

## 3. 厂商管理端

入口：

```text
/admin/dashboard
```

主菜单按 V2 体感展示：

| 分组     | 页面                                                                         |
| -------- | ---------------------------------------------------------------------------- |
| 工作台   | 总览仪表盘                                                                   |
| 业务管理 | 商机管理、客户报备、报价管理、订单管理                                       |

阶段9.11已将“工作量配置、平台管理”从主侧栏收敛，避免和 V2 主菜单差异过大。相关路由和后续后台留口仍保留。

顶栏操作：

| 操作     | 说明                                                   |
| -------- | ------------------------------------------------------ |
| 通知     | 点击铃铛打开右侧通知中心，可查看通知并标记全部已读     |
| 帮助     | 保留 V2 顶栏位置                                       |

说明：修改密码弹窗当前完成 V2 视觉与表单校验，真实在线改密接口仍留口，正式改密暂按账号管理后台重置流程处理。

## 6. 客户报备到订单验收链路

推荐按以下顺序验收：

1. 选择厂商管理入口或渠道合作伙伴入口登录。
2. 进入客户报备列表，搜索并查看报备记录。
3. 新建客户报备，填写客户名称、统一社会信用代码、联系人、联系电话。
4. 在管理端审核报备通过。
5. 从已通过报备创建商机。
6. 创建报价单，选择商机、端点数和产品，并执行报价试算。
7. 在报价列表确认报价。
8. 将报价转为订单。
9. 在订单列表确认订单状态。

页面体感检查：

1. 桌面工作台应能看到快捷入口、近期商机、最近报价单、主力产品线、商机销售漏斗。
2. 产品目录应显示产品卡片，不再只是普通通用表格。
3. 报价详情应按软件产品、硬件设备、服务项分组展示明细。
4. 报备、商机、订单详情应包含 V2 时间线区块。

3. 导入任务历史。

## 9. 注意事项

1. 阶段9.11只做 V2 UI严格还原，不新增公海池等新功能。
2. V2源码只作为参照，不维护、不写入、不回改。
3. 如果要在 HexHub 验收，需要先发布阶段9.11版本到 HexHub「渠道CRM（新架构）」。
4. HexHub发布后应重新验收登录入口、管理端、渠道端、手机端和报备到订单主链路。
5. 未登录页对 `/api/auth/me` 的 401 是会话探测预期，不代表登录页异常。
