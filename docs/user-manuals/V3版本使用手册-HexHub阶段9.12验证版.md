## 3. 主业务链路

建议按以下顺序做人工验收：

1. 登录 `admin / LrCRM@2026!`。
2. 新建客户报备。
3. 管理端审核客户报备通过。
4. 创建或查看对应商机。
5. 新建报价并选择产品。
6. 审核报价。
7. 报价转订单。
8. 完成订单一级确认。

## 5. 注意事项

1. 当前测试环境使用 HTTP 和 IP 访问，正式上线前需要配置域名和 HTTPS。
2. 阶段9.12只做 V2 UI严格还原纠偏，不新增公海池等后续功能。
3. V2旧密码不迁移，正式用户需要初始化新密码。
4. OpenAPI旧密钥不迁移，正式对接前需要重新签发。
5. 当前为单机部署，未配置备用服务器时仍存在整机单点。
