# 联软CRM V3版本使用手册

文档版本：2.1  
适用系统版本：V3 `3.0.0-stage9.20260727`  
适用交付阶段：阶段9 V2业务体验完整迁入验收版  
生成日期：2026-07-27  
适用范围：联软总部及其渠道体系

## 1. 登录方式

生产或测试环境部署完成后，浏览器访问：

```text
http://服务器IP/login
```

默认验收账号：

| 项目 | 内容 |
| --- | --- |
| 用户名 | `admin` |
| 初始密码 | `LrCRM@2026!` |
| 默认入口 | `/unified` |

该账号用于交付验收。正式上线前需要补齐正式账号、角色、密码策略和首次改密流程。V2原密码不迁移，所有正式用户应初始化新密码。

| 入口 | 地址 | 主要用途 |
| --- | --- | --- |

## 6. 首要验收链路

阶段9第一优先级验收链路如下：

1. 登录 `/login`。
2. 进入 `/admin/registration/new` 新建客户报备。
3. 回到 `/admin/registration`，对待审核报备点击“通过”。
4. 进入 `/admin/opportunity/new`，选择已通过报备，新建商机。
5. 进入 `/admin/quote/new`，选择商机、产品和端点数，点击“试算”，确认金额和工作量后提交。
6. 回到 `/admin/quote`，点击“确认”或“转订单”。
7. 进入 `/admin/order`，对订单点击“确认”。
8. 回到 `/unified` 或 `/admin/dashboard`，确认统计、待办和最近业务有变化。

## 8. 运维常用命令

生产安装目录默认为 `/opt/lianruan-crm-v3`。

```bash
sudo /opt/lianruan-crm-v3/scripts/health-check.sh
sudo /opt/lianruan-crm-v3/scripts/start.sh
sudo /opt/lianruan-crm-v3/scripts/stop.sh
sudo /opt/lianruan-crm-v3/scripts/backup.sh --type manual
sudo /opt/lianruan-crm-v3/scripts/collect-diagnostics.sh
```

健康检查接口：

```bash
curl -i http://127.0.0.1/health/live
curl -i http://127.0.0.1/health/ready
curl -i http://127.0.0.1/health/dependencies
```

## 9. 当前边界

- 公海池和其他新增功能不在阶段9范围。
- 阶段9按V2已有业务能力迁入，PC菜单、字段和流程尽量保持V2体感。
- OpenAPI旧密钥不能恢复，正式使用前需要重新签发。
- V2用户密码不能恢复，正式用户需要初始化密码。
- 当前无域名和证书，测试和预生产先使用HTTP加服务器IP；正式上线前必须补HTTPS。
- 单机部署已具备容器级高可用和备份留口，但没有备用服务器时不能消除整机单点。
