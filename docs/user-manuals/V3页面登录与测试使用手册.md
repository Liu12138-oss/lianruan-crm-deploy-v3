## 2. 登录步骤

1. 打开浏览器访问 `http://10.20.3.10/login`。
2. 在“用户名”输入 `admin`。
3. 在“密码”输入 `LrCRM@2026!`。
4. 点击“登录”。
5. 登录成功后进入统一入口 `/unified`。

如果用户名或密码错误，页面会提示“用户名或密码不正确。”。

## 4. 刷新与退出测试

刷新测试：

1. 登录后进入 `/mobile` 或 `/unified`。
2. 按浏览器刷新。
3. 页面应保持登录状态，不应跳回登录页。

退出测试：

1. 点击页面上的“退出”按钮。
2. 页面应回到 `/login`。
3. 再访问 `/admin`、`/partner`、`/mobile` 时，应跳转到登录页。

## 5. 第一优先级业务验收

请按以下顺序验证主链路：

1. 进入 `/admin/registration/new`，新建客户报备。
2. 回到 `/admin/registration`，对待审核报备点击“通过”。
3. 进入 `/admin/opportunity/new`，选择已通过报备，新建商机。
4. 进入 `/admin/quote/new`，选择商机、产品和端点数，点击“试算”，确认金额和工作量后提交。
5. 回到 `/admin/quote`，确认报价或转订单。
6. 进入 `/admin/order`，确认订单。
7. 回到 `/unified` 或 `/admin/dashboard`，确认统计、待办和最近业务有变化。
