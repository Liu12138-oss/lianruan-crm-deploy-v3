## 4. 客户报备

列表地址：

```text
/admin/registration
```

常用操作：

1. 在搜索框输入客户、渠道、负责人或编号。
2. 选择状态，例如待审核、已通过、已驳回。
3. 点击“查询”刷新列表。
4. 点击“新增客户报备”进入新建页。
5. 点击“导出”导出当前列表 CSV。
6. 点击“批量导入”进入导入页。
7. 点击表格行或“详情”打开详情弹窗。
8. 对待审核记录可点击“通过”或“驳回”。

新建地址：

```text
/admin/registration/new
```

需要填写：

| 字段             | 说明               |
| ---------------- | ------------------ |
| 客户名称         | 必填，客户主体名称 |
| 统一社会信用代码 | 用于客户主体识别   |
| 联系人           | 客户联系人         |
| 联系电话         | 客户联系电话       |

## 5. 渠道商管理

地址：

```text
/admin/partners
```

筛选项：

| 筛选     | 说明                             |
| -------- | -------------------------------- |
| 搜索框   | 搜索渠道商名称、联系人、城市     |
| 全部级别 | 支持 LEP、钻石、金牌、银牌、铜牌 |
| 全部区域 | 支持按区域筛选                   |
| 全部状态 | 支持启用、停用                   |

表格重点字段：

1. 渠道商名称。
2. 渠道级别。
3. 区域和城市。
4. 联系人和电话。
5. 销售人数。
6. 报价和订单数量。
7. 累计金额。
8. 状态。

## 6. 商机、报价、订单

商机列表：

```text
/admin/opportunity
```

商机新建：

```text
/admin/opportunity/new
```

报价列表：

```text
/admin/quote
```

报价新建：

```text
/admin/quote/new
```

订单列表：

```text
/admin/order
```

推荐验收链路：

1. 新建客户报备。
2. 在客户报备列表审核通过。
3. 进入商机新建页，选择已通过报备，填写商机名称和预计金额。
4. 进入报价新建页，选择商机、端点数、产品，点击“试算报价”。
5. 确认报价后回到报价列表，点击确认或转订单。
6. 进入订单列表，确认订单状态。

## 7. 导入导出

当前已支持：

| 功能       | 说明                                      |
| ---------- | ----------------------------------------- |
| 列表导出   | 在列表页点击“导出”，下载当前页 CSV        |
| 下载模板   | 在导入页点击“下载模板”，生成 CSV 表头模板 |
| 上传并预检 | 上传 CSV 或 Excel 文件，识别行数和字段数  |

导入页示例：

```text
/admin/registration/import
/admin/opportunity/import
/admin/partners/import
```

注意：阶段9.10已完成模板下载和文件预检体感；正式入库、错误行下载、任务队列执行将在后续阶段接入。
