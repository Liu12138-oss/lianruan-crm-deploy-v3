## 6. 主业务验收流程

推荐按下面顺序测试：

1. 使用 `wangning` 登录渠道端。
2. 进入“客户报备”，创建一条客户报备。
3. 使用 `admin` 或 `liulonghai` 登录管理端。
4. 进入“审核中心”，查看并处理客户报备。
5. 进入“商机管理”，确认报备可继续形成商机。
6. 进入“报价管理”或“新建报价”，选择产品并查看工作量试算。
7. 审核报价。
8. 报价转订单。
9. 在“订单管理”确认订单状态。

## 9. 注意事项

1. 当前测试环境使用HTTP和服务器IP，正式上线前需要配置域名和HTTPS。
2. 统一初始化密码只用于迁移和验收，正式使用前应安排用户改密。
3. OpenAPI旧密钥不恢复，需要在V3中重新签发。
4. 管理员可看全量数据，渠道用户只看权限范围内数据。
5. 本版本只做V2已有功能等价迁移，不包含公海池等新增功能。
