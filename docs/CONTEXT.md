# 联软渠道管理平台 V3 业务上下文

本文件用于统一商机、客户报备、报价与订单相关改造中的业务术语，避免同一概念在页面文案、接口和测试中使用不同名称。

## 语言（术语）

**客户报备**：
渠道或内部人员提交客户归属与保护申请的业务记录。
_避免_：客户线索、报备单

**商机**：
基于已通过客户报备建立、可持续推进阶段并关联报价和订单的销售机会。
_避免_：销售线索、项目机会

**商机跟进**：
围绕具体商机记录沟通方式、沟通内容、下一步计划和下次跟进时间的业务动作。
_避免_：客户跟进、沟通日志

**商机阶段**：
商机从客户建联到成单或终止的状态，包含七阶段主进度及输单、项目取消等终止结果。
_避免_：销售状态、后端阶段码

**产品商机**：
以新产品销售为目标、可创建产品报价和产品订单的商机。
_避免_：普通商机、主商机

**维保商机**：
以既有产品订单的续保、维保服务为目标、必须关联至少一个有效产品订单的商机。
_避免_：售后商机、续费线索

**产品订单**：
由产品商机下的产品报价转成，包含产品、硬件或产品实施服务的订单。
_避免_：新增订单、销售订单

**维保订单**：
由维保商机下的维保报价转成，必须关联至少一个产品订单，且不得混入新产品或新硬件。
_避免_：售后订单、服务续费单

**持续运营**：
客户全生命周期的固定第七阶段，表示客户已进入长期经营；在保或断保状态作为运营状态另行展示。
_避免_：质保阶段、第七阶段

**报价单**：
基于商机、产品模块、硬件和服务生成的正式商务价格记录。
_避免_：价格表、成本单

**标准产品报价**：
内部管理员和渠道用户均可创建的报价类型；不展示报价价格，订单最终成交价由区管在订单审批时补充。
_避免_：普通报价、免价单

**渠道分销产品报价**：
按区域覆盖价和渠道分销层级价格规则自动取价的报价类型。
_避免_：渠道价格单、分销底价

**区管补价**：
标准产品报价转为订单后，由区管在区管审批节点填写最终订单价格的业务动作。
_避免_：订单改价、手工定价

**合同附件**：
报价转订单时上传的合同或相关证明材料，支持图片、PDF、Word 和 Excel，由服务端受控存储与下载。
_避免_：报价附件、普通文件

**出货金额**：
渠道向最终客户出货的成交金额，也是订单价格对比中的出货价格。
_避免_：订单金额、报价金额

**渠道利润**：
出货金额减去渠道订单价格后的差额，仅向内部管理员和区管展示。
_避免_：项目利润、内部收益

**渠道订单目标金额**：
按自然年人工维护的渠道订单目标，实际完成金额仍由系统按订单自动统计。
_避免_：订单考核额、人工订单额

**报价免审批直接转单**：
新 UI 不再设置报价审批环节；标准产品报价金额为 0，草稿或历史状态报价可直接转订单，最终订单价格由区管在订单审批节点补充；渠道分销产品报价仍由服务端自动取价。
_避免_：报价待审核、报价待确认、先审批再转单

**一级导航**：
顶部业务导航中的业务全景、工作台、客户、线索、商机、订单、审核、产品、消息、渠道和配置等入口。
_避免_：主菜单、侧栏菜单
