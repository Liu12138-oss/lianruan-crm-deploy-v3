# 产品价格比例功能设计方案

## 需求概述

超级管理员在产品目录中设置价格比例，一级渠道商和二级渠道商在提报价时自动匹配对应价格。

**核心要求**：
1. 超管可设置价格比例（0%-100%）
2. 基于基础价格自动计算一级和二级渠道商价格
3. 不影响其他功能

## 现有数据分析

### 现有数据模型

产品（Feature）数据结构：
```javascript
{
  "id": "FEAT-MOD-LEP-01-01",
  "name": "桌面管理模块",
  "priceType": "tiered",  // 阶梯价格
  "tiers": [  // 基础价格阶梯
    { "min": 10, "max": 19, "price": 150 },
    { "min": 20, "max": 49, "price": 140 }
  ],
  "priceForPrimary": [  // 一级渠道商价格阶梯
    { "min": 10, "max": 19, "price": 150 },
    { "min": 20, "max": 49, "price": 140 }
  ],
  "priceForSecondary": [  // 二级渠道商价格阶梯
    { "min": 10, "max": 19, "price": 165 },
    { "min": 20, "max": 49, "price": 154 }
  ]
}
```

**现状问题**：
- 需要手动为每个价格阶梯设置一级和二级渠道商价格
- 价格调整时需要逐个修改，容易出错

## 新设计方案

### 1. 数据模型调整

#### 新增字段

在产品（Feature）中添加：
```javascript
{
  "priceRatioPrimary": 1.0,     // 一级渠道商价格比例（1.0 = 100%）
  "priceRatioSecondary": 1.1,   // 二级渠道商价格比例（1.1 = 110%）
  "priceRatioUpdatedAt": "2026-04-16T10:00:00Z"
}
```

#### 保留字段

- `priceForPrimary` 和 `priceForSecondary` 保留，但改为自动计算
- 计算公式：
  - `priceForPrimary` = `tiers` * `priceRatioPrimary`
  - `priceForSecondary` = `tiers` * `priceRatioSecondary`

### 2. 价格计算规则

#### 阶梯价格产品（priceType: "tiered"）

```
基础价格：10-19端点 → ¥150
一级比例：100%
二级比例：110%

一级价格：10-19端点 → ¥150 * 1.0 = ¥150
二级价格：10-19端点 → ¥150 * 1.1 = ¥165
```

#### 固定价格产品（priceType: "fixed"）

```
基础价格：¥10000
一级比例：100%
二级比例：110%

一级价格：¥10000 * 1.0 = ¥10000
二级价格：¥10000 * 1.1 = ¥11000
```

#### 价格四舍五入规则

- 计算结果保留整数（四舍五入）
- 示例：¥150 * 1.1 = ¥165, ¥140 * 1.1 = ¥154

### 3. 前端界面设计

#### 功能管理界面新增

在产品编辑表单中添加：

```
┌─────────────────────────────────────────┐
│ 价格设置                                 │
├─────────────────────────────────────────┤
│ 基础价格：                               │
│  [阶梯价格设置区域]                       │
│                                          │
│ 渠道商价格比例：                          │
│  ├─ 一级渠道商： [100] %                  │
│  │   提示：价格 = 基础价格 × 比例         │
│  │                                       │
│  └─ 二级渠道商： [110] %                  │
│      提示：价格 = 基础价格 × 比例         │
│                                          │
│ 预览：                                   │
│  ├─ 一级渠道商价格：¥150 - ¥90           │
│  └─ 二级渠道商价格：¥165 - ¥99           │
└─────────────────────────────────────────┘
```

#### 输入限制

- 比例范围：0% - 200%
- 最小单位：1%
- 默认值：
  - 一级渠道商：100%
  - 二级渠道商：110%（在一级基础上上浮10%）

### 4. 后端API调整

#### 修改现有接口

**PUT /api/features/:id**（更新产品）

请求参数：
```json
{
  "name": "桌面管理模块",
  "priceRatioPrimary": 1.0,
  "priceRatioSecondary": 1.1
}
```

后端逻辑：
1. 接收价格比例参数
2. 基于基础价格自动计算一级和二级渠道商价格
3. 更新 `priceForPrimary` 和 `priceForSecondary`
4. 保存价格比例设置时间

#### 新增辅助接口

**POST /api/features/:id/calculate-prices**（价格预览）

请求参数：
```json
{
  "priceRatioPrimary": 1.0,
  "priceRatioSecondary": 1.1
}
```

响应：
```json
{
  "success": true,
  "data": {
    "priceForPrimary": [
      { "min": 10, "max": 19, "price": 150 }
    ],
    "priceForSecondary": [
      { "min": 10, "max": 19, "price": 165 }
    ]
  }
}
```

### 5. 报价逻辑调整

#### 报价创建时价格选择

渠道商提报价时：
1. 获取渠道商等级（primary/secondary/none）
2. 选择对应价格：
   - 一级渠道商：使用 `priceForPrimary`
   - 二级渠道商：使用 `priceForSecondary`
   - 无等级：使用基础价格 `tiers`

#### 向后兼容

- 旧数据没有价格比例字段：默认为1.0（100%）
- 旧数据已有 `priceForPrimary/Secondary`：保持不变，除非超管重新设置比例

### 6. 数据迁移方案

#### 迁移脚本

创建迁移脚本 `backend/migrate-price-ratio.js`：

```javascript
// 为所有产品添加默认价格比例
db.features.forEach(f => {
  if (!f.priceRatioPrimary) {
    f.priceRatioPrimary = 1.0;
    f.priceRatioSecondary = 1.1;
    f.priceRatioUpdatedAt = new Date().toISOString();
  }
});
```

#### 迁移时机

- 在系统启动时自动检测并迁移
- 不影响现有数据
