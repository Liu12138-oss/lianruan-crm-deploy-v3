## 常见问题排查

### 问题1：页面空白或无响应

**排查步骤**：
1. 按 F12 打开浏览器控制台
2. 查看 Console 标签页的错误信息
3. 查看 Network 标签页的请求状态

**常见原因**：
- partner-level-module.js 未加载：检查文件是否存在
- API 请求失败：检查后端服务是否运行

### 问题2：等级设置失败

**排查步骤**：
1. 打开浏览器开发者工具（F12）
2. 切换到 Network 标签页
3. 重新尝试设置等级
4. 找到失败的请求，查看响应内容

**常见原因**：
- 权限不足：确认使用的是管理员账号
- API 路径错误：确认请求路径为 `/api/partners/:id/level`

### 问题3：价格没有差异

**排查步骤**：
1. 检查产品数据是否包含分级价格字段
2. 检查渠道商等级是否正确设置

**验证命令**：
```bash
# 在服务器上检查数据
node -e "const data = require('./data.json'); console.log(data.features[0]);"
```
