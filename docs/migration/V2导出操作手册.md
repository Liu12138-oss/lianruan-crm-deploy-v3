
# V2导出操作手册草案

生成日期：2026-07-23

## 1. 操作原则

- 只读操作V2快照，不直接读取正在写入的生产库。
- 使用SQLite一致性备份能力包含WAL数据。
- 导出产物必须包含实体记录数、文件大小和SHA-256摘要。
- 导出文件不得包含本地密码明文和开放接口密钥明文。
- 缺少业务库、审计库或摘要不一致时立即停止。

## 2. 建议目录

```text
migration-runs/
  2026xxxx-正式演练-01/
    source/
      crm.db
      audit.db
    exported/
      entities-users.ndjson
      entities-partners.ndjson
      audit-logs.ndjson
      manifest.json
    reports/
      export-report.md
```

## 3. 导出步骤

1. 停止V2写入或从生产备份生成一致性副本。
2. 对 `crm.db` 和 `audit.db` 分别执行SQLite备份，确认WAL已合并。
3. 只读打开快照，按实体流式读取 `entities`。
4. 每行输出 `batchId`、`entityName`、`sourceId`、`sourceUpdatedAt`、`sourceSha256`、`redactedJson`。
5. 对 `users.password` 和 `openApiClients.secret` 等敏感字段做脱敏，不输出原值。
6. 生成 `manifest.json`，记录实体数量和摘要。

## 4. 本阶段限制

当前worktree没有SQLite样本库，本手册仅作为阶段2可执行设计。真实导出工具应在阶段1脚本规范确定后实现，并在授权快照上执行。
