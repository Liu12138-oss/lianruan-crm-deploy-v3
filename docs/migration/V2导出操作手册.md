# V2导出操作手册

更新日期：2026-07-27

## 1. 操作原则

- 只读操作 V2 快照，不直接读取正在写入的生产库。
- 使用包含 `crm.db`、`audit.db`、WAL 和 SHM 的一致性快照。
- 导出产物必须包含实体记录数、文件大小和 SHA256 摘要。
- 导出文件不得包含本地密码明文、开放接口密钥明文、令牌和授权值。
- 缺少业务库、审计库、完整性检查失败或数量不守恒时立即停止。

## 4. 执行命令

```bash
node scripts/migration/导出V2只读迁移批次.js \
  --crm-db "/Users/liu/Documents/Codex/lianruan-crm-deploy-v2.2.0 3/lianruan-crm-deploy-v2.2.0 2/backend/crm.db" \
  --audit-db "/Users/liu/Documents/Codex/lianruan-crm-deploy-v2.2.0 3/lianruan-crm-deploy-v2.2.0 2/backend/audit.db" \
  --output-dir "tmp/stage8/v2-export-official" \
  --label "正式V2源库只读导出-阶段8.2" \
  --batch-id "S8-RUN-20260727-001" \
  --page-size 500 \
  --record-doc "docs/stage-records/阶段8.2-V2只读导出报告.md"
```

参数说明：

| 参数           | 说明                                     |
| -------------- | ---------------------------------------- |
| `--crm-db`     | V2业务库快照路径                         |
| `--audit-db`   | V2审计库快照路径                         |
| `--output-dir` | 本次导出目录                             |
| `--label`      | 报告中的导出标签                         |
| `--batch-id`   | 本次演练批次编号                         |
| `--page-size`  | 分页读取数量，默认500，最大5000          |
| `--record-doc` | 把导出报告同步到交接文档目录             |
| `--force`      | 允许覆盖已有导出目录中的 `manifest.json` |

## 6. 脱敏规则

以下字段名命中后统一输出为 `[已脱敏]`：

```text
password、passwd、pwd、secret、token、apiKey、api_key、clientSecret、accessKey、authorization、密码、密钥、令牌
```

说明：

- 脱敏会递归处理对象和数组。
- 脱敏字段路径会记录到 `redactionPaths`。
- 导出文件保留源 JSON SHA256，不保留源 JSON 明文。
- 正式迁移时，用户密码应采用初始化密码加首次登录强制改密；开放接口密钥应重新签发。

## 8. 失败处理

| 失败类型         | 处理方式                         |
| ---------------- | -------------------------------- |
| 源库不存在       | 停止，重新确认快照路径           |
| 完整性检查失败   | 停止，重新生成一致性快照         |
| JSON解析失败     | 停止，回到 V2 源数据确认         |
| 数量不一致       | 停止，检查导出分页和源库是否漂移 |
| 发现敏感明文     | 停止，修正脱敏规则后重新导出     |
| 输出目录已有清单 | 默认停止，确认重跑后加 `--force` |

## 9. 阶段边界

本手册只覆盖阶段8.2只读导出。导出通过不等于迁移完成，后续还必须完成 PostgreSQL 暂存装载、数量守恒校验、业务映射校验、异常隔离和测试服务器迁移演练。
