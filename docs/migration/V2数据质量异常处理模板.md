
# V2数据质量异常处理模板

生成日期：2026-07-23

## 1. 阶段0异常结论

阶段0数据质量报告识别70项异常，全部为 `users` 实体的疑似明文密码。阶段2处理结论为：自动映射，不要求业务逐条补录，不允许明文进入中间文件和正式库。

## 2. 70项异常分类模板

| 异常类型 | 涉及数量 | 默认分类 | 处理规则 | 验收证据 |
| --- | ---: | --- | --- | --- |
| 疑似明文密码 | 70 | 自动映射 | 迁移装载时使用 `scrypt` 或阶段3最终确认算法生成密码散列；原始明文只在只读源快照读取时存在，不写入导出文件、日志、暂存表和正式表 | `iam.password_credentials.password_hash` 非空，`migration.v2_raw_records.redacted_json` 不含 `password` 明文 |

## 3. 后续异常分类表

| 分类 | 定义 | 允许进入正式表 | 示例 | 责任人 |
| --- | --- | --- | --- | --- |
| 自动映射 | 规则确定、可自动转换、无业务语义损失 | 是 | 明文密码转散列、空字符串转NULL | 数据负责人、后端负责人 |
| 业务补录 | 缺少必要业务字段，需要人工确认后补齐 | 补齐后允许 | 未知区域、缺少渠道归属 | 产品负责人、业务代表 |
| 隔离 | 不影响主链路迁移，但不能写入正式业务表 | 否，进入隔离清单 | 历史废弃实体、空样本保留项 | 产品负责人、数据负责人 |
| 阻断迁移 | 会破坏数量、金额、权限或关系一致性 | 否 | 金额重算不一致、重复订单、断裂必需外键 | 产品总负责人、架构负责人 |

## 4. 密码异常处理模板

| 字段 | 规则 |
| --- | --- |
| 源字段 | `users.password` |
| 目标字段 | `iam.password_credentials.password_hash` |
| 中间文件 | 不输出明文；导出时生成 `redacted_json`，把 `password` 替换为 `已脱敏` |
| 散列算法 | 阶段2草案使用 `scrypt`；阶段3认证底座可统一调整，但不能回退明文 |
| 失败处理 | 散列失败则该用户阻断迁移，记录到 `migration.migration_errors` |
| 验收SQL | 检查正式表不存在 `123456`、空散列和未标记算法 |

## 5. 产品需要签字的例外

当前70项无需逐条签字，但需要产品确认以下口径：

- V3上线后是否强制所有迁移账号首次登录改密。
- 应急管理员是否从V2超级管理员中迁移，还是重新初始化。
- 历史手机号用户名是否允许继续作为用户名。
