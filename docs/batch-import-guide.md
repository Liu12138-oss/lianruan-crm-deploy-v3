# 批量导入功能使用指南

## 功能概述

批量导入功能支持通过Excel文件批量导入以下数据：
- **渠道商**：批量创建或更新渠道商信息
- **员工**：批量创建或更新渠道商员工账号
- **客户报备**：批量创建或更新客户报备记录
- **商机**：批量创建或更新商机记录

### 核心特性

1. **UPSERT策略**：重复数据自动更新，不创建重复记录
2. **依赖验证**：自动检查数据依赖关系，缺失依赖的数据导入失败
3. **预览确认**：导入前会校验必填字段、权限范围和依赖关系，检查无误后再执行导入
4. **错误追踪**：详细记录每条失败数据的原因

### Step 3: 上传预览

1. 点击 **📤 上传Excel文件** 按钮
2. 选择填写好的Excel文件
3. 系统解析后显示预览数据；页面最多展示前 50 行，并显示整份文件的错误行数
4. 检查每行状态：
   - ✓ 正常：数据验证通过
   - 红色背景：错误信息，请根据提示修改

### Step 4: 执行导入

1. 确认预览数据无误后
2. 点击 **确认导入** 按钮
3. 系统执行导入，显示结果：
   - 新增：成功新增的记录数
   - 更新：成功更新的记录数
   - 失败：失败的记录数

## 数据依赖关系

### 员工导入
- 所属渠道商名称 → 必须已存在

### 客户报备导入
- 所属渠道商名称 → 必须已存在
- 负责员工姓名 → 必须在该渠道商下存在

### 商机导入
- 所属渠道商名称 → 必须已存在
- 负责员工姓名 → 必须在该渠道商下存在
- 客户名称 → 必须在已审批通过的客户报备中存在

## 常见问题

### Q: 导入时显示"渠道商不存在"
**A**: 请先导入渠道商，或确保渠道商名称完全一致（区分大小写）

### Q: 导入时显示"员工不存在"
**A**:
1. 确认员工已添加到对应渠道商下
2. 确认员工姓名填写正确

### Q: 商机导入失败"客户尚未报备"
**A**:
1. 必须先完成客户报备且审批通过
2. 报备的客户名称必须与商机中的客户名称完全一致

### Q: 重复导入会怎样？
**A**: 系统采用UPSERT策略：
- 渠道商：按名称查重，匹配到则更新
- 员工：按登录账号查重，匹配到则更新
- 客户报备：按客户名称查重，匹配到则更新
- 商机：按商机名称+客户名称查重，匹配到则更新

## 注意事项

1. **必填字段**：带 * 的字段必须填写
2. **数据顺序**：可以任意顺序导入，但需保证依赖关系存在；依赖缺失会在预览阶段提示
3. **编码格式**：Excel文件请使用UTF-8编码或GBK编码
4. **文件格式**：仅支持 .xlsx 和 .xls 格式
5. **文件大小**：单次导入文件大小限制10MB
6. **权限范围**：超管可导入全部数据；区管只能导入本区域渠道商、客户报备和商机；员工账号导入仅超管可操作
