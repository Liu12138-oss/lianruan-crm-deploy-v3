# 迁移验收用例与回退策略

生成时间：2026-07-23

## 1. 验收总则

- 每个页面必须先有阶段0旧页面基线，再做新页面对照。
- 每个批次必须同时验收接口契约、权限、浏览器、响应式、错误状态和回退。
- 旧页面保留到阶段8稳定期结束。
- 新旧页面切换必须通过路由开关，不允许临时改代码回退。

## 2. 通用验收矩阵

| 编号 | 场景 | 验收内容 | 通过标准 |
| --- | --- | --- | --- |
| FE-BASE-001 | 首次访问 | 访问深链页面 | 未登录进入会话流程，登录后按权限进入目标页 |
| FE-BASE-002 | 刷新 | 在列表、详情、表单、移动页刷新 | 会话从服务端恢复，不依赖本地伪造身份 |
| FE-BASE-003 | 无权限 | 修改路由地址访问未授权页面 | 显示无权限页，接口返回 403，不展示数据 |
| FE-BASE-004 | 数据不存在 | 访问不存在详情编号 | 显示数据不存在页，可返回列表 |
| FE-BASE-005 | 会话失效 | 服务端返回 401 | 清理敏感状态，进入会话失效页 |
| FE-BASE-006 | 冲突 | 编辑期间对象被他人修改 | 显示 409，保留用户输入，可刷新 |
| FE-BASE-007 | 网络错误 | 断网或服务不可用 | 显示中文可重试错误，不显示堆栈 |
| FE-BASE-008 | 维护中 | 后端返回维护状态 | 显示维护页，写操作关闭 |
| FE-BASE-009 | 响应式 | 1440×900、1280×720、390×844、360×800 | 无文字遮挡、溢出和不可点击区域 |
| FE-BASE-010 | 可观测 | 任一接口错误 | 页面展示请求编号，可关联后端日志 |

## 8. 每批回退策略

| 层级 | 回退方式 | 触发条件 | 验证 |
| --- | --- | --- | --- |
| 页面级 | 关闭该页面新路由开关，回到旧静态页面 | 单页面阻断缺陷、权限误判、响应式严重问题 | 旧页面可访问，新后端数据无分叉 |
| 工作空间级 | 关闭管理、渠道或移动工作空间新入口 | 布局、会话、导航类系统性缺陷 | 旧入口可访问，登录和退出正常 |
| 批次级 | 整批开关回退 | 多页面同类接口或权限缺陷 | 批次全部回到旧页面 |
| 生产级 | 回退到上一发布镜像 | 构建资源、会话、路由大面积异常 | 发布、回退、日志和监控记录完整 |

## 9. 回退规则

- 回退只切前端入口，不改数据库。
- 回退后新旧页面必须继续调用同一套后端服务。
- 回退不能跳过缺陷记录，必须登记页面、角色、接口、请求编号和影响范围。
- 一旦涉及金额、权限或数据范围错误，默认回退对应页面或批次。
- 页面迁移完成后不删除旧页面，直到阶段8稳定期结束。

## 10. 阶段5完成定义

| 项目 | 完成标准 |
| --- | --- |
| 页面覆盖 | 阶段0纳入范围页面全部迁移或有书面废弃批准 |
| 接口调用 | 新页面不直接拼接口地址，不传前端身份授权字段 |
| 权限 | 核心资源允许和拒绝用例通过 |
| 金额 | 报价和订单固定样本逐分一致 |
| 响应式 | 四类视口全部通过 |
| 错误页 | 401、403、404、409、500、维护中全部覆盖 |
| 可观测 | 错误请求可通过请求编号追踪 |
| 回退 | 页面级和批次级回退演练通过 |
