# 联软渠道管理平台 — 用户操作手册（渠道伙伴）

> 版本：v2.2.0 | 适用角色：渠道伙伴员工（staff）

---

## 一、登录系统

**访问地址：** `http://服务器IP:8080/login.html`

1. 打开浏览器，输入以上地址
2. 输入用户名和密码（初始密码：`123456`，请及时修改）
3. 点击**登录**按钮
4. 系统会自动识别设备类型：
   - 电脑端 → 跳转到 PC 版操作界面
   - 手机端 → 跳转到手机版界面

> **注意：** 渠道伙伴员工只能看到本公司的数据，无法查看其他渠道商信息。

---

## 二、主界面说明

登录后进入渠道伙伴主界面，左侧导航包括：

| 菜单 | 功能说明 |
|------|---------|
| 仪表盘 | 查看本公司的商机、报价、订单汇总数据 |
| 商机登记 | 登记新的销售商机 |
| 我的商机 | 查看和跟进已登记的商机 |
| 报价单 | 为客户创建报价单 |
| 订单管理 | 查看已成交的订单 |
| 个人设置 | 修改密码等个人信息 |

---

## 三、商机登记

商机登记用于提前锁定客户，避免同一客户被多个渠道商重复跟进。

### 操作步骤

1. 点击左侧菜单**「商机登记」**
2. 点击右上角**「新建商机」**按钮
3. 填写商机信息：

| 字段 | 说明 | 是否必填 |
|------|------|---------|
| 客户名称 | 最终客户的公司全称 | ✅ 必填 |
| 联系人 | 客户方对接人姓名 | ✅ 必填 |
| 联系电话 | 客户联系电话 | ✅ 必填 |
| 预计金额 | 本次商机预估合同金额（元） | 选填 |
| 预计签约日期 | 预计成交时间 | 选填 |
| 备注 | 项目背景、需求描述等 | 选填 |

4. 点击**「提交」**按钮
5. 系统提交后由区域管理员审批，审批通过后正式锁定商机

### 商机状态说明

| 状态 | 说明 |
|------|------|
| 待审批 | 已提交，等待管理员审核 |
| 已登记 | 审批通过，商机已锁定 |
| 已拒绝 | 管理员拒绝，可查看拒绝原因后修改重新提交 |
| 已转单 | 商机已转化为订单 |

---

## 四、创建报价单

报价单用于向客户提供正式的产品报价。

### 操作步骤

1. 点击左侧菜单**「报价单」**
2. 点击**「新建报价单」**
3. 填写基本信息：
   - 关联客户（可关联已登记的商机）
   - 报价有效期

4. **添加产品**：
   - 点击**「添加产品」**
   - 从产品目录中选择产品大类 → 产品模块 → 具体功能
   - 输入授权数量（端点数）
   - 系统自动按阶梯价格计算单价和小计

5. 所有产品添加完毕后，检查总价
6. 点击**「保存」**生成报价单
7. 可点击**「导出 PDF」**生成正式报价文件发给客户

### 产品价格说明

系统采用**阶梯定价**，购买数量越多，单价越低：

| 端点数量 | 价格级别 |
|---------|---------|
| 10–19 | 基础价 |
| 20–49 | 略有优惠 |
| 50–99 | 中等优惠 |
| 100–199 | 较大优惠 |
| 200–500 | 最优价格 |

> 具体价格以系统显示为准，最终成交价由管理员审批确认。

## 五、订单管理

### 查看订单

1. 点击左侧菜单**「订单管理」**
2. 可按状态筛选：进行中 / 已完成 / 已取消
3. 点击订单号可查看订单详情

### 订单流程

```
报价单 → 客户确认 → 提交成单申请 → 管理员审批 → 订单成立 → 执行交付
```

## 六、个人设置

### 修改密码

1. 点击右上角头像或用户名
2. 选择**「个人设置」**
3. 输入原密码
4. 输入新密码（建议8位以上，包含字母和数字）
5. 确认新密码
6. 点击**「保存」**

> ⚠️ **强烈建议首次登录后立即修改初始密码 `123456`！**

---

## 七、手机版使用

手机浏览器访问系统会自动跳转手机版，支持以下功能：

- 查看商机列表
- 新建/提交商机
- 查看报价单
- 查看订单状态

> 手机版功能略少于 PC 版，完整操作建议使用电脑。

## 八、常见问题

**Q：登录时提示"用户名或密码错误"？**  
A：确认用户名是否正确，初始密码为 `123456`。如仍无法登录，请联系管理员重置密码。

**Q：提交商机后长时间没有审批通知？**  
A：请联系您所在区域的管理员。

**Q：报价单产品价格如何确认？**  
A：系统显示的是官方价格体系，最终含折扣价格由管理员审批后确认。

**Q：能否查看其他渠道商的报价？**  
A：不能，系统按渠道商隔离数据，每个账号只能看到本公司数据。
