> 用途：给 AI-agent / crm-agent 联调用，记录测试账号视角和样例业务对象。  
> 安全说明：不填写 CRM 登录密码，不填写 OpenAPI `appSecret`。

## 3. 权限验证矩阵

| 验证项 | 超管 | 区管 | 渠道管理员 | 员工 |
|---|---|---|---|---|
| `/auth/me` | 应通过 | 应通过 | 应通过 | 应通过 |
| `/meta/permission-scope` | `all` | `region` | `partner` | `user` |
| `/diagnostics/self-check` | 全量资源 | 区域资源 | 渠道资源 | 本人相关 |
| `/analytics/business-overview` | 全量总览 | 区域总览 | 渠道总览 | 个人相关 |

## 4. 记录要求

1. 只记录 ID、展示名、状态、关联字段和统计数量。
2. 不记录密码、`appSecret`、`accessToken`。
3. 对外大模型使用 Markdown 时，手机号、邮箱、联系人、统一社会信用代码按约定脱敏。
