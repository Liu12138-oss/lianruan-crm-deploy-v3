## 常见问题

### Q1：价格比例修改后，旧报价单会更新吗？

**答**：不会。已创建的报价单价格已锁定，仅新报价单使用新价格。

### Q2：为什么一级价格和基础价格相同？

**答**：因为价格比例为100%，即基础价格 × 100% = 基础价格。您可以根据需要调整比例。

### Q3：如何调整价格比例？

**答**：超管登录 → 产品目录 → 功能管理 → 编辑产品 → 修改"渠道商价格比例" → 保存

### Q4：价格比例可以设置为多少？

**答**：支持0%-200%，即0到2倍基础价格。

### Q5：阶梯价格产品的价格比例如何计算？

**答**：每个阶梯的价格都会按比例计算。例如：
- 阶梯1：¥150 × 100% = ¥150
- 阶梯2：¥140 × 100% = ¥140
- 阶梯3：¥130 × 100% = ¥130
