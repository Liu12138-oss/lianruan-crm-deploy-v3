# 联软渠道管理平台 — 管理员操作手册

> 版本：v2.2.0 | 适用角色：超级管理员（superadmin）/ 区域管理员（admin）

---

## 一、角色权限说明

系统共三个角色，权限逐级递减：

| 角色 | 说明 | 权限范围 |
|------|------|---------|
| 超级管理员 | 联软科技总部管理员 | 全部数据、全部区域、系统设置 |
| 区域管理员 | 各区域负责人 | 仅限本区域的渠道商、商机、订单 |
| 渠道伙伴员工 | 渠道商的销售人员 | 仅限本渠道商的数据 |

---

## 二、登录系统

**访问地址：** `http://服务器IP:8080/login.html`

1. 输入管理员账号和密码
2. 系统自动跳转到管理后台（`admin.html`）

> ⚠️ **初始账号信息请联系系统部署人员获取，上线后请立即修改密码！**

## 四、渠道商管理

### 4.1 新增渠道商

1. 点击左侧**「渠道商管理」**
2. 点击**「新增渠道商」**
3. 填写渠道商信息：

| 字段 | 说明 | 必填 |
|------|------|------|
| 渠道商名称 | 公司全称 | ✅ |
| 渠道等级 | 银牌 / 金牌 / 钻石 | ✅ |
| 所属大区 | 大北区 / 大东区 / 大南区 等 | ✅ |
| 所属区域 | 更细分的区域 | ✅ |
| 联系人 | 渠道商主要联系人 | ✅ |
| 联系电话 | — | ✅ |
| 邮箱 | — | 选填 |
| 加入日期 | — | 选填 |

4. 点击**「保存」**

### 4.2 编辑渠道商

1. 在渠道商列表找到对应记录
2. 点击**「编辑」**按钮
3. 修改相关信息后点击**「保存」**

### 4.3 禁用/启用渠道商

- 点击对应渠道商的**「禁用」**按钮，该渠道商员工将无法登录
- 点击**「启用」**恢复正常

> ⚠️ 禁用渠道商不会删除其历史数据。

### 4.4 渠道商等级说明

| 等级 | 说明 |
|------|------|
| 银牌（silver） | 普通渠道伙伴 |
| 金牌（gold） | 核心渠道伙伴 |
| 钻石（diamond） | 顶级渠道伙伴，享受最优折扣 |

## 五、用户管理

### 5.1 新增员工账号

1. 点击**「用户管理」**
2. 点击**「新增用户」**
3. 填写信息：

| 字段 | 说明 |
|------|------|
| 用户名 | 登录账号，英文+数字，不可重复 |
| 姓名 | 真实姓名 |
| 角色 | staff（渠道员工） |
| 所属渠道商 | 选择关联的渠道商 |
| 初始密码 | 建议设置后告知用户并要求修改 |

4. 点击**「保存」**

### 5.2 重置密码

1. 找到对应用户
2. 点击**「重置密码」**
3. 输入新密码（告知用户）

### 5.3 禁用/删除账号

- **禁用**：用户无法登录，数据保留
- **删除**：彻底删除（不可恢复，谨慎操作）

## 六、商机审批

### 6.1 审批流程

```
渠道员工提交 → 区域管理员审批 → 通过/拒绝 → 员工收到结果
```

### 6.2 审批操作

1. 点击左侧**「商机审批」**或仪表盘上的「待审批」角标
2. 查看待审批商机列表
3. 点击商机名称查看详情：
   - 客户信息
   - 预计金额
   - 商机描述
4. 做出决定：
   - 点击**「通过」** → 商机正式锁定，同客户后续不接受其他渠道商重复提交
   - 点击**「拒绝」** → 填写拒绝原因，返回给渠道员工

### 6.3 重复商机处理

同一客户已有"已登记"状态的商机时，系统会提示重复。处理原则：
- 先提交者优先
- 如确有特殊情况，超级管理员可手动干预

## 七、报价管理

### 7.1 查看报价单

1. 点击**「报价管理」**
2. 可按渠道商、客户名称、时间筛选
3. 点击报价单查看详情（产品明细、金额、有效期等）

### 7.2 报价审批

报价单金额超过一定额度或折扣超出权限时，需管理员审批：
1. 在报价单详情页点击**「审批通过」**或**「审批拒绝」**
2. 拒绝时需填写原因

---

## 八、订单管理

### 8.1 订单审批

1. 点击**「订单管理」**→**「待审批」**
2. 查看订单详情（产品、金额、渠道商信息）
3. 点击**「确认成单」**或**「退回修改」**

### 8.2 订单状态流转

```
待审批 → 已确认 → 执行中 → 已完成
              ↓
           已取消
```

## 九、产品管理（仅超级管理员）

### 9.1 产品目录结构

系统采用三级产品架构：

```
产品大类（如：联软ESPP企业安全监测保护平台）
  └── 产品模块（如：桌面安全管理、防泄密、防勒索、准入控制）
        └── 功能模块（具体可售项目，含产品编码和价格）
```

### 9.2 添加新产品

1. 点击**「产品管理」**
2. 选择对应大类和模块
3. 点击**「新增功能模块」**
4. 填写：
   - 功能名称
   - 产品编码（如 `UA-AM-1`）
   - 计费单位（端点/套/年）
   - 定价类型：阶梯价 or 固定价
   - 各阶梯价格
   - 折扣系数（如 0.2 = 8折）
5. 保存后对渠道商端立即生效

### 9.3 修改价格

1. 找到对应功能模块
2. 点击**「编辑」**
3. 修改价格后点击**「保存」**

> ⚠️ 价格修改后立即生效，但**不影响已生成的报价单**。

### 9.4 下架产品

点击对应功能模块的**「下架」**，渠道商的报价单中将不再显示该产品。

## 十、系统设置（仅超级管理员）

### 10.1 大区和区域管理

可在系统设置中增加/修改大区和区域划分，新增区域后可为其分配区域管理员。

### 10.2 数据备份（重要！）

系统所有数据存储在 `backend/data.json` 文件中，**必须定期备份**！

**手动备份命令（Linux 服务器）：**
```bash
cp /opt/lianruan-crm-deploy-v2.2.0/backend/data.json \
   /opt/backup/data_$(date +%Y%m%d_%H%M%S).json
```

**建议配置每日自动备份（crontab）：**
```bash
# 编辑定时任务
crontab -e

# 添加以下内容（每天凌晨2点备份，保留30天）
0 2 * * * cp /opt/lianruan-crm-deploy-v2.2.0/backend/data.json /opt/backup/data_$(date +\%Y\%m\%d).json && find /opt/backup/ -name "data_*.json" -mtime +30 -delete
```

## 十二、常见问题

**Q：渠道员工反映无法登录？**  
A：检查账号状态是否"启用"，所属渠道商是否被禁用，密码是否正确。可在用户管理中重置密码。

**Q：如何导出所有渠道商数据？**  
A：当前版本暂无导出功能。可直接备份 `backend/data.json`，用文本编辑器或 Excel 处理 JSON 数据。

**Q：商机重复导致渠道商纠纷？**  
A：以系统登记时间为准，先提交且审批通过的渠道商享有该客户的独家权益，超级管理员可查看完整提交时间记录。

**Q：忘记超级管理员密码？**  
A：在服务器上直接编辑 `backend/data.json`，找到 `username: "admin"` 的记录，将 `password` 字段改为新密码，然后重启服务。

**Q：服务器重启后系统不能访问？**  
A：需要手动重新启动服务，建议配置 systemd 开机自启（联系技术支持）。
