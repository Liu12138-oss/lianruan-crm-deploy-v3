# 报价优惠价格修复验证指南

## 📋 问题诊断

### 用户反馈
报价单没有显示优惠价格，只显示了折后价格。

### 问题根因
1. **价格计算函数返回值错误**
   - `calcFeatureTotal` 函数返回数字（折后价格）
   - 但函数内部定义的是返回对象 `{ total, originalTotal, discountAmount }`
   - 导致无法获取原价和优惠金额

2. **报价汇总界面缺少显示**
   - 只显示折后价格
   - 不显示原价和优惠金额

3. **报价单详情页缺少显示**
   - 只显示总价
   - 不显示原价和优惠金额

4. **报价创建缺少价格信息**
   - 只传递折后价格（total）
   - 不传递原价和优惠金额

---
