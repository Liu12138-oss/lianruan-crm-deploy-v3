# 阶段8.3 PostgreSQL暂存装载交付记录

生成时间：2026-07-27

## 1. 阶段定位

阶段8.3交付 PostgreSQL 暂存层装载能力，把阶段8.2的 V2 只读导出文件转换为 PostgreSQL 可执行装载包，并在 `migration.*` 暂存表内完成数量守恒校验和异常隔离清单记录。

本阶段不写入业务正式表，不执行正式切换。

## 4. 生成命令

```bash
node scripts/migration/生成PostgreSQL暂存装载包.js \
  --export-manifest "tmp/stage8/v2-export-official/manifest.json" \
  --output-dir "tmp/stage8/v2-postgres-staging-official" \
  --batch-code "S8-RUN-20260727-001" \
  --record-doc "docs/stage-records/阶段8.3-PostgreSQL暂存装载包报告.md" \
  --force
```

## 5. 装载包边界

- 只写 `migration.migration_batches`、`migration.v2_raw_records`、`migration.v2_import_expected_counts`、`migration.validation_results` 和 `migration.migration_errors`。
- 不写业务正式表。
- 不保存 V2 明文密码、开放接口密钥、令牌和授权值。
- `02-verify-staging.sql` 失败时阻断进入阶段8.4。

## 6. 验收命令
