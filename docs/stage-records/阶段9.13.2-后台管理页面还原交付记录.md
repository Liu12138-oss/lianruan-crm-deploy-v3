# 阶段9.13.2 后台管理页面还原交付记录

## 交付目的

阶段9.13.2 的目标是让 V3 管理端继续沿用 V2 用户体感：管理员进入后台后，可以按原有业务心智查看审核中心、OpenAPI 对接、工作量配置、客户报备、商机、报价、订单等页面。V3 本阶段只做架构和页面体感还原，不改变 V2 既有业务流程。

## 交付范围

1. 管理端后台页面继续使用 V2 风格的顶部、侧栏、列表、表单、审核台和配置页结构。
2. 报备、商机、报价、订单第一业务链路保持既有流程：新建报备、审核通过、创建商机、试算报价、创建报价、报价转订单、订单确认。
3. 手机管理员和手机渠道用户保留一期入口，重点保证业务查询、新建入口、返回逻辑和底部导航不串路由。
4. OpenAPI 和工作量配置不再回落到通用列表页，改为后台专用配置页面。
