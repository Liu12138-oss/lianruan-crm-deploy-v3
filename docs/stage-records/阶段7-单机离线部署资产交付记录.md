## 3. 交付边界

- 本阶段交付可执行的部署资产、离线安装包生成能力和首个离线安装包构建产物。
- 本阶段已在当前构建机生成生产候选离线安装包，尚未向欧拉生产服务器部署。
- 当前无域名和证书，因此只支持HTTP和服务器IP方式做预生产验证。
- 当前无异机备份，因此只能完成本机备份脚本和异机备份配置留口。
- 真实初始化密钥不写入仓库，生产安装时由脚本在 `/opt/lianruan-crm-v3/secrets` 生成。

## 4. 后续阶段7执行顺序

1. 在构建机执行 `npm run verify`。
2. 执行 `deploy/single-server/scripts/build-images.sh`。
3. 执行 `deploy/single-server/scripts/save-images.sh`。
4. 执行 `deploy/single-server/scripts/package-offline.sh`。
5. 将 `tmp/phase7-package` 下的安装包上传到欧拉服务器。
6. 在欧拉服务器执行 `sudo SERVER_HOST=服务器IP ./scripts/install.sh`。
7. 执行 `sudo /opt/lianruan-crm-v3/scripts/start.sh`。
8. 执行 `/opt/lianruan-crm-v3/scripts/health-check.sh`。
9. 执行备份演练、单实例重启演练和回退演练。

## 5. 风险和注意事项

| 风险 | 说明 |
| --- | --- |
| 构建机无法访问Docker Hub | 构建和导出脚本已支持通过 `V3_NODE_IMAGE`、`V3_NGINX_IMAGE`、`V3_POSTGRES_IMAGE_SOURCE`、`V3_REDIS_IMAGE_SOURCE` 指定等价镜像源，也支持 `V3_SKIP_PULL=1` 使用本地已准备镜像 |
| 无HTTPS | 只能作为预生产或内网验证；正式公网开放前必须补域名和证书 |
| 无异机备份 | 不能承诺整机故障恢复时间；后续必须配置 `BACKUP_REMOTE_TARGET` |
| Compose环境变量含连接串 | 当前代码只支持 `DATABASE_URL` 和 `REDIS_URL`，严格密钥文件读取需后续改造 |
| Docker网段可信代理 | 当前 `TRUSTED_PROXY_IPS` 只支持精确IP，阶段7后续可改造为支持网段 |
| 业务功能未完整迁移 | 阶段7部署的是V3底座生产候选，不代表正式业务上线 |
