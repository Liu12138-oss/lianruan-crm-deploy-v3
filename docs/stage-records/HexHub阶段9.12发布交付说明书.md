## 9. 注意事项

1. 当前测试环境仍使用 HTTP 和服务器 IP，正式上线前需要配置域名和 HTTPS。
2. 当前是单机部署，未配置备用服务器时仍存在整机单点。
3. V2旧密码不恢复，正式用户需要初始化新密码。
4. OpenAPI旧密钥不迁移，正式对接前需要重新签发。
5. 阶段9.12仍是 V2 UI严格还原纠偏，不新增公海池等后续功能。
6. 本次新增了一组阶段9.12业务闭环验收数据，属于交付验收留痕。
7. Web标准 Docker 构建遇到本地 Docker 缓存摘要异常后，脚本按预案使用 Nginx 容器基底应急构建，最终 Nginx 镜像构建、导出、远端加载和页面巡检均通过。
