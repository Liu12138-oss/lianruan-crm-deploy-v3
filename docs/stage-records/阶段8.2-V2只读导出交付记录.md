## 6. 安全策略

- 导出文件不保存明文密码、开放接口密钥、令牌和授权字段。
- 每条记录保留源 JSON SHA256，后续可用于确认源记录未漂移。
- `users.password`、`openApiClients.secret`、审计 JSON 中的敏感字段均输出为 `[已脱敏]`。
- 正式迁移时，V3 用户密码应采用初始化密码加首次登录强制改密；开放接口密钥应重新签发。

## 7. 本阶段通过标准

1. `crm.db` 和 `audit.db` 完整性检查均为 `ok`。
2. 每类 CRM 实体满足源记录数等于导出记录数。
3. 审计日志满足源记录数等于导出记录数。
4. 导出文件、报告和清单均生成 SHA256。
5. 导出文件不得包含明文密码、密钥、令牌和授权值。
6. 未加 `--force` 时不得覆盖已有导出清单。
