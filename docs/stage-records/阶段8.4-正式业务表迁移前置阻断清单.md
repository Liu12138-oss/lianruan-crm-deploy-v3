# 阶段8.4正式业务表迁移前置阻断清单

生成日期：2026-07-27

## 1. 结论

阶段8.4当前不能直接执行正式业务表迁移。

原因是当前阶段8.3只完成 `migration.*` 暂存层装载，正式业务表落表脚本、业务映射转换、异常隔离处理、审计分区策略和业务抽样验收口径尚未完成。

## 2. 已具备输入

| 输入                   | 状态   |
| ---------------------- | ------ |
| V2正式源库数量记录     | 已完成 |
| V2只读导出             | 已完成 |
| PostgreSQL暂存装载包   | 已完成 |
| 测试服务器暂存装载演练 | 已完成 |
| 暂存层数量守恒校验     | 已通过 |
| 未解决异常             | `0`    |

## 3. 阶段8.4阻断项

| 编号     | 阻断项                                 | 处理要求                                               |
| -------- | -------------------------------------- | ------------------------------------------------------ |
| S8.4-B01 | 正式业务表落表脚本不存在               | 补齐 `阶段8_4_00` 至 `阶段8_4_04` SQL 和统一执行脚本   |
| S8.4-B02 | V2用户密码已脱敏                       | 不能恢复原密码，必须采用初始化密码、强制改密或重新激活 |
| S8.4-B03 | 开放接口密钥已脱敏                     | 不能恢复旧密钥，必须重新签发并通知接入方               |
| S8.4-B04 | 报价、订单明细完整性不足               | 需补金额、折扣、产品明细和状态机抽样验收               |
| S8.4-B05 | 渠道商产品、区域价、阶梯价存在结构差异 | 需补映射规则和异常隔离策略                             |
| S8.4-B06 | 审计表分区或默认分区策略未落地         | 需先补分区策略，避免历史审计写入失败                   |
| S8.4-B07 | 业务链路接口尚未完整迁移               | 不能用当前前端骨架验收替代业务验收                     |
| S8.4-B08 | 回退演练未完成                         | 测试迁移必须先验证恢复和清库重跑方案                   |

## 4. 建议脚本包

阶段8.4最小脚本包建议如下：

```text
阶段8_4_00_正式落表前预校验.sql
阶段8_4_01_基础字典与审计分区.sql
阶段8_4_02_主数据落表.sql
阶段8_4_03_业务链路落表.sql
阶段8_4_04_验收与批次封口.sql
执行阶段8_4正式落表.sh
```

脚本要求：

1. 所有脚本必须只读取 `migration.*` 暂存层，不回读 V2 SQLite。
2. 每一步必须可重复执行或具备明确的回退脚本。
3. 每一步必须写入 `migration.validation_results`。
4. 校验失败必须阻断下一步。
5. 正式业务表写入前必须先完成备份。

## 5. 阶段8.4验收标准

阶段8.4完成时至少满足：

| 验收项     | 标准                                                           |
| ---------- | -------------------------------------------------------------- |
| 主数据数量 | 用户、渠道商、产品、模块、功能与暂存层数量匹配或有明确隔离记录 |
| 业务链路   | 注册、商机、报价、订单、审批记录可关联                         |
| 账号策略   | 脱敏密码账号已进入强制改密或初始化状态                         |
| 开放接口   | 脱敏密钥客户端已进入重新签发状态                               |
| 审计数据   | 历史审计可查询，分区策略有效                                   |
| 异常隔离   | 未解决阻断异常为 `0`                                           |
| 回退       | 可按批次清理业务落表数据并恢复迁移前状态                       |

## 6. 启动条件

阶段8.4启动前必须确认：

1. 用户确认账号初始化策略。
2. 用户确认开放接口密钥重新签发策略。
3. 产品负责人确认报价和订单抽样验收口径。
4. 架构师确认审计表分区方案。
5. 测试负责人确认业务链路回归用例。
6. 运维负责人确认测试库备份和回退脚本。

满足以上条件后，阶段8.4可以进入测试迁移落表演练。
