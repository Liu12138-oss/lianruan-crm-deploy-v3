# 阶段1工程化骨架交付记录

生成时间：2026-07-23

## 交付范围

- 根npm工作区，包含 `apps/*` 和 `packages/*`。
- Node 22约束、TypeScript严格配置、ESLint、Prettier和统一验证脚本。
- Express 5 API骨架，应用创建和监听分离，提供 `/health/live`、`/health/ready`、`/health/dependencies`。
- Worker骨架，包含Redis连接配置位置和无业务副作用健康任务。
- Vue 3 + Vite 前端骨架，包含统一入口、管理端、渠道端、移动端和中文错误页测试路由。
- OpenAPI 3.1基础契约和契约类型生成入口。

## 验收命令

```bash
npm install
npm run check
npm test
npm run test:e2e
npm run build
npm run verify
```

## 本机依赖说明

- 当前开发机Node版本如果不是22，`npm run verify`会明确失败并提示升级。
- Redis和PostgreSQL在阶段1默认为 `HEALTH_DEPENDENCY_MODE=mock`，因此本机未启动容器时仍可完成骨架测试。
- 设置 `HEALTH_DEPENDENCY_MODE=real` 后，就绪检查会真实验证PostgreSQL和Redis。
