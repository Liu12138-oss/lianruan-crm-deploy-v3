# 阶段3审计事件与敏感操作清单

生成日期：2026-07-23

## 1. 审计目标

阶段3统一审计用于回答四个问题：谁在什么时间、从什么来源、对什么目标做了什么操作，结果如何。

审计模型必须能关联应用日志、接口请求、会话、账号状态、权限版本、数据范围和业务目标。审计记录不得保存密码、令牌、密钥、完整 Cookie、证书私钥和未脱敏敏感字段。

## 2. 审计事件模型

| 字段 | 含义 | 要求 |
| --- | --- | --- |
| `event_id` | 审计事件编号 | 全局唯一 |
| `request_id` | 请求编号 | 同一请求的应用日志和审计可关联 |
| `trace_id` | 链路编号 | 跨服务或异步任务复用 |
| `occurred_at` | 发生时间 | 使用带时区时间 |
| `actor_user_id` | 服务端确认的操作者编号 | 不读取前端自报操作者 |
| `actor_username` | 操作者用户名快照 | 写入当时快照，后续改名不影响追溯 |
| `actor_role_codes` | 操作者角色快照 | 写入本次会话中的角色代码 |
| `actor_auth_version` | 授权版本 | 用于排查旧会话授权问题 |
| `identity_source` | 登录来源 | 统一身份认证、真实客户关系管理系统、本地应急、开放接口 |
| `session_id_digest` | 会话编号摘要 | 不保存令牌明文 |
| `client_id` | 开放接口客户端编号 | 非开放接口可为空 |
| `source_ip` | 来源地址 | 可保存原值或合规要求下保存摘要 |
| `user_agent` | 用户代理 | 长度限制，防止日志膨胀 |
| `module` | 模块 | 身份、渠道、报备、商机、报价、订单、产品、审计等 |
| `resource` | 资源 | 用户、角色、渠道、报备、报价等 |
| `action` | 动作 | 读取、创建、修改、审批、导入、导出、下载等 |
| `permission_code` | 权限代码 | 记录本次动作要求的权限 |
| `data_scope_snapshot` | 数据范围快照 | 保存服务端计算结果摘要 |
| `target_type` | 目标类型 | 用户、渠道、报备、商机、报价、订单等 |
| `target_id` | 目标编号 | 业务编号或主键 |
| `target_summary` | 目标摘要 | 脱敏后的客户名、渠道名、账号名等 |
| `result` | 结果 | 成功、拒绝、失败、部分成功 |
| `reason_code` | 原因代码 | 便于统计和告警 |
| `reason_message` | 中文原因 | 不包含敏感明文 |
| `before_value_masked` | 操作前值 | 仅保存必要字段，必须脱敏 |
| `after_value_masked` | 操作后值 | 仅保存必要字段，必须脱敏 |
| `client_claims_masked` | 客户端自报字段摘要 | 用于记录篡改差异，不参与授权 |
| `idempotency_key_digest` | 幂等键摘要 | 不保存原始敏感载荷 |
| `risk_level` | 风险等级 | 普通、中风险、高风险、最高风险 |
| `retention_until` | 保留到期时间 | 按保留策略计算 |

## 3. 审计结果枚举

| 结果 | 使用场景 |
| --- | --- |
| `success` | 操作成功 |
| `denied` | 权限、数据范围、账号状态或来源地址拒绝 |
| `failed` | 系统错误或外部依赖失败 |
| `partial_success` | 批量任务部分成功，必须有明细报告 |
| `queued` | 异步任务已创建 |
| `cancelled` | 任务或会话被撤销 |

## 4. 敏感操作清单

| 类别 | 操作 | 风险等级 | 审计要求 | 审计不可用策略 |
| --- | --- | --- | --- | --- |
| 登录认证 | 登录成功、登录失败、统一身份回调失败、外部身份无映射 | 高风险 | 记录来源、账号摘要、失败原因、请求编号 | 登录类操作拒绝或延迟 |
| 密码凭据 | 修改密码、管理员重置密码、凭据迁移 | 高风险 | 不记录明文；记录目标账号和会话撤销结果 | 阻断 |
| 账号状态 | 启用、停用、锁定、解锁、拒绝审核 | 高风险 | 记录原状态、新状态、原因、操作者 | 阻断 |
| 角色权限 | 角色新增、角色停用、权限绑定、权限移除 | 最高风险 | 记录授权版本变化和影响范围 | 阻断 |
| 数据范围 | 绑定区域、绑定大区、绑定渠道、调整成员关系 | 最高风险 | 记录范围前后值和标准化结果 | 阻断 |
| 应急管理员 | 启用、登录、禁用、会话撤销、报告导出 | 最高风险 | 全量记录并立即告警 | 阻断 |
| 开放接口 | 客户端创建、停用、密钥轮换、权限调整 | 最高风险 | 密钥只记摘要；记录调用方和权限变更 | 阻断 |
| 导入导出 | 导入预检、导入执行、导出创建、导出下载 | 高风险 | 记录任务编号、范围快照、文件摘要、数量 | 阻断或暂停任务 |
| 审批 | 报备审批、报价审批、订单审批、账号审批 | 高风险 | 记录目标、原状态、新状态、审批意见摘要 | 阻断 |
| 价格金额 | 产品价格、折扣、报价金额、订单金额调整 | 最高风险 | 记录必要前后值，金额字段脱敏或按授权展示 | 阻断 |
| 渠道关系 | 创建渠道、停用渠道、上下级关系调整 | 高风险 | 记录关系前后值，检测断裂和环形 | 阻断 |
| 业务状态 | 商机阶段推进、订单取消、履约状态更新 | 中风险 | 记录状态变化和目标编号 | 普通动作可进入补偿，高风险阻断 |
| 密钥证书 | 配置密钥、证书、回调地址、来源白名单 | 最高风险 | 只记录摘要和配置项名称 | 阻断 |
| 数据恢复 | 备份恢复、迁移重跑、隔离数据释放 | 最高风险 | 记录处置单、操作者、摘要和影响数量 | 阻断 |
| 审计查询 | 查询审计、导出审计 | 高风险 | 记录查询条件摘要、导出文件摘要 | 阻断 |

## 5. 敏感字段处理

| 字段类型 | 处理方式 |
| --- | --- |
| 密码、一次性密码、口令片段 | 禁止进入审计、日志、响应和文件 |
| 会话令牌、开放接口密钥、刷新令牌 | 只保存摘要或末尾4位掩码 |
| Cookie、认证头 | 不保存完整值，只记录是否存在和摘要 |
| 手机、邮箱、证件号 | 按合规规则脱敏 |
| 客户联系人、电话 | 默认脱敏，只有授权审计查询才可查看 |
| 金额、折扣、价格 | 审计保存前后值时按角色脱敏展示，原始值仅限受控查询 |
| 文件名和导入内容 | 文件名脱敏，文件内容不进入审计事件 |

## 6. 审计保留建议

| 类型 | 建议保留期 | 说明 |
| --- | ---: | --- |
| 普通业务审计 | 不少于3年 | 对应阶段0默认建议 |
| 高风险审计 | 不少于5年 | 包含权限、应急、密钥、导入导出、审批和价格 |
| 应急管理员审计 | 不少于5年，且单独归档 | 应急报告需经产品、运维、安全复核 |
| 开放接口安全审计 | 不少于3年 | 便于追溯调用方和密钥轮换 |
| 访问日志 | 不少于180天 | 阶段0默认建议 |
| 导入原始文件 | 180天至1年，需合规确认 | 文件加密存放，过期删除 |
| 导出结果文件 | 7天至30天，需业务确认 | 到期删除，只保留摘要 |
| 审计导出文件 | 7天至30天，需安全确认 | 下载和删除都写审计 |

## 7. 查询和导出约束

- 审计查询需要 `audit.event.read` 权限。
- 审计导出需要 `audit.event.export` 权限，并写高风险审计。
- 查询条件、导出字段和返回字段必须按角色脱敏。
- 不允许普通业务用户查询审计。
- 应急管理员只能在启用时段内查询与处置单相关的审计，查询本身进入最高风险审计。

## 8. 告警建议

| 告警场景 | 级别 | 建议处理 |
| --- | --- | --- |
| 应急管理员启用或登录 | 最高 | 立即通知产品、运维、安全 |
| 来源地址不在白名单 | 高 | 拒绝并通知安全 |
| 连续登录失败或撞库特征 | 高 | 触发限流和临时锁定 |
| 权限或数据范围批量变化 | 高 | 要求二次复核 |
| 审计写入失败 | 高 | 高风险动作阻断，普通动作进入补偿 |
| 导出数量异常 | 高 | 暂停任务并要求复核 |
| 访问跨区域、跨渠道、跨本人数据 | 中到高 | 拒绝并记录风险审计 |
