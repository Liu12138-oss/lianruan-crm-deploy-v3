## 9. 后续阶段准入建议

### 阶段7生产部署准入

1. 固化Node 22长期支持版构建环境，所有生产候选版本继续执行 `npm run verify`。
2. 确认生产服务器操作系统、磁盘、备份目录、证书和域名。
3. 准备单机容器编排，包含PostgreSQL、Redis状态实例、Redis缓存实例、API、Worker、Web、Nginx和监控。
4. 完成异机备份位置和恢复演练，即使暂时没有备用服务器，也必须能在临时机器恢复。
5. 建立日志保留、备份保留、告警责任人和应急管理员双人保管机制。

### 阶段8迁移切换准入

1. 完成V2数据只读快照和迁移演练。
2. 完成数量守恒、金额逐分一致、状态合法性、附件文件存在性校验。
3. 完成业务抽样签收和异常分类。
4. 完成停写通知、停机窗口、回滚条件和恢复负责人确认。
5. 停机窗口按5至8小时控制，超时必须执行预设决策点。
