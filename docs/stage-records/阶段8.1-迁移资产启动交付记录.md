## 6. 准入门槛

进入第一轮测试迁移前必须满足：

1. 正式源库路径已确认，且 `crm.db`、`audit.db` 都存在。
2. `PRAGMA integrity_check` 全部返回 `ok`。
3. 每个有记录的 V2 实体都覆盖迁移映射。
4. CRM实体非法 JSON 数为 0。
5. 审计日志编号无空值、无重复，审计 JSON 字段非法数为 0。
6. 源库、WAL、报告文件都有 SHA256 记录。
7. 迁移脚本仅只读访问 V2，不修改源库。
