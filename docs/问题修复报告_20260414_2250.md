## 问题1：渠道商等级标签不显示 ✅

### 问题描述
- **现象**：渠道商管理列表的"级别"列只显示合作级别（金牌/银牌等），不显示渠道商等级（一级/二级/无等级）
- **预期**：同时显示合作级别和渠道商等级两个标签

### 根本原因
前端代码中，`getPartnerLevelBadge(partner)` 方法接收整个渠道商对象，但直接传递给 `PartnerLevelModule.getPartnerLevelBadge()`，而该模块期望接收的是等级字符串，而不是对象。

**错误代码**（admin-app.js 第5749-5755行）：
```javascript
function getPartnerLevelBadge(partner) {
  if (typeof window.PartnerLevelModule !== 'undefined') {
    return window.PartnerLevelModule.getPartnerLevelBadge(partner); // ❌ 传递了整个对象
  }
  return '';
}
```

**PartnerLevelModule 期望**：
```javascript
function getPartnerLevelBadge(level) {
  const config = getPartnerLevelTag(level); // level 应该是字符串 'primary' | 'secondary' | 'none'
  // ...
}
```

### 修复方案
在调用前提取 `partnerLevel` 字段：

```javascript
function getPartnerLevelBadge(partner) {
  if (typeof window.PartnerLevelModule !== 'undefined') {
    const level = partner?.partnerLevel || 'none'; // ✅ 提取等级字段
    return window.PartnerLevelModule.getPartnerLevelBadge(level);
  }
  return '';
}
```

**修复文件**：`frontend/admin-app.js` 第5749-5755行

## 问题2：审批后员工状态不更新 ✅

### 问题描述
- **现象**：超管在审核中心审批"企业管理员"账号后，审核中心显示操作成功，但在渠道商管理模块查看对应渠道商的员工列表，该账号仍显示"待审批"状态
- **预期**：审批通过后，渠道商详情页面的员工列表应显示"已审批"或"正常"状态

### 根本原因
前端审批方法只刷新了"待审批列表"，没有刷新"渠道商列表"，导致渠道商详情页面的员工数据还是旧数据。

**错误代码**（admin-app.js 第7894-7921行）：
```javascript
async function approveStaff(s) {
  try {
    let res;
    if (s.type === 'partner_admin') {
      res = await apiRequest('PUT', `/pending-approvals/${s.aprId}`, { 
        action: 'approve',
        approvedBy: store.user?.name
      });
    } else {
      res = await apiRequest('PUT', `/users/${s.id}/status`, { 
        status: 'active',
        approvedBy: store.user?.id
      });
    }
    
    if (res.success) {
      s.status = 'active';
      loadPendingApprovals(); // ❌ 只刷新了待审批列表
      // 缺少渠道商列表刷新
    }
  } catch (err) {
    alert('审批失败：' + err.message);
  }
}
```

### 后端逻辑验证
后端逻辑正确，审批通过后会更新两个地方：
1. 用户状态：`user.status = 'active'`（第2827行）
2. 渠道商员工状态：`partner.staff[].status = 'active'`（第2832行）
3. 待审批记录状态：`apr.status = 'approved'`（第2835行）

**后端代码**（server.js 第2823-2837行）：
```javascript
if (action === 'approve') {
  // 激活账号
  const user = db.users.find(u => u.id === apr.targetId);
  if (user) {
    user.status = 'active';
    // 同时激活 partner.staff 中的记录
    const partner = db.partners.find(p => p.id === apr.targetPartnerId);
    if (partner && partner.staff) {
      const sf = partner.staff.find(s => s.userId === apr.targetId);
      if (sf) sf.status = 'active'; // ✅ 后端正确更新
    }
  }
  apr.status = 'approved';
}
```

### 修复方案
在前端审批成功后，同时刷新渠道商列表：

```javascript
async function approveStaff(s) {
  try {
    // ... 审批逻辑 ...
    
    if (res.success) {
      s.status = 'active';
      store.notifications.unshift({ id:Date.now(), title:'员工审批通过', desc:`${s.name} 已审批通过`, time:'刚刚', unread:true });
      
      // 刷新待审批列表
      loadPendingApprovals();
      // ✅ 同时刷新渠道商列表，确保渠道商详情页面的员工状态更新
      await loadPartners();
    }
  } catch (err) {
    alert('审批失败：' + err.message);
  }
}
```

function getPartnerLevelBadge(level) {
  const config = getPartnerLevelTag(level);
  const tagClass = level === 'primary' ? 'tag-blue' : 
                   level === 'secondary' ? 'tag-green' : 'tag-gray';
