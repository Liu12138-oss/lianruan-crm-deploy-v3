# 阶段0迁移数据抽样验收模板

生成时间：2026-07-23

## 使用说明

本模板用于阶段0确认V2数据迁移边界、抽样口径和异常分类。阶段0不执行正式迁移，不写入SQLite样本库，不改V2生产数据。所有统计以 `docs/baseline/V2数据字典.xlsx`、`docs/baseline/V2数据质量报告.md` 和只读一致性快照为准。

抽样验收目标不是修复历史数据，而是决定每类异常在阶段2迁移时如何处理：自动映射、业务补录、隔离迁移、阻断迁移。
