# 阶段0角色权限允许拒绝样本模板

生成时间：2026-07-23

## 使用说明

本模板用于阶段0退出会前补齐“每个核心接口至少有一个允许样本和一个拒绝样本”的人工验收证据。阶段0只记录现状，不修复权限问题；历史4xx、前端隐藏、前端传角色、后端真实校验都按当前行为登记。

执行人必须使用复制后的样本库或隔离环境，不写入V2生产库，不写入SQLite样本库。涉及创建、修改、删除、审批、导入、导出、下载的场景，如无法做到只读验证，先记录为“待阶段3自动化验证”，不得为了补样本制造业务数据。
