# 阶段0状态机验收样本模板

生成时间：2026-07-23

## 使用说明

本模板用于冻结账号、渠道、报备、商机、报价、订单、审批和发布状态的当前语义。阶段0只确认“当前有哪些状态、哪些流转必须保留、哪些例外需要产品决策”，不修改业务逻辑，不补写历史数据。

状态验收必须同时保留允许样本和拒绝样本。涉及写操作时，在隔离环境或复制库中验证；如无法做到不污染样本库，则只登记代码路径、页面路径、业务负责人确认结论和后续阶段验证方式。

## 阶段0退出判定

| 判定项 | 最低要求 | 当前状态 | 是否阻断阶段1 |
| --- | --- | --- | --- |
| 状态值冻结 | 核心对象状态值已登记 | 已有 `现有业务状态机.md`，本模板待签收 | 不阻断工程骨架，阻断阶段2状态字段定稿 |
| 合法流转确认 | 每个核心状态更新有来源、目标、角色、条件 | 待人工确认 | 不阻断工程骨架，阻断阶段4业务接口迁移 |
| 金额样本确认 | 报价、订单、工作量样本由业务确认 | 待人工确认 | 不阻断工程骨架，阻断阶段2金额模型和阶段4报价订单迁移 |
| 非法流转样本 | 关键拒绝路径已登记 | 待人工确认 | 不阻断工程骨架，阻断阶段3和阶段4验收 |
