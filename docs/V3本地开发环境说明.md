# V3 本地开发环境说明

本文档记录本机开发用的容器、PostgreSQL 和 Redis 环境。该环境只用于第三版本地开发、迁移预演和接口测试，不直接代表生产配置。

## 已安装工具

- 容器运行环境：Colima
- 虚拟机管理：Lima
- 容器命令行：Docker
- 编排命令：Docker Compose

工具安装在当前用户目录：

```bash
~/.local/bin
```

如当前终端找不到命令，先执行：

```bash
export PATH="$HOME/.local/bin:$PATH"
```

## 启动容器环境

```bash
export PATH="$HOME/.local/bin:$PATH"
colima start
```

查看状态：

```bash
colima status
docker info
```

停止容器环境：

```bash
colima stop
```

## 启动数据库和缓存

```bash
export PATH="$HOME/.local/bin:$PATH"
docker compose -f deploy/local-dev/docker-compose.yml up -d
```

服务地址：

- PostgreSQL：`localhost:5432`
- 数据库名：`lianruan_crm_v3`
- 用户名：`lianruan`
- 密码：`lianruan_dev_password`
- Redis：`localhost:6379`
- Redis 密码：`lianruan_dev_redis`

## 健康检查

PostgreSQL：

```bash
docker exec lianruan-crm-v3-postgres pg_isready -U lianruan -d lianruan_crm_v3
docker exec lianruan-crm-v3-postgres psql -U lianruan -d lianruan_crm_v3 -c "select version();"
```

Redis：

```bash
docker exec lianruan-crm-v3-redis redis-cli -a lianruan_dev_redis ping
```

## 停止服务

```bash
docker compose -f deploy/local-dev/docker-compose.yml down
```

如需保留数据，只执行上面的停止命令即可。不要删除卷，除非明确要清空本地开发数据。
