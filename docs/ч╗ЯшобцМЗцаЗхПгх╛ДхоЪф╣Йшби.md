# OpenAPI 统计指标口径定义表

> 日期：2026-06-17  
> 用途：统一 AI-agent / crm-agent 统计分析口径。

## 1. 通用口径

| 指标 | 字段/来源 | 说明 |
|---|---|---|
| 记录数 | `totalCount` / 列表 `total` | 当前权限和筛选条件下的记录数 |
| 金额 | `amount / totalAmount / total / totalAmt` | 后端按可识别金额字段汇总 |
| 时间分组 | `createdAt` 默认，可用 `dateField` 调整 | 默认按月，可用 `granularity=day/month/year` |
| 状态分组 | `status` | 报备、报价、订单等对象 |
| 商机阶段 | `stage` | 商机不要按普通 `status` 理解 |
| 区域 | `region` | 业务对象所属区域 |
| 大区 | `bigRegion` | 业务对象所属大区 |
| 渠道 | `partnerId / assignedPartnerId / parentPartnerId / parentPartnerIds` | 渠道贡献需兼容多字段 |
| 负责人 | `ownerId / assignedStaffId / createdBy` | 负责人贡献按后端归一口径 |

## 2. 漏斗口径

```text
客户报备 -> 商机 -> 报价 -> 订单
```

| 阶段 | 资源 | 说明 |
|---|---|---|
| 客户报备 | `registrations` | 客户入口和报备状态 |
| 商机 | `opportunities` | 销售机会和阶段 |
| 报价 | `quotes` | 报价金额和报价状态 |
| 订单 | `orders` | 成交金额和订单状态 |

转化率：

```text
当前阶段数量 / 上一阶段数量 * 100%
```

总转化率：

```text
订单数量 / 客户报备数量 * 100%
```

## 3. 分析注意事项

1. 当前 token 绑定用户不是 `superadmin/all` 时，统计只能代表当前权限范围。
2. 同一份 Markdown 快照内必须使用同一时间范围和过滤条件。
3. 数据质量异常需要先列为问题，不得直接推导经营结论。
4. 列表本地聚合结果应与统计接口 `totalCount` 做交叉校验。
