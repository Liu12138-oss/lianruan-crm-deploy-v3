🏢 四、渠道商管理

4.1 新增渠道商

1
点击左侧 「渠道商管理」
2
点击 「新增渠道商」
3
填写信息（见下表）
4
点击 「保存」
字段说明必填
渠道商名称公司全称✅
渠道等级银牌 / 金牌 / 钻石✅
所属大区大北区 / 大东区 / 大南区 等✅
所属区域更细分的区域✅
联系人渠道商主要联系人✅
联系电话—✅
邮箱—选填

4.2 渠道商等级

等级说明
银牌 silver普通渠道伙伴
金牌 gold核心渠道伙伴
钻石 diamond顶级渠道伙伴，享受最优折扣

4.3 禁用 / 启用渠道商

点击 「禁用」 → 该渠道商员工将无法登录；点击 「启用」 恢复。

💡 禁用渠道商不会删除其历史数据。

👤 五、用户管理

5.1 新增员工账号

1
点击 「用户管理」 → 「新增用户」
2
填写用户名（登录账号，英文+数字，不可重复）、姓名、所属渠道商
3
角色选 staff（渠道员工），设置初始密码并告知用户
4
点击 「保存」

5.2 重置密码

1
找到对应用户，点击 「重置密码」
2
输入新密码后告知用户

5.3 禁用 / 删除账号

操作效果建议
禁用用户无法登录，数据保留员工离职时优先使用
删除彻底删除，不可恢复⚠️ 谨慎操作

✅ 六、商机审批

审批流程

渠道员工提交 → 区域管理员审批 → 通过 / 拒绝 → 员工收到结果

审批操作

1
点击左侧 「商机审批」 或仪表盘上的「待审批」角标
2
查看待审批商机列表，点击商机名称查看详情（客户信息、预计金额、描述）
3
点击 「通过」 → 商机正式锁定，同客户后续不接受其他渠道商重复提交
点击 「拒绝」 → 填写拒绝原因，返回给渠道员工
💡 重复商机处理：先提交且审批通过者优先；特殊情况下超级管理员可手动干预。

📄 七、报价管理

7.1 查看报价单

点击 「报价管理」，可按渠道商、客户名称、时间筛选，点击报价单查看产品明细、金额、有效期等。

7.2 报价审批

报价金额超出权限时需管理员审批：在报价单详情页点击 「审批通过」 或 「审批拒绝」（拒绝需填写原因）。

📦 八、订单管理

8.1 订单审批

1
点击 「订单管理」 → 「待审批」
2
查看订单详情（产品、金额、渠道商信息）
3
点击 「确认成单」 或 「退回修改」

8.2 订单状态流转

待审批 → 已确认 → 执行中 → 已完成 （也可 → 已取消）

🗂️ 九、产品管理 仅超级管理员

9.1 产品目录结构（三级）

产品大类（如：联软ESPP企业安全监测保护平台）
  └── 产品模块（如：桌面安全管理、防泄密、防勒索、准入控制）
        └── 功能模块（具体可售项目，含产品编码和价格）

9.2 添加新产品

1
点击 「产品管理」，选择对应大类和模块
2
点击 「新增功能模块」
3
填写：功能名称、产品编码（如 UA-AM-1）、计费单位（端点/套/年）、定价类型（阶梯 or 固定）、各阶梯价格、折扣系数
4
保存后对渠道商端立即生效

9.3 修改价格

找到对应功能模块 → 点击 「编辑」 → 修改后保存。

⚠️ 价格修改立即生效，但不影响已生成的报价单。

9.4 下架产品

点击功能模块的 「下架」，渠道商报价单中将不再显示该产品。

⚙️ 十、系统设置 仅超级管理员

10.1 大区和区域管理

可在系统设置中增加/修改大区和区域划分，新增区域后为其分配区域管理员。

10.2 数据备份（重要！）

⚠️ 系统所有数据存储在 backend/data.json，文件丢失则数据全部消失！必须定期备份。

手动备份：

cp /opt/lianruan-crm-deploy-v2.2.0/backend/data.json \
   /opt/backup/data_$(date +%Y%m%d_%H%M%S).json

配置每日自动备份（crontab）：

# 编辑定时任务
crontab -e

# 每天凌晨2点备份，保留30天
0 2 * * * cp /opt/lianruan-crm-deploy-v2.2.0/backend/data.json \
  /opt/backup/data_$(date +\%Y\%m\%d).json \
  && find /opt/backup/ -name "data_*.json" -mtime +30 -delete

❓ 十二、常见问题

Q：渠道员工反映无法登录？
检查账号状态是否「启用」、所属渠道商是否被禁用、密码是否正确。可在用户管理中重置密码。
Q：如何导出所有渠道商数据？
当前版本暂无导出功能。可直接备份 backend/data.json，用文本编辑器或 Excel 处理 JSON 数据。
Q：商机重复导致渠道商纠纷？
以系统登记时间为准，先提交且审批通过的渠道商享有独家权益，超级管理员可查看完整提交时间记录。
Q：忘记超级管理员密码？
在服务器上直接编辑 backend/data.json，找到 username: "admin" 的记录，将 password 字段改为新密码，然后重启服务。
Q：服务器重启后系统不能访问？
需要手动重新启动服务：bash scripts/start.sh start。建议配置 systemd 开机自启，请联系技术支持。
如需技术支持，请联系联软科技实施团队。
