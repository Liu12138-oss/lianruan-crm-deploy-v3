# 正式管理员页缺少“外部身份映射”入口修复方案手册

## 1. 问题标识

- 任务目录：`docs/tasks/formal-admin-external-identities-entry-fix/`
- 影响环境：生产环境 `10.20.3.10`
- 当前生产版本：`3.0.0-stage10.20260910-messagepageidentity1`
- 当前生产提交：`699b3eb`
- 问题类型：已上线查询能力未接入正式管理端页面

## 2. 现象

用户从统一入口进入 `admin.html`，打开“组织架构”后，只能看到“组织与成员、证书管理、角色管理、权限与范围、离职交接、企微同步”，没有“外部身份映射”。

用户目前只能逐个打开账号编辑抽屉，查看单个账号的“泛微 OA 身份”和“企业微信身份”；不能批量核对泛微 OA userid、企业微信 UserId 和映射缺失/异常状态。

## 3. 已确认根因

后端和工程化页面已经实现并发布了批量查询能力：

- 接口：`GET /api/org/external-identities`
- 后端：`apps/api/src/org-routes.ts`、`apps/api/src/org-store.ts`
- 契约：`packages/contracts/openapi/organization.yaml`
- 工程化页面：`apps/web/src/pages/admin/platform-admin/OrganizationWorkspacePage.vue`
- 工程化路由：`/workspace/admin/platform-admin/organization/external-identities`

但生产正式入口是 `apps/web/public/admin.html` 加载的 `apps/web/public/admin-app.js`。该静态脚本没有同步增加：

1. “外部身份映射”页签；
2. `/organization/external-identities` 正式内嵌路由；
3. 查询客户端、响应式状态、筛选、统计、列表和分页；
4. 正式入口的回归和发布校验断言。

这是正式发布资产漏接，不是权限开关、数据库数据或浏览器缓存问题。

## 4. 修复目标

在正式管理端中增加只读页面：

~~~text
平台管理 → 组织架构 → 外部身份映射
正式路径：/organization/external-identities
~~~

页面仅允许超级管理员使用现有 Cookie 会话查询现有接口；不修改任何身份数据、订单、OA、企微或消息业务。

## 5. 严格边界

不得修改：

- `iam.external_identities`、`iam.external_identity_candidates` 中的任何数据；
- 泛微候选确认、驳回、停用流程；
- 企业微信身份导入、冲突校正、企微组织同步；
- 订单预审、泛微 OA 发起、自动拉群、消息通道；
- 订单、客户、商机、报价、渠道商、区域权限；
- 企微应用凭据、泛微参数、生产功能开关；
- V2 目录、移动端页面和历史接口。

不新增数据库迁移，不直接修改生产数据库。该任务只是把已经上线的只读查询能力补入正式桌面端页面。

## 6. 推荐修复路径

### 6.1 开始前基线核对

其他 Agent 开始前先执行：

~~~bash
git status --short
git rev-parse --short HEAD
git show --stat --oneline 699b3eb
~~~

发现无关未提交改动时必须保留，禁止重置或覆盖。批量查询的字段定义和状态规则以现有方案为准：

~~~text
docs/tasks/external-identity-mapping-query/IMPLEMENTATION-PLAN.md
~~~

### 6.2 补正式脚本查询客户端

在 `apps/web/public/admin-app.js` 的组织接口客户端区域增加等价方法：

~~~javascript
function 组织查询外部身份映射(参数 = {}) {
  return 组织读取('/api/org/external-identities' + 组织构建查询参数(参数));
}
~~~

必须复用 `组织读取`，确保请求携带 `credentials: 'include'`。禁止改用 `/api/v2`、页面令牌、兼容令牌或客户端自报身份字段。

### 6.3 补正式页签、当前栏目和路由

在 `导航项列表` 中增加：

~~~javascript
{ 栏目: 'external-identities', 名称: '外部身份映射', 路径: '/organization/external-identities' }
~~~

在 `当前栏目` 解析中增加：

~~~javascript
if (路径.endsWith('/external-identities')) return 'external-identities';
~~~

在正式管理员路由表中增加：

~~~javascript
{ path: 'organization/external-identities', component: OrganizationWorkspace }
~~~

禁止把正式入口改为跳转到 `/workspace/admin/platform-admin/organization/external-identities`。工程化工作区只能作为过渡预览通道；正式用户必须继续留在 `admin.html`。

### 6.4 补正式页面内容

从 `OrganizationWorkspacePage.vue` 移植等价的只读逻辑到 `admin-app.js`，包括：

- 结果、加载和错误状态；
- 关键词、区域、系统角色筛选；
- 映射类型：全部、仅泛微、仅企微；
- 映射状态：全部、完整、泛微缺失、企微缺失、异常；
- “包含停用账号”开关；
- 统计：账号总数、泛微已确认、泛微缺失、泛微待核验、企微已维护、企微缺失、映射异常；
- 表格：登录名、姓名、账号状态、区域、系统角色、泛微状态、企微状态、查看详情；
- 分页：默认 20，允许 20、50、100；
- 状态编码的中文标签和明确错误提示。

“查看详情”必须复用现有账号编辑抽屉，例如传入 `userId、username、displayName、statusCode` 打开内部账号详情；完整 userid 在抽屉中查看。列表默认只显示映射状态，不能新增身份修改、批量确认、导出或导入按钮。

进入该页签时加载数据；筛选变更重置到第 1 页；关键词使用回车或防抖触发。禁止逐账号请求，禁止 N+1 查询。

### 6.5 必须处理路由切换

正式 `OrganizationWorkspace` 是同一组件复用路由，不能只在 `onMounted` 中加载外部身份映射。

需增加对 `当前栏目` 的监听：当栏目切换为 `external-identities` 且组织功能已开启时，调用加载函数。否则用户从“组织与成员”点击该页签时可能看到空白页面。

## 9. 人工验收

用超级管理员账号验收：

1. 从 `/` 登录后进入 `admin.html`；
2. 进入“组织架构”，顶部出现“外部身份映射”；
3. 点击后地址为 `/organization/external-identities`；
4. 显示统计和映射列表；
5. 各筛选条件、分页和刷新均生效；
6. 点击“查看详情”后可在既有账号抽屉中查看泛微 OA 与企业微信身份；
7. 刷新页面仍停留在该栏目；
8. 普通管理员、区管和渠道账号不能访问；
9. 组织功能关闭时不读取映射数据，保留现有关闭提示；
10. 只读观察模式没有任何身份写入按钮。

回归：组织其他六个页签、账号编辑、泛微候选、企微映射导入、登录、订单、OA、自动拉群、消息通知和移动端入口均正常。

## 10. 制包、发布和回退

生产发布前必须取得明确授权，并先执行全量备份和校验：

~~~bash
sudo bash /opt/lianruan-crm-v3/scripts/system-backup-restore.sh backup
sudo bash /opt/lianruan-crm-v3/scripts/system-backup-restore.sh verify --backup <本次备份目录>
~~~

制包前必须实际执行升级包外层校验、包内 `manifest/SHA256SUMS` 校验、脚本语法检查和正式静态页验证。生产服务器不得访问镜像仓库。

发布后必须记录：

- 版本与提交；
- `admin.html` 实际引用的静态资源路径；
- 正式脚本包含上述路由和接口；
- API、Nginx、Worker、PostgreSQL、Redis 的健康状态；
- 超级管理员页面验收截图。

若正式管理员页加载异常、组织其他页签异常或静态资源校验失败：

1. 停止继续发布，不修改数据库；
2. 保留验证输出和日志；
3. 使用既有升级脚本回退到升级前镜像和静态资源；
4. 回退后执行健康检查和正式入口冒烟；
5. 本任务没有数据库迁移，禁止用数据库恢复处理前端静态资源问题。

## 11. 完成判定

只有同时满足以下条件才可关闭问题：

- 正式 `admin.html` 可见并可访问“外部身份映射”；
- 生产正式静态资源确实包含该路由、接口调用和列表；
- 超级管理员能查询，非超级管理员不能访问；
- 没有身份数据、订单数据或生产配置的非授权变更；
- 全部测试、制包校验、备份、发布和回退记录齐全；
- 现有组织、订单、OA、企微和消息主业务回归通过。
