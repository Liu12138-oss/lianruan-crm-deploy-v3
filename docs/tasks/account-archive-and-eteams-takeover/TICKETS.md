# 任务单

## T1 账号归档清理

- 增加归档预览与执行服务、路由、审计和前端按钮。
- 仅允许已完成交接的停用账号；存在未处理交接项时拒绝。
- 保存原登录名历史，生成唯一归档登录名，释放原登录名。

## T2 泛微身份接管

- 放宽停用账号执行“停用泛微身份”的校验，但仍禁止停用启用账号映射。
- 增加来源停用账号到启用目标账号的一键接管接口和前端入口。
- 保持数据库有效 userid 唯一约束，增加审计和并发冲突处理。
- 接管必须分别确认来源登录名和目标登录名，确认错误时事务不产生任何映射变化。

## T3 测试与回归

- 覆盖归档资格、未完成交接、登录名释放、历史引用保留、重复归档和并发冲突。
- 覆盖泛微接管成功、来源启用拒绝、目标已有映射拒绝、userid 冲突和事务回滚。
- 运行 API 类型检查、组织集成测试、Worker 交接测试和前端构建。
