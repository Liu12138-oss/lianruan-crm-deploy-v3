# 报价免审批直接转订单修改方案

> 依据用户 2026-11-04 明确确认的业务口径整理。术语见仓库 `docs/CONTEXT.md`。

## 问题陈述

新 UI 的渠道标准产品报价仍沿用历史报价审批链路：渠道员工创建报价后需要提交，区管再确认，才能把报价转为订单。这与当前业务口径不一致。标准产品报价的报价金额应为 0，全链路不展示价格，转成订单后由区管在订单审批节点补充最终价格；渠道分销产品报价由服务端自动取价，也不需要报价审批。新 UI 继续展示报价审批按钮和审核中心报价分类，会让渠道员工误以为必须等待审批，并产生无意义的待办。

## 解决方案

- 新 UI 的报价中心、商机报价弹窗移除提交、确认、驳回、重新提交和撤回等报价审批动作，仅保留查看、打印、修改历史报价和直接转订单。
- 报价中心页签调整为“全部、待转订单、标准产品、渠道分销”，草稿报价直接归入待转订单。
- 标准产品报价继续由服务端保存产品和数量，报价金额固定为 0；报价接口、列表、详情、试算、PDF 和新 UI 均不展示价格，订单显示“待区管定价”。
- 渠道分销产品报价继续由服务端按标准价、区域覆盖价和渠道分销层级自动取价。
- 报价状态为 `draft`、`submitted`、`approved`、`rejected` 时均可直接转订单；`converted`、`cancelled`、`expired` 禁止转单。
- 同一报价重复转单优先返回 `V3_QUOTE_ALREADY_CONVERTED`，不得产生第二张订单。
- 标准产品报价转成订单后进入待区管定价状态，区管必须补充大于 0 的最终订单价格，才能提交超管确认。
- 审核中心移除“报价审核”分类和指标；历史报价审批数据不删除，但不再进入待审批和已审批列表，避免形成无法处理的遗留任务。
- 保留报价状态接口供旧 UI/V2 兼容使用，不修改老 UI。本轮只改变新 UI 的调用路径和服务端转单门禁。

## 影响范围

- 服务端：报价转订单状态门禁；重复转单检查保持优先；标准产品报价已有免价能力复用。
- 新 UI：报价中心、商机报价弹窗、审核中心、工作台待办统计和路由说明。
- 测试：API 覆盖草稿、历史提交、历史通过、历史驳回、已取消和重复转单；Web 覆盖新 UI 不出现报价审批按钮；测试环境执行真实报价创建、直接转单、区管补价和页面验收。
- 数据库：不新增迁移，不修改历史报价状态和金额。
- 老 UI/V2、移动端报价接口和报价审批状态兼容接口：保留，不修改页面和业务入口。

## 兼容性分析

- 历史报价的 `submitted`、`approved`、`rejected` 状态可能由旧流程产生，新 UI 允许这些状态直接转单，避免存量在途报价被阻断。
- `converted` 报价已有订单，继续禁止转单；`cancelled` 和 `expired` 视为关闭状态，禁止转单。
- 标准产品报价金额为 0 是业务预期，不代表订单最终成交价；最终价格以区管补价后的订单金额为准。
- 渠道分销产品报价沿用原自动取价和权限脱敏逻辑，不因取消报价审批而扩大价格可见范围。
- 老 UI 仍可调用报价状态接口；本次不删除接口、不删除历史状态数据、不改变老 UI 页面。

## 验收标准

- [x] 新 UI 报价中心和商机报价弹窗不存在提交、确认、驳回、重新提交、撤回报价按钮。
- [x] 渠道员工创建标准产品报价后金额为 0，无需报价审批即可直接转订单。
- [x] 草稿、历史提交、历史通过、历史驳回报价均可直接转订单。
- [x] 已取消报价不能转单；同一报价重复转单返回已有订单提示。
- [x] 标准订单进入“待区管定价”，区管未补价或补零价格不能提交超管确认。
- [x] 渠道分销产品报价自动取价正确，无需报价审批即可直接转订单。
- [x] 审核中心不再展示报价审核分类或历史报价待办。
- [x] 收货人、联系电话、收货地址、一级渠道出货金额和合同附件校验不回归。
- [x] 老 UI/V2 报价状态接口保持兼容，未修改老 UI 页面。
- [x] 测试环境版本、健康检查、数据清理和回退证据完整。

## 回归范围

- 报价：新建、详情、列表、试算、修改、打印、直接转订单。
- 商机：关联报价弹窗、直接转订单、转单后订单列表回显。
- 审核：待审批、已审批、客户报备、渠道资质和订单审批不回归。
- 订单：待区管定价、区管补价、超管确认、一级渠道确认、取消订单、附件下载和渠道利润脱敏。
- 权限：超级管理员、区管、一级渠道、二级渠道的数据范围和价格可见范围。

## 回滚方案

- 本轮不包含数据库迁移，回滚只回退应用镜像。
- 发布前备份测试环境 Compose 配置、`v3.env`、`deploy.env` 和数据库。
- 当前测试环境版本 `3.0.0-stage10.20261029-quote-order-fulfillment-r1` 作为回退目标。
- 若验收失败，恢复发布前 `.env` 中的 API、Worker 和 Nginx 镜像标签，仅重启对应测试环境容器，不回退数据库结构。

## 范围外

- 不修改老 UI/V2 的报价审批页面和按钮。
- 不删除历史报价审批记录，不批量改写历史报价状态。
- 不修改标准产品报价的最终定价权限，仍由区管在订单审批节点补价。
- 不修改渠道分销产品的价格规则、区域覆盖规则或渠道等级规则。
- 不连接、不部署、不修改生产环境。
