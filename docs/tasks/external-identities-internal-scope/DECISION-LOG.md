# 决策记录：外部身份映射仅显示联软内部人员

## 已确认事实

- 当前外部身份映射查询直接从 `iam.users` 查询账号，因此会包含渠道商员工和没有内部任职的历史账号。
- 联软内部组织由 `org.org_units.unit_type NOT LIKE 'channel_%'` 标识。
- 当前有效内部人员以 `org.staff_assignments.expired_at IS NULL` 且任职组织为有效内部组织为准。

## 用户确认

- 仅显示当前联软架构人员。
- 不显示渠道商员工和已结束内部任职的历史账号。
- 不影响当前业务和既有身份映射数据。

## 采用方案

服务端在外部身份映射基础查询中增加有效内部任职存在性条件；同时返回当前主内部任职组织名称，页面增加“所属组织”列。筛选、统计、分页和映射维护入口保持不变。

## 验收与回退

- 通过 API 单元测试和前端静态断言。
- 不新增数据库迁移，不写入业务表，不调用外部系统。
- 如需回退，仅回退本次代码发布版本即可，数据库数据无需恢复。
