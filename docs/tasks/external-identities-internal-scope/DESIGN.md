# 外部身份映射内部组织范围优化

## 目标

外部身份映射页面只展示当前有效归属联软内部组织的人员，避免渠道商账号和历史离职账号形成错误的映射待办统计。

## 实施边界

- 修改 `apps/api/src/org-store.ts` 的查询条件和返回字段。
- 修改当前正式管理员入口 `apps/web/public/admin-app.js` 的说明和所属组织列，并更新资源版本号。
- 补充接口和页面回归测试。
- 不修改数据库结构、身份映射记录、权限规则和其他业务查询。

## 数据口径

账号必须存在一条未过期的 `org.staff_assignments`，且任职组织为非渠道组织、状态为 `active` 或 `draft`。停用账号只有在勾选“包含停用账号”且仍有有效内部任职时显示。

## 风险控制

查询采用 `EXISTS` 和主任职 `LATERAL` 查询，不改变原有身份映射聚合逻辑；没有有效内部任职的账号不会被删除或停用，只是不出现在该页面及其统计中。
