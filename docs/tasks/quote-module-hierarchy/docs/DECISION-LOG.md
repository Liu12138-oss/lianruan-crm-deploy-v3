# 报价方式三级结构决策日志

## 2026-10-28 — 报价方式与目录结构

- 问了什么：用户提供了旧 UI 三张截图，要求新 UI 的报价单按“报价方式 → 功能模块 → 具体功能”展示，可选内容留在报价方式区域，软件模块区只展示已选内容。
- 定了什么：沿用旧 UI 的信息层级。套餐报价和补充功能先选产品套餐；自定义报价与维保报价按产品大类卡片选择，点击大类后在下方按产品模块分组展示具体功能。软件模块区改为按产品模块分组，只展示已入单功能。
- 否了什么：不再在软件模块区放可选功能搜索和可选模块网格；不把产品大类、产品模块和具体功能平铺成同一层；不改报价试算、价格规则、保存载荷和审批逻辑。
- 权衡了什么：复用现有阶段九产品数据，并用只读产品树补充稳定的排序与图标；产品树不可用时回退到阶段九数据自带的分类和模块名称，避免报价页因目录树接口失败而无法使用。
- 范围边界：本次只改桌面端新建/编辑报价页；移动端报价表单不纳入本次结构重构。老 UI/V2 页面不修改。

## 2026-10-28 — 测试环境最终验收

- 验收对象：测试环境 `http://10.9.86.66` 的前端镜像 `lianruan-crm-v3-nginx:3.0.0-stage10.20261028-quotehierarchy-r1`；API 与 Worker 仍为既有 r9，本次未重启。
- 套餐报价：21 个套餐均保留；默认数据防泄漏（DLP）带出 11 个功能；切换到无代理准入后，软件模块清单收敛为 1 个功能，金额随服务端重新计算。
- 补充功能：展示 14 个产品大类，只列套餐外功能；套餐内 11 个功能保持锁定，点击不会重复入单，金额不变。
- 自定义报价：展示 14 个产品大类和具体功能；点击大类可切换模块与功能明细，点击功能立即进入软件模块清单。
- 渠道端：三类方式均可切换，自定义目录展示 14 个大类；报价方式选择区没有价格符号、价格规则或内部成本说明。
- 编辑回填：历史套餐报价正确选中远程办公套餐并回填 2 个产品；历史自定义报价正确回填 1 个产品与数量 100；数量加 1 后服务端返回新金额。
- 布局：1366、1440、1920 三档宽度下文档宽度等于视口宽度，报价方式面板与产品大类卡片无横向溢出。
- 自动化：`npm --workspace @lianruan/web run check`、`npm --workspace @lianruan/web run test`、`npm --workspace @lianruan/web run build` 均通过，单元测试 224/224。
- 未执行写操作：未保存报价、未转订单、未修改数据库；避免用验收动作污染业务数据。
- 已知边界：移动端报价表单、价格算法和报价保存载荷不属于本次改动；渠道报价页的计算结果区沿用既有报价权限，本次报价目录选择区未新增价格信息。
