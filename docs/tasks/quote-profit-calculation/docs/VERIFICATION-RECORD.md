## 4. 收益专项验证

### 4.1 计算引擎

- 验证 `weidun-v1` 公式、定点字符串和输入指纹稳定。
- 覆盖软件、硬件、服务、质保年限、采购维保年限、一分钱精度、负收益和缺失规则。
- 验证采购维保成本只作为结果保存，不从项目收益再次扣减。
- 验证硬件同型号两台时，销售金额、内部成本和年度质保/维保成本均按两台计算。

### 4.2 API 与权限

- 验证收益查询、草稿保存、服务端重算、冻结投递和成本规则新旧版本接口。
- 验证金额字段不能由前端提交覆盖服务端计算。
- 验证超管、普通管理员、单区域区管和多区域区管的权限边界。
- 验证跨区域访问返回保护性 404，区管无正式区域绑定返回明确 403。
- 验证 `/api/v2`、OpenAPI、MCP、渠道端和普通管理员页面不暴露收益金额或内部成本。

### 4.3 Worker 与异步冻结

- 验证订单超管确认后写入 `crm.quote.profit.freeze.requested`。
- 验证缺成本时生成 `incomplete`，订单状态不回滚。
- 验证补齐成本规则后自动重试并生成 `frozen`。
- 验证事件租约、重复事件和并发处理不会重复生成正式快照。
- 验证正式快照使用订单确认事件时点对应的成本规则。

### 4.4 数据库迁移

- 在本地 PostgreSQL 16.4 隔离测试库完成“正向迁移 → 回退迁移 → 再次正向迁移”闭环。
- 验证回退脚本能识别新增格式硬件数量和上线后业务数据并安全阻断破坏性回退。
- 验证 13 条 Excel 初始成本规则存在，`LV-7050A → LV-7050-A` 映射成立，年度成本保持 `NULL`。
- 验证冻结记录不可直接更新，成本规则有效期不能重叠。

## 6. 残余风险与边界

1. 生产环境的数据量、账号数据范围、历史异常区域和目录映射仍需在发布前执行预检，不应直接复用本地统计值作为生产结论。
2. 历史订单不自动回填收益。若后续要求回填，必须单独生成清单、确认订单确认时点与成本版本时点，并获得授权。
3. 成本规则 V1 只允许当前或过去时间生效。补齐历史已确认订单时，若规则生效时间晚于订单确认事件时间，Worker 仍按确认时点取值，收益可能继续保持 `incomplete`。
4. 升级包尚未制作；生产发布前仍需完成外层 SHA256、解压、包内校验、脚本语法、动态资源路径和关键断言验证。
5. 本次验证没有对生产配置、生产数据、外部 OA、企微或消息平台产生副作用。

1. 备份生产数据库、应用配置、当前镜像摘要和 Worker 配置。
2. 在生产同构环境执行预检和迁移断言，确认 13 个型号、稳定分类编码和区域来源分布。
