# 修改任务单

## T01 报价与价格规则收口（阻塞 T02、T03）

- 修正端点数量严格校验、未来/停用区域价过滤、价格区间冲突校验和价格版本留痕。
- 报价编辑增加并发互斥与 `rowVersion` 冲突校验；并发转单冲突返回 409，不返回 500。
- 验收：QTE-22、QTE-25、QTE-26、QTE-30、PRD-15、PERF-04 对应自动化测试通过。

## T02 产品目录与工作量维护（阻塞 T03）

- 产品大类、模块、功能、硬件、套餐写接口仅允许内部管理员；渠道和区管越权返回 403。
- 空套餐、重复功能/硬件、被引用项删除均明确拒绝；增加工作量映射和交付规则完整 CRUD。
- 验收：PRD-13、PRD-14、PRD-17、PRD-19、PRD-20、SEC-02 对应接口测试通过。

## T03 质保、客户与商机一致性

- 核实质保更新接口实际落库与客户业务概况回读；修正边界样式和取消订单口径。
- 补齐客户查重审计检索、报备下拉选项、驳回重提、维保商机关联订单展示。
- 验收：PWR-01 至 PWR-06、PWR-11、REG-16、REG-18、REG-21、OPP-11、OPP-15、OPP-16、OPP-18 有真实页面或接口证据。

## T04 审批、渠道、组织与消息

- 增加审批记录详情路由、驳回原因校验、终态待办过滤、审批计数刷新和渠道审批拒绝。
- 修复渠道成员手机号规范化唯一、审批状态、成员数口径和等级中文。
- 增加账号停用会话撤销验证；修正证书当天到期边界；补齐组织导入预览/错误报告。
- 修正消息偏好字段写入、已读幂等和关闭态文案。
- 验收：APR-09、APR-12 至 APR-16、CHN-18、CHN-20 至 CHN-23、ORG-15 至 ORG-22、MSG-09、MSG-11、MSG-12、E2E-34。

## T05 导入导出与审计

- 导入增加同文件重复、行号错误、编码识别、超长字段、批次幂等和错误报告下载；全失败批次返回非成功业务结果。
- 审计增加筛选导出、稳定分页、完整性摘要和长文本安全展示。
- 验收：IMP-01 至 IMP-05、IMP-07、IMP-08、AUD-09、AUD-13、AUD-14。

## T06 移动端能力补齐

- 商机详情兼容 `followups`/`followUps` 并展示跟进历史；客户列表增加搜索。
- 移动报价增加试算/提交入口；订单详情按角色提供确认、退回、审批动作。
- 统一 44px 触控区、日期/数字键盘和弹窗宽度。
- 验收：MOB-02 至 MOB-05、MOB-07；MOB-01 修订为当前统一移动入口验收口径。

## T07 安全、并发与稳定性

- 全局同源写请求校验、上传内容类型识别、登录失败限流、存储型 XSS 复核。
- 修复客户/商机/报价快速连点幂等与按钮防重。
- 对外部 Worker/IAM/OA/企微项完成代码级准备并明确环境阻塞。
- 验收：SEC-04、SEC-05、SEC-07、SEC-08、PERF-01、PERF-02、PERF-05、PERF-06、AUTH-10、MSG-13、INT-01 至 INT-06。

## T08 发布、复测与报告（依赖 T01-T07）

- 构建并部署测试环境，核对 API/Worker/Nginx 版本和健康检查。
- 只复跑受影响脚本，生成新结果文件与 Markdown/HTML 最终报告。
- 更新 `docs/AI接手会话记录.md`，列明阻塞项和需要的授权/凭据。
- 验收：测试环境健康、受影响用例全部有最新结论、报告可追溯。
