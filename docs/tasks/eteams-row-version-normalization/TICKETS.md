# 任务单

## T1 API 行版本数字化

泛微身份详情查询中的行版本以 JSON 数字返回。

## T2 正式页面兼容保护

候选维护和正式身份维护提交前转换行版本。

## T3 回归验证

验证候选、正式泛微、企业微信身份详情的行版本类型，以及正式页面保护代码。

## T4 内部管理员组织归集

账号管理新建超管或区管时，在同一事务内创建对应组织任职；区管按正式区域归入“联软总部→大区→区域”。

## T5 新建内部用户外部身份

账号管理和组织成员的新建用户入口支持可选泛微 OA userid、泛微姓名或登录名、企业微信 userid；泛微写待核验候选，企微唯一校验后写有效身份。
