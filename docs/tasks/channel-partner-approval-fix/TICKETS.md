# 渠道商创建审批缺陷修复任务单

## CP-01：待审批状态与回退资产

- 状态：已完成。
- 实现：渠道商主档增加 `pending`、`rejected` 状态约束，并提供对应回退脚本。
- 验收：区域管理员提交的渠道商可保存为 `pending`；回退前发现待审批或已驳回记录时拒绝执行。

## CP-02：创建、审批与状态同步

- 状态：已完成。
- 实现：创建待审批渠道商时同一事务写入主档、审批任务、审批事件和发件箱事件；通过或驳回时同步主档状态。
- 验收：`pending → active`、`pending → rejected`、`rejected → pending` 状态转换与审批任务一致；重复处理返回冲突。

## CP-03：列表范围与审批中心展示

- 状态：已完成。
- 实现：渠道商保存 `region_id`，区域管理员按本区域读取待审批渠道商，超级管理员读取全部；审批中心以审批任务编号处理渠道商审批。
- 验收：区域管理员提交后可在本区域列表看到该渠道商；超级管理员可在渠道商审批页看到并处理对应待办。

## CP-04：回归验证

- 状态：已完成。
- 验收：执行 API 类型检查、前端语法和类型检查、差异检查，以及 V2 兼容接口完整回归；新增真实登录态用例覆盖区域管理员提交、列表可见、超级管理员审批和状态回写。
- 回退：先确认没有 `pending` 或 `rejected` 渠道商，再执行本任务的数据库回退脚本并回退代码。
