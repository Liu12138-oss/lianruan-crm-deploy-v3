# 全业务链 54 项复测缺陷收口修改方案

> 由 hgrill-bug 流程依据前序测试证据与本轮用户“继续”指令整理，术语表见仓库 `docs/CONTEXT.md`。

## Problem Statement（问题陈述）

测试环境完成全业务链人工复测后，仍有审批中心成功操作返回 404、渠道成员驳回状态与原因不可见、V2 兼容接口业务错误被页面泛化、超大附件被 Nginx 英文页面拦截、证书缺少版本时提示偏技术化等问题。另有工作台首屏加载时间较长，过早截图会把真实数据误判为全 0。上述问题会误导用户对业务是否成功、账号是否驳回及上传限制产生错误判断。

## Solution（解决方案）

- 审批中心：以审批记录编号处理审批后，仍能读取到对应审批详情，接口返回成功且页面不再误报失败。
- 渠道成员：驳回账号在渠道成员列表中展示“已驳回”和驳回原因；驳回账号尝试登录时显示与审批结果相关的中文提示。
- 通用接口错误：前端兼容业务接口返回字符串错误与对象错误两种结构，优先展示后端中文业务提示。
- 附件上传：Nginx 放宽至略高于业务上限的请求体限制，使 10MB 业务校验由应用返回中文提示，而不是由网关返回英文 413。
- 证书操作：缺少或非法数据版本时提示“数据版本信息缺失，请刷新页面后重试”，不再暴露技术字段名。
- 工作台复测：等待全量业务数据加载完成后再读取 KPI，并以接口总数核对页面数值。

## 涉及模块（Implementation Impact）

- 接口层：审批详情查询兼容审批记录编号；渠道成员状态映射；账号停用登录提示；组织证书版本校验提示。
- 前端：通用业务请求错误解析；渠道成员驳回状态与原因展示；报价编辑入口对不存在或无权访问的报价给出明确提示。
- 部署层：测试环境 Nginx 请求体限制与配置重载。
- 业务逻辑：不改变既有审批状态机、渠道数据范围、报价定价和证书生命周期，只修正返回结果与用户可见文案。

## Compatibility（兼容性分析）

- 审批接口仍同时支持审批记录编号和业务目标编号，不破坏现有调用方。
- 渠道成员新增“已驳回”状态只影响展示，不改变数据库既有状态码。
- 错误结构兼容不会改变成功响应契约。
- Nginx 限制调整只增加 multipart 余量，应用仍保持 10MB 的正式业务上限。
- 不修改数据库结构，不需要数据迁移。

## Acceptance Criteria（验收标准）

- [x] 渠道商、渠道成员审批通过或驳回均返回 200，目标状态、审批事件和审计日志同步生效。
- [x] 驳回成员在渠道成员接口和页面显示“已驳回”及原因；登录失败提示不误称普通停用。
- [x] 重复手机号等 V2 兼容接口错误在页面展示明确中文业务原因。
- [x] 超过 10MB 的附件由应用返回中文大小限制提示，不再出现 Nginx 英文 413 页面。
- [x] 证书缺少版本时返回面向业务用户的中文提示，正常延期与撤销仍成功。
- [x] 工作台完成加载后 KPI 与真实接口总数一致，无占位 0。
- [x] 54 项用例逐项给出通过或受限通过结论，报告不含测试账号口令。

## Regression Scope（回归范围）

- 审批中心待审批、已审批、渠道商审批、渠道成员审批。
- 客户报备审批、订单审批、报价审批状态流。
- 渠道成员新增、编辑、启停、密码重置与渠道端登录。
- 客户报备附件上传、产品与套餐、商机跟进、报价单、订单处理。
- 管理端与渠道端统一入口、角色分流和 403 越权拦截。
- 证书模板、颁证、延期、撤销、到期风险和组织权限范围。

## Rollback Plan（回滚方案）

代码回退到本轮修复前版本；测试环境部署前备份数据库与配置。若 Nginx 调整导致异常，恢复上一份配置并重载；若接口回归失败，仅回退对应 API 与前端构建产物。无数据库结构变更，不执行数据回退。

## Out of Scope（范围外）

- 不修改老 UI 静态页面与旧启动脚本。
- 不访问或改动生产环境及其数据。
- 不改变既有角色、区域数据范围、报价定价算法和审批状态机。
- 不清理工作区历史未提交改动。
