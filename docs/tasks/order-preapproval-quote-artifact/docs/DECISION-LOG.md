# 决策记录

## 2026-09-03：正式报价单和采购内容

- 用户确认：两个 OA 附件都上传页面点击下载得到的正式报价单；采购内容直接写软件产品、服务项明细，并包含端点数/数量和小计金额。
- 已知事实：页面下载当前为浏览器打印，Worker 没有可复用的后端下载接口。
- 采用方案：在 Worker 内实现与页面正式结构一致的确定性 PDF 成品生成，复用同一份字节内容完成两个附件上传；不使用浏览器自动化，不改变人工页面下载。
- 追加决定：页面下载也改为调用 API 服务端正式 PDF 接口，与 Worker 共享 `packages/shared` 生成器；浏览器打印仅保留报价预览展示，不再作为交付文件生成方式。
- 一致性约束：Worker 使用报价创建时间和报价快照字段生成 PDF，文件键升级为 `order-preapproval-formal-quote-pdf:<requestId>`；旧订单已经固化的旧附件不自动替换。
- 未授权事项：不部署测试或生产环境，不调用真实泛微/企微写接口，不改数据库迁移。
