# 退回订单重提权限与分销价格修复

## 目标

修复退回订单重新提交时模块单价为 0、产品引用丢失及权限误拒绝问题，保持现有二级渠道商、一级渠道商、区管、超管审批状态机不变。

## 已确认规则

1. 订单原提交人本人可以修改并重新提交。
2. 系统管理员（`admin`、`superadmin`、`region_manager`）和订单所属渠道商企业管理员（`partner_admin`）可以修改并重新提交。
3. 重提时单价按订单原提交人的渠道商分销等级、订单区域、产品数量和当前有效产品价格配置由服务端计算；不信任前端传入单价。
4. 订单提交时固化提交人、渠道商及分销等级；历史异常订单缺少快照时，按订单负责人绑定渠道商及历史扩展字段兼容恢复，并在本次重提中补齐快照。
5. 原有审批节点映射和待办流转保持不变。

## 实施边界

- 只修改 `apps/api/src/business-store.ts`、`apps/web/public/partner-app.js` 及订单重提回归测试。
- 不执行测试环境或生产数据库写操作，不改已有订单状态和金额。
- 历史有效手工明细继续保留；仅对缺少产品引用且单价为 0 的异常明细按目录恢复并重新计价。

## 验收

- 原提交人可重提退回订单；非提交人普通员工仍被拒绝。
- 系统管理员、订单所属渠道商企业管理员可重提；其他无关渠道员工不可越权。
- 一级渠道商产品按区域阶梯价计算，重提后报价与订单明细单价、小计、产品引用一致且不为 0。
- 二级、区管、超管原审批状态流转及既有测试全部通过。
