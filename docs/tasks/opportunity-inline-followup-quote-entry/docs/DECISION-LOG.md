## 2026-10-19 — 第一轮决策确认

- 问了什么：确认跟进入口与字段、阶段推进与商机编辑、报价单弹窗动作、取消报价列表的范围。
- 定了什么：
  - 选择 `1A`：商机列表提供可展开的快速跟进，商机详情「跟进」页签提供完整表单和历史时间线；字段为跟进方式、本次沟通内容、下一步计划、下次跟进时间。
  - 选择 `2A`：删除商机详情顶部「编辑商机 / 推进阶段」「记录跟进」「创建报价单」三个按钮；跟进表单可选同步推进阶段，选择新阶段时必须填写变更原因；基本商机资料在「档案与审计」内维护。
  - 选择 `3A`：点击商机关联报价单打开弹窗，展示报价摘要、状态、金额、端点数与明细，并按权限提供修改、提交、确认、驳回、打印和转订单。
  - 选择 `4A`：取消渠道端「报价管理」菜单和独立报价列表，`/quote` 统一回到商机列表；报价查看走商机弹窗，新建和编辑完成后回到对应商机。
  - 一级导航中「渠道」移动到「消息」之后、「配置」之前；超管和渠道端一级导航统一放大字号、加粗并增加项间距。
- 否了什么：不保留顶部三个商机操作按钮；不让报价卡继续跳报价列表；不把独立报价列表作为正式入口。
- 权衡了什么：取消独立报价列表后，必须把报价状态动作收进报价弹窗，否则会丢失提交、确认、驳回与转订单闭环；阶段推进收进跟进表单后，需要保留变更原因审计。
