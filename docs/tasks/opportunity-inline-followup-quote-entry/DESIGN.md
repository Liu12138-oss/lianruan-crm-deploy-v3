# 商机直接跟进与报价弹窗 修改方案

> 由 hgrill-feature 访谈自动生成，来源：`docs/tasks/opportunity-inline-followup-quote-entry/docs/DECISION-LOG.md`。术语表见仓库 `docs/CONTEXT.md`。

## Problem Statement（问题陈述）

当前新 UI 的商机跟进需要跳到客户跟进页，商机顶部又集中放置编辑、推进阶段、记录跟进和创建报价按钮，操作路径分散；商机报价卡点击后会跳到独立报价列表，创建或编辑报价后也固定返回报价列表。用户希望以商机为中心完成跟进和报价操作，同时减少商机详情顶部的重复按钮。

## Solution（解决方案）

1. 商机列表不提供「快速跟进」；选择商机后统一在详情内登记跟进，避免列表与详情出现两套入口。
2. 商机详情固定为「跟进、报价、订单、档案与审计」四个页签，默认进入「跟进」，不再展示「概览」。
3. 原「概览」中的商机编号、客户、状态、概率、金额、负责人、渠道商、关联报价、停滞天数、最近更新和下一步建议统一并入右侧「业务状态」。
4. 商机详情「跟进」页签内提供完整跟进表单和历史时间线；历史记录展示阶段、跟进方式、操作人、时间、本次沟通内容和下一步计划。
5. 商机详情顶部删除「编辑商机 / 推进阶段」「记录跟进」「创建报价单」三个按钮。
6. 跟进表单增加可选的「同步推进阶段」：不选择时只记录跟进；选择新阶段时必须填写变更原因，服务端写入阶段历史与审计。
7. 基本商机资料在「档案与审计」页签内维护，不占用详情顶部操作区。
8. 点击商机关联报价卡打开报价弹窗，展示报价摘要、状态、金额、端点数和明细，并按权限提供修改、提交、确认、驳回、打印和转订单。
9. 创建或编辑报价成功后返回来源商机并预选该商机；取消独立报价列表正式入口，`/admin/quote` 与 `/partner/quote` 回到商机列表。
10. 管理端一级导航顺序调整为「渠道」位于「消息」之后、「配置」之前；一级导航统一放大字号、加粗并增加项间距。

## 涉及模块（Implementation Impact）

- 数据层：不新增表、不做数据库迁移。跟进阶段、跟进方式、下一步计划写入 `crm.opportunity_followups.extra_json`；下次跟进时间写入 `next_action_at`；跟进时间使用 `followup_at`。商机查询补充跟进历史聚合，旧记录缺少阶段时从 `crm.opportunity_stage_history` 按跟进时间回推。
- 接口层：沿用商机更新接口，新增可选的跟进方式、下一步计划与下次跟进时间输入；响应中的商机记录补充跟进历史数组。报价继续使用既有状态更新、PDF、转订单接口。
- 前端：
  - 商机详情新增直接跟进表单、历史时间线和可选阶段推进；商机列表移除快速跟进入口。
  - 删除「概览」页签，将商机信息与下一步建议并入右侧「业务状态」。
  - 四个页签的内容面板统一左右边距，与上方页签和阶段条对齐。
  - 商机详情增加报价弹窗并删除顶部三个旧按钮。
  - 报价创建/编辑页调整返回路径和提交后落点。
  - 管理端顶部导航重排；管理端与渠道端一级导航调整样式。
- 逻辑：商机跟进保存后刷新对应记录；可选阶段与跟进在同一事务中更新；报价状态动作沿用既有服务端状态机与权限；报价列表路由改为回商机列表。

## Compatibility（兼容性分析）

- 存量数据：旧跟进记录缺少阶段或跟进方式时，阶段按阶段历史回推，页面以「商机跟进」和已有内容、时间、操作人降级展示；无需数据迁移。
- 存量调用方：商机更新接口新增字段均为可选，不破坏原有调用；阶段推进仍要求变更原因。
- 第三方对接：接口路径与既有报价 PDF、订单创建契约不变。
- 需要跟随更新：相关前端单元测试、商机接口集成测试、导航测试、报价入口测试与测试环境复测。

## Regression Scope（回归范围）

- 商机：列表筛选、搜索、区域筛选、选择商机、新建商机、详情跟进保存、阶段推进、审计留痕。
- 报价：从商机创建报价、编辑报价、报价弹窗、提交、确认、驳回、打印、转订单。
- 订单：报价转订单后进入订单中心，原订单审批链路不受影响。
- 导航：管理端一级/二级导航、配置浮层、渠道端一级导航、1280 与 1600 宽度布局。
- 权限：超管、区管、渠道管理员只能看到各自范围内商机与报价；渠道账号不能看到内部审核动作。

## Rollback Plan（回滚方案）

- 代码：回退本次改动并重建镜像。
- 数据：新增跟进字段写入既有 JSON 与时间列，无结构变更；回滚后历史数据仍保留，旧页面可继续读取最近跟进内容。
- 部署：恢复上一稳定镜像标签并重启 API、Worker、Nginx。

## Out of Scope（范围外）

- 不恢复独立报价列表为正式业务入口。
- 不修改老 UI，不操作生产环境。
