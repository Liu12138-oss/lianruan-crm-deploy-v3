# 新 UI 客户报备来源、查重审计与订单质保改造方案

> 由 hgrill-feature 访谈自动生成，来源：docs/tasks/customer-registration-source-order-warranty/docs/DECISION-LOG.md。术语表见仓库 docs/CONTEXT.md。

## Problem Statement（问题陈述）

新 UI 的客户报备仍包含客户等级、预计金额和预计签约时间，所属行业与企业规模为自由输入；客户名称相近时只提示不拦截，统一社会信用代码重复也没有服务端强制校验，更没有留下冲突审计。客户报备不能同时登记项目信息并在审批通过后自动形成商机。客户质保仍保存在客户级字段，无法反映每笔订单各自的质保和维保责任，客户列表也无法提前提示订单即将过保或已经过保。

## Solution（解决方案）

1. 客户查重以客户为主：客户名称按去除空白、忽略大小写后的规范化值完全一致，或统一社会信用代码去除空白、统一大写后完全一致，即判定冲突。服务端在事务内加锁复核并拒绝报备，同时把本次提交的全部报备字段、冲突客户和冲突字段写入审计；操作审计页可查看本周冲突汇总。该周报属于管理配置能力，仅超级管理员可访问，区管和渠道账号返回 403。
2. 报备表单删除客户等级、预计金额和预计签约时间；所属行业、企业规模、客户来源改为下拉选择。企业规模补齐 `500-1000人` 档，客户来源与商机来源共用同一组选项。
3. 报备表单增加可选的“同时报备商机”，采集项目名称、预计端点范围、申请保护期和项目备注。报备审核通过后，系统在同一事务中自动创建关联商机并把报备标记为已转商机；重复审批不会重复创建。
4. 客户级质保从新 UI 停止使用。每笔订单保存质保起始日、质保到期日、维保起始日、维保到期日四个日期，默认按订单确认日期和报价收益计算中的质保、采购维保年限自动带出；区管、超管可手工修改，手工值不再被自动计算覆盖，并写入订单审计。
5. 客户列表中的非取消订单条目按质保到期日着色：剩余 0 至 30 个自然日为黄色，已过期或到期日为当天之前的记录为红色；客户生命周期根据全部有效订单汇总显示在保、断保或未建立质保。

## 涉及模块（Implementation Impact）

- 数据层：订单表新增质保、维保起止日期和手工维护标记；存量订单按已有报价收益年限与确认时间回填；客户信用代码增加规范化查询索引，不修改历史客户质保数据。
- 接口层：报备创建和资料更新增加服务端查重与冲突审计；报备审核通过时自动创建可选商机；新增订单质保维护接口和报备冲突周报接口；订单列表返回质保日期。
- 前端：新建客户页调整字段、下拉选项和可选商机区；客户管理页移除客户级质保编辑，增加订单质保展示、维护入口和到期着色；操作审计页增加本周查重冲突汇总；新建商机页补充商机来源选项。
- 逻辑：查重、审计、审核与商机创建保持同一事务；订单质保自动值可被人工覆盖；所有写操作遵守现有账号数据范围与角色权限。

## Compatibility（兼容性分析）

- 存量客户级质保字段保留在报备扩展数据中，不做删除和错误迁移；新 UI 不再读取或写入，历史数据仍可由数据库和审计追溯。
- 存量订单在迁移时按最新报价收益计算记录回填四个日期；缺失计算记录时按默认质保 3 年、采购维保 0 年处理。
- 已有报备、商机、订单接口字段继续返回，新增字段为可选扩展；老 UI 不修改、不重新构建。
- 自动创建商机只处理显式勾选“同时报备商机”的新报备；历史报备不会在后续查看或重新保存时自动补建商机。
- 冲突审计包含业务字段，不写入登录凭据、密码或附件二进制内容。

- 权限：超管、区管、渠道管理员、渠道员工的数据范围与订单质保维护权限。
