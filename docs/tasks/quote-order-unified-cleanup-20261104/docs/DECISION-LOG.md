# 决策日志

## 2026-11-04 — 问题定位与处理口径

- 已知事实：
  - 测试环境真实点击时浏览器报错 `s.出货金额.trim is not a function`，请求未发出。
  - 新建报价初始化逻辑会主动选择第一个套餐。
  - `/unified` 仍是独立布局路由。
- 用户决定：
  - 新建报价默认没有任何功能和模块。
  - `/unified` 若属于测试页面则直接去掉。
- 本轮方案：
  - 出货金额统一字符串化，并把异常提示收口到用户可见位置。
  - 仅保留地址栏显式 `packageId` 的预选能力，移除所有“默认第一个套餐”逻辑。
  - 删除 `/unified` 页面与路由；状态页回站点根路径；登录分流忽略历史 `/unified` 权限。
- 不做事项：
  - 不修改老 UI/V2。
  - 不操作生产环境。
  - 不新增数据库迁移。
