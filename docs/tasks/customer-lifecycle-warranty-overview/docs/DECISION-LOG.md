## 2026-10-19 — 第一轮访谈结论（用户确认）

- 问了什么：质保期字段形态、在保/断保判定、生命周期激活条件、业务概况口径与交互、右栏范围、表单对齐位置、标题字体范围。
- 定了什么：
  - 质保期维护「起始日 + 到期日」两个字段；在保/断保按到期日判定；客户有非取消订单时生命周期第 7 步点亮。
  - 业务概况订单口径：排除「已取消」订单；商机口径：全部关联商机（含已成交），金额按预计金额。
  - 条目列表固定高度可滚动，点击弹出摘要弹窗，弹窗内提供「查看完整详情」跳转。
  - 右栏删除「当前状态 / 关联商机 / 建议动作」，保留「最近动态」。
  - 表单错位位置：新建商机页「当前阶段」下拉框撑破两列网格，压住右侧「端点数量」标签（用户截图实锤）。
  - 标题字体：全站将未加粗的字段标签（表单 label、信息项标签）加粗到 700，字号维持现有四档规范。
- 否了什么：未采纳「标题统一放大一号（12px）」；未采纳「质保期限自动从订单计算」。
- 权衡了什么：生命周期第 7 步采用「有非取消订单即进入」的简化口径，避免引入交付状态机改造；质保期采用新增可选字段，不做历史迁移。
- 工程备注：技能模板中的 JVM/Native 交付阶段不适用于本项目（TypeScript + Docker 单机部署），以 V3 的类型检查、构建、接口/权限测试、测试环境部署与 Playwright 复测替代。
