# 客户生命周期质保与业务概况增强 修改方案

> 由 hgrill-feature 访谈自动生成，来源：docs/tasks/customer-lifecycle-warranty-overview/docs/DECISION-LOG.md。术语表沿用仓库既有中文业务术语。

## Problem Statement（问题陈述）

当前新 UI 的客户管理存在六个问题：

1. 客户全生命周期最后一步固定为「持续运营」，无法体现客户当前处于质保期内（在保）还是质保已失效（断保）；客户档案无质保期字段，也无法手动维护。
2. 客户列表每条记录都展示「已通过 / 已驳回」状态徽标，信息冗余。
3. 客户档案中的「业务概况」只有关联商机数和报备状态，缺少订单与商机的数量、金额，也无法直接查看对应订单/商机。
4. 客户详情右栏的「当前状态 / 关联商机 / 建议动作」与中间档案重复，占用版面。
5. 新建商机页两列表单中，「当前阶段」下拉框撑破网格列宽，压住右侧「端点数量」标签与输入框，视觉错位。
6. 表单字段标签、信息项标签字号与正文相同且未加粗，标题层级不够清晰。

## Solution（解决方案）

1. 客户档案新增「质保起始日」「质保到期日」两个可维护字段；客户档案在客户管理页通过弹窗维护，保存后原位刷新当前客户详情，不离开当前客户。客户档案展示「质保期：起始日 至 到期日」，未设置时显示「未设置」。生命周期第 7 步按到期日动态显示「在保客户」（到期日 ≥ 今天）或「断保客户」（已过期或未设置）；客户存在非取消订单时，第 7 步作为当前阶段点亮，否则维持原有阶段推进逻辑。
2. 客户列表仅对「待审核」展示状态徽标，已通过、已驳回不再展示徽标；顶部统计卡保持不变。
3. 业务概况新增四个指标：订单总数、订单总金额、商机数、商机金额；订单与商机各以固定高度、纵向滚动的条目列表展示；点击条目打开摘要弹窗，弹窗内提供「查看完整详情」跳转对应业务页面。
   - 订单：按客户关联的全部非取消订单统计；金额取订单总额。
   - 商机：按客户关联的全部商机（含已成交）统计；金额取预计金额。
4. 删除客户详情右栏的「当前状态 / 关联商机 / 建议动作」三块，保留「最近动态」。
5. 两列表单网格改为可收缩列（`minmax(0, 1fr)`），表单控件与字段容器允许收缩，消除下拉框撑破网格导致的错位；新建商机页与全站同类表单同步生效。
6. 全站未加粗的字段标签（表单 label、信息项标签）统一加粗到 700，字号维持 22/16/23/11 四档规范；已加粗标题不变。

## 涉及模块（Implementation Impact）

- 数据层：不新增表、不做数据迁移。质保起始日/到期日写入客户报备 `extra_json` 的新键，旧数据缺省为空。
- 接口层：复用现有客户报备资料更新接口与列表查询接口，不改变接口契约；前端在保存客户档案时提交两个新字段。
- 前端：
  - 客户管理页：生命周期第 7 步文案与当前阶段计算、列表徽标、业务概况指标与滚动条目、订单/商机摘要详情弹窗、客户档案编辑弹窗、右栏精简。
  - 客户跟进页：保留档案摘要、关联商机选择、跟进记录与时间线；不再重复提供「报备商机」「编辑客户档案」入口。
  - 新建商机页及全站表单：网格与标签样式修正。
- 逻辑：客户与订单/商机按 `customer_id` 关联聚合；在保/断保按到期日与当天比较。

## Compatibility（兼容性分析）

- 存量数据兼容：质保字段为可选新增键，旧客户显示「未设置」并按断保处理；不修改既有保护期字段。
- 存量调用方：接口契约不变，其他页面不受影响。
- 第三方对接：无影响。
- 需要跟随更新：客户管理页的订单查询使用既有订单列表接口，遵循现有账号数据范围与权限。
