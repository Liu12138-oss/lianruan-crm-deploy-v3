# 决策记录

## 2026-09-08：冲突范围与处理方式

- 用户确认同时处理同名不同登录账号和企业微信 `UserId` 冲突。
- 完全相同的 V3 登录账号继续由数据库唯一约束拒绝，不新增重复账号创建能力。
- 同名不同登录账号不自动归并；沿用既有“明确选择保留账号、交接当前业务、停用来源账号”的规则。
- 企业微信身份冲突采用“定位、原因、二次确认、停用旧有效映射、创建新有效映射、审计”的受控校正，不物理删除、不自动按姓名转移。
- 文件内重复或格式错误仍由映射文件维护人修正，系统不做猜测性自动清理。

## 2026-09-08：本地验收结果

- 已执行真实 PostgreSQL 集成验证：同名不同登录账号可识别；企业微信身份校正会停用旧有效映射、创建目标账号新映射并保留审计；重新预览显示已一致。
- 已执行 API 全量回归 157 项、前端全量回归 109 项、类型检查、静态检查、格式检查和全量构建，均通过。
