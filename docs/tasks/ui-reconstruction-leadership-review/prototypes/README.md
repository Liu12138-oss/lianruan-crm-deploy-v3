# UI 重构原型方案

本目录包含三套基于现有《联软渠道管理平台 UI 重构领导评审稿》扩展的概念原型。每套原型均连续展示渠道管理、商机管理和订单管理，不涉及真实业务逻辑、接口或权限调整。

## 原型入口

- `index.html`：三套方案索引
- `01-command-center.html`：深蓝指挥台
- `02-insight-workspace.html`：轻量洞察工作台
- `03-process-canvas.html`：流程画布

## 共同口径

- 数据均为演示数据，不代表正式统计口径。
- 登录、角色、权限、数据范围、业务字段、状态机和接口契约保持不变。
- 三套方案使用相同的业务信息结构，差异集中在导航、信息密度、分析区域和流程表达。
- 当前版本只用于方向评审，不能直接作为正式开发或发布依据。
