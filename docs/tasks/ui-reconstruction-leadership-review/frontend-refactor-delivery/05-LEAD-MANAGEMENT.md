# 线索管理模块落地文档

## 1. 定位

线索管理是独立一级业务板块，与客户管理、商机作战平级。第一版只做前端 UI，不接真实业务数据、不接爬虫、不建立客户或商机联动。

## 2. 页面

- 线索列表。
- 线索详情。
- 数据来源与采集状态。
- 关注、忽略、备注和导出窗口。
- 客户与商机关联预留说明窗口。

## 3. 第一版范围

只做：

- 关键词和组合筛选。
- 线索详情展示。
- 来源、附件、变更和抓取时间展示。
- 关注、忽略、备注和导出。
- 来源状态和采集日志展示。
- 角色和字段权限控制。

不做：

- 客户或商机关联。
- 创建客户、商机或报价。
- 修改线索原文。
- 爬虫配置、调度和外部数据接入。
- 投标过程管理。

## 4. 前端数据方案

后端未完成前使用 `mock repository`，但组件不得直接引用静态数组。推荐接口：

```text
LeadRepository.list(query)
LeadRepository.detail(id)
LeadRepository.followState(id, input)
LeadSourceRepository.list()
LeadSourceRepository.runs(sourceCode)
```

组件只依赖 Repository，后续替换为真实 API 时不改页面结构。

## 5. 状态

来源状态：

`enabled / paused / running / partial_failed / failed`

线索状态：

`new / closing / expired / changed / cancelled`

处理状态：

`unread / following / ignored`

关联状态第一版固定为 `reserved`，不可操作。

## 6. 权限

- 超管：全量查看、来源管理。
- 区域管理员：绑定区域查看，来源只读。
- 普通管理员：按权限和范围。
- 渠道管理员：授权范围查看，不进入来源管理。
- 渠道员工：按权限查看，默认不可管理来源。

## 7. 分辨率

- 筛选区、列表和右侧预览保持三栏。
- 1280px 以上不折行。
- 表格允许容器内部横向滚动，页面整体不使用折行布局。
- 操作列和状态标签禁止换行。

## 8. 测试

- 搜索、组合筛选、分页和排序。
- 各角色菜单、字段和动作可见性。
- 关注、忽略和备注状态。
- 关联区域必须不可用。
- 来源失败、部分失败和任务日志。
- 1366 / 1440 / 1600 / 1920 视觉回归。

## 9. 后续预留

- 线索详情右侧保留客户与商机关联区域。
- 第一版没有关联写接口和候选对象。
- 后端完成后新增关联动作，不改变线索主数据归属。
