# 原型画板逐页对齐报告（r14）

对齐日期：2026-09-24

测试环境：`http://10.9.86.66`

Web 镜像：`lianruan-crm-v3-nginx:3.0.0-stage10.20260924-prototype25`

## 1. 问题定性

需求负责人反馈「格式、内容、排版与原型不一致」。量化核对后确认根因：之前只对齐了组件类型，没有对齐原型的**固定画板几何**。

修复前实测（客户管理，1600×1000 视口）：

| 指标 | 原型 | 修复前 |
| --- | --- | --- |
| KPI 区 | 1398×96 | 1508×84 |
| KPI 卡片宽 | 225px | 243px |
| 三栏列宽 | 304 / 792 / 342 | 304 / 860 / 342 |
| 三栏高度 | 560（固定，列内滚动） | 24173（被内容撑开） |
| 整页滚动高 | 画板固定 740 | 24469 |

## 2. 修复措施

1. 新增统一画板样式 `apps/web/src/styles/war-artboard.css`：
   - `war-artboard`：1440 画板居中、六指标固定 96px、三栏固定 304 / 自适应 / 342、**列内滚动**、整页不被内容撑高；窗口更窄时横向滚动且不换行。
   - `war-artboard-plain`：线索、证书、组织这类专属结构页面统一画板宽度与内边距。
2. 补齐原型列表头的**区域范围过滤**下拉（客户 / 商机 / 报价 / 订单；渠道页原型无此项，已按原型移除）。
3. 工作台按原型专属布局重做：指标区 + 两栏（业务趋势 / 我的待办）+ 通栏「最近业务」，不再是三栏。
4. 卡片与页签按原型口径调整：
   - 渠道：页签「全部 / 核心渠道 / 待续签」，卡片「等级 · 区域 · 负责人」+ 合作状态徽标 +「X 人 / Y 项证书」+ 动作行（查看档案 / 成员维护）。
   - 报价：页签「全部 / 待确认 / 折扣待审」，卡片 meta 改为「报价号 · 客户/项目」。
   - 商机：页签「全部 / 重点商机 / 停滞风险」。
   - 订单：卡片标签收敛为 2 个短标签（避免换行导致高度差）。
5. 管理配置中心按原型改为**左中右三栏**（左配置入口 / 中说明 / 右权限边界）。

## 8. 窄屏裁切修复与表单页补齐（同批次）

**问题**：应用外壳最小宽度 1280px，而画板写死 1440px → 在 1280 / 1366 / 1440 分辨率下右栏被挤出可视区（实测 1366 时右栏右边界 1468 > 视口 1366）。

**修复**：画板改为 `width: min(1440px, 100%)`、`min-width: 1180px`，宽屏最大 1440、窄屏自适应收窄。实测：

| 视口 | 画板宽 | 三栏列宽 | 右栏完整可见 |
| --- | --- | --- | --- |
| 1280×800 | 1224 | 304 / 576 / 342 | 是 |
| 1366×768 | 1310 | 304 / 662 / 342 | 是 |
| 1440×900 | 1384 | 304 / 736 / 342 | 是 |
| 1600 / 1920 | 1440 | 304 / 792 / 342 | 是 |

**表单页补齐**（此前仍是旧版工作区）：从 `ui-demo/demo.css` 抽取 53 条表单/向导/报价构建器样式（`war-form.css`），并按原型实现三个页面：
