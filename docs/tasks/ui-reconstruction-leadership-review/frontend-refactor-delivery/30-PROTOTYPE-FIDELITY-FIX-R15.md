# 测试环境 UI 与原型一致性修复（r15）

修复日期：2026-09-29

验收环境：`http://10.9.86.66`（测试环境，唯一发布目标）

原型基准：`docs/tasks/ui-reconstruction-leadership-review/ui-demo/index.html` + `VISUAL-RULES.md`

生产环境 `10.20.3.10` 未连接、未修改。

## 1. 结论

需求负责人反馈「测试环境 UI 与原型图不一致」**属实**，且主因是**应用外壳与画板几何整体偏移**，不是配色或组件细节问题。

修复后，19 个管理端业务页的画板宽度、六项指标区坐标与尺寸、三栏区坐标与列宽**与原型逐项一致**（画板内相对坐标完全相等）。

## 2. 根因

| 项 | 修复前 | 原型 | 说明 |
| --- | --- | --- | --- |
| 页内面包屑行 | 存在，48px | **不存在**（VISUAL-RULES §3.6 明确禁止） | 把整页内容下推 48px |
| 页面内容内边距 | `24px 28px 32px` | 0（画板直接铺满） | 画板被压窄 56px |
| 画板宽度 | 1384px | 1440px | 由上一项导致 |
| 六项指标区 | 顶 10、左 20、宽 1344 | 顶 74、左 21、宽 1398 | 由前两项导致 |
| 三栏区 | 顶 116、宽 1384、高 620 | 顶 181、宽 1438、高 560 | 由前两项导致 |
| 三栏中栏宽 | 736px | 792px | 由画板宽度导致 |
| 顶部导航高 | 64px | 62px | 独立差异 |

一句话：实现多了一行面包屑、外层又多了一层内边距，导致画板比原型窄 56px、内容整体下移。

## 3. 本次修复

### 3.1 应用外壳（全局生效）

- `apps/web/src/styles/theme.css`
  - 顶部导航高度 `64px → 62px`（含 `grid-template-rows` 与内容区 `min-height` 联动）。
  - 顶部导航左右内边距 `22px → 28px`（对齐 `visual-ui.css .top-nav`）。
  - 删除 `.v2-页内标题栏` 样式；新增 `.v2-页面内容:has(> .vui.war-artboard…) { padding: 0 }`，仅对画板页取消外层内边距，非画板页（导入页、消息设置页等）保持原内边距不变。
- `apps/web/src/layouts/AdminLayout.vue`、`apps/web/src/layouts/PartnerLayout.vue`
  - 移除页内标题栏（含面包屑与右下角「修改密码」）。
  - 「修改密码」入口迁入顶部导航用户区，功能不变（沿用 `V2TopActions` 的密码弹窗）。

### 3.2 画板几何（`apps/web/src/styles/war-artboard.css`）

按原型 `demo.css` / `visual-ui.css` 的固定画板重写：

- 画板：`1440 × 740`（内容盒）+ `1px #cadbed` 边框 + `14px` 圆角 + 画板底色。
- 六项指标区：`padding-top: 73px`、`margin: 0 20px`、高 `96px`、固定六列、间距 `10px` → 实测 顶 74 / 左 21 / 宽 1398 / 卡片宽 225。
- 三栏区：`gap: 11px` 使三栏顶部落在 180px → 实测 顶 181 / 左 1 / 宽 1438 / 高 560；列宽固定 `304 / 自适应 / 342` → 实测 `304 / 792 / 342`。
- 专属画板 `war-artboard-plain`（线索来源、证书风险、新建流程）：`padding: 73px 20px 20px` + 同款边框圆角；其内部六项指标区改为静态流式布局，修掉了原先因 `position: absolute` 导致指标区跑到画板外（实测顶 −63、左 −8）的缺陷。
