## 2. 修复内容

### 2.1 管理配置二级菜单

- `admin-navigation.ts`：`顶部导航项` 新增 `子项` 字段；「配置」挂 6 个二级菜单项（组织与账号 / 证书与风险 / 审核与业务规则 / 消息与提醒 / 操作审计 / 开放接口），每项带一句职责描述。
  - 原独立的一级菜单「审计日志」收口进「配置」，不再单独占一级菜单位。
  - 新增 `判断子项激活()` 与 `取当前一级导航()`，供顶栏与二级菜单条复用同一套激活口径。
  - 激活口径调整：`/admin/products` 一级菜单纳入 `/admin/workload-config`（产品子目录入口）；`/admin/notifications/platform`、`/admin/notifications/rules` 从「消息中心」改为归属「配置」；`/admin/platform-admin` 不再匹配 `/admin/admin-review`。
- `AdminLayout.vue`：一级导航新增下拉二级菜单浮层（悬停展开，带描述）；进入配置类页面时常驻渲染二级菜单条（`管理配置 | 组织与账号 | 证书与风险 | …`），当前项高亮。
- 组织与账号纳入管理端外壳：新增 `/admin/organization/*` 内嵌路由（与既有 `/workspace/admin/platform-admin/organization/*` 全屏工作区共用同一页面），页内栏目切换跟随当前形态，不再把用户弹出到全屏工作区。
- `PlatformCenterPage.vue`（业务全景）改写为纯业务板块：客户管理 / 线索管理 / 商机作战 / 报价管理 / 订单中心 / 渠道管理 / 产品目录 / 消息中心，含业务环节链路与进入按钮；管理配置入口全部移出，仅保留一句「管理配置在顶部『配置』二级菜单」的说明。

### 2.2 布局高度口径拆分

二级菜单条会额外占用 42px 外壳高度，而画板的「内边距扣减」只对应原型画板内的 62px 顶栏，两者不能共用一个变量：

- 新增 `--v3-board-inner-topnav-h`（无顶栏 0px、顶部导航外壳 62px，不随二级菜单条变化），`war-artboard.css` 的 `padding` / `inset` 改用该变量。
- `--v3-board-topbar-h` 继续承担高度口径，带二级菜单条时为 `62px + 42px = 104px`；`AdminLayout` 在渲染二级菜单条时挂 `v2-带二级导航` 类，同步切换网格行与画板高度。
- 修正 `.v2-一级导航` 的 `overflow-x: auto`：该滚动容器会把二级菜单浮层裁掉；顶部外壳本身 `min-width: 1280px`，实测 1280 / 1440 / 1720 下导航均不溢出，故改为 `overflow: visible`。

### 2.3 产品维护子目录

`ProductCatalogPage.vue` 由「大表 + 产品结构」改为 7 个子目录，结构与老 UI 一致，样式沿用新 UI：

| 子目录 | 内容 |
| --- | --- |
| 产品目录 | 大类卡片网格（图标、名称、描述、软件/硬件标签、N 模块、N 功能）+ 硬件产品分区；点大类 → 模块卡片 → 功能卡片三层下钻，面包屑带「← 返回」 |
| 大类管理 | 卡片网格，编辑 / 删除，`+ 新增大类` |
| 模块管理 | 大类下拉筛选 + 卡片网格（大类标签、N 功能），编辑 / 删除，`+ 新增模块` |
| 功能管理 | 模块下拉筛选 + 关键词搜索 + 卡片网格（产品编码、必选 / 待发布 / 阶梯价 / 区域覆盖标签、价格块），编辑 / 下架·发布 / 删除，`+ 新增功能` |
| 硬件管理 | 关键词搜索 + 卡片网格（型号、规格、价格），编辑 / 下架·发布 / 删除，`+ 新增硬件` |
| 套餐管理 | 关键词搜索 + 卡片网格（模块 / 功能 / 硬件数量标签），编辑 / 下架·发布 / 删除，`+ 新增套餐` |
| 工作量配置 | 展示已配置产品映射条数，跳转独立 `/admin/workload-config` |

- 区域管理员仅见「产品目录 / 推荐套餐」两个子目录，全部只读（与老 UI 的非超管口径一致）。
- 写操作仍只对超级管理员开放；删除沿用归档接口，二次确认。
- 五类新建 / 编辑弹窗（功能、硬件、套餐、大类、模块）与价格规则入口保持不变。

## 6. 风险与回退

- 风险：「配置」二级菜单目前只对超级管理员可见（沿用 `可访问管理配置`）；若后续要让区域管理员自助维护证书或消息渠道，需要单独放开角色并补回归测试。
- 风险：审核中心 `/admin/admin-review` 归属「配置」后，区域管理员进入该页面时顶部无高亮菜单项（页面本身仍可从工作台与消息中心进入）；如需恢复高亮，可为其单独保留一级入口。
- 风险：二级菜单条依赖 `--v3-board-topbar-h` 与 `--v3-board-inner-topnav-h` 两个变量，后续新增外壳层级时必须同步维护，否则画板高度或顶部留白会偏移。
- 回退：`cp compose/.env.bak-before-r30navproduct compose/.env` 后执行
  `docker compose up -d --no-deps api-1 api-2 nginx`，即回到本轮改动前的 protolign22 状态。
