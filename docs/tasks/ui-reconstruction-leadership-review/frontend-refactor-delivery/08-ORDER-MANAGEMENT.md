# 订单管理模块落地文档

## 1. 目标

订单中心负责订单审批、调价、回退修订和履约展示，不负责报价创建或报价转订单。

## 2. 页面

- 订单列表。
- 订单详情。
- 一级确认。
- 一级驳回。
- 区管确认和调价。
- 超管确认和退回。
- 回退修订申请、审核和重新提交。
- 发货、完成和取消订单。

## 3. 状态

主链包含：草稿、待一级确认、一级已确认、待超管确认、已确认、处理中、已发货、已完成。

异常链包含：一级已驳回、已驳回、退回区管修改、退回一级修改、退回二级修改、待回退修改审核、已取消、已替换。

## 4. 页面结构

- 订单编号和当前状态。
- 来源报价和版本。
- 客户、渠道和区域。
- 商品模块、数量、报价单价、订单单价和差异。
- 收货信息。
- 审批轮次和动作历史。
- 当前状态可执行动作。

## 5. 权限

- 超管、区域管理员、一级渠道和二级渠道按状态显示不同动作。
- 渠道员工只能在允许角色下查看或执行对应动作。
- 驳回和退回必须填写原因。
- 调价后重新进入超管确认。

## 6. 规则

- 订单商品和价格来自报价快照。
- 订单详情不直接修改报价明细。
- 回退修订创建新版本，不覆盖旧订单。
- 履约动作独立于审批动作。

## 7. 测试

- 主链和异常链状态。
- 每个角色可见动作。
- 重复审批和并发提交。
- 调价后流转。
- 回退修订版本一致性。
- 订单与来源报价快照。
