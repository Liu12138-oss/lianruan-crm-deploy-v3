# 审核、消息、组织与账号模块落地文档

## 1. 审核中心

### 范围

- 客户报备审核。
- 渠道准入审核。
- 员工账号审核。
- 报价折扣和状态审核。
- 订单审批入口。

### 页面

- 审核列表。
- 审核详情。
- 批量处理。
- 通过、驳回和退回窗口。

### 规则

- 所有审批动作必须显示业务上下文。
- 驳回和退回必须填写原因。
- 审批动作和订单状态动作不能混用。
- 无权限审批对象返回保护性 404。

## 2. 消息中心

### 页面

- 消息列表。
- 消息详情。
- 未读、已读和归档。
- 通知偏好。
- 站内消息与业务跳转。

### 规则

- 消息引用业务对象，不复制业务详情。
- 点击消息跳转前再次校验对象范围。
- 已删除或无权对象显示安全提示。
- 外部投递失败不回滚业务事实。

## 3. 组织与账号

### 页面

- 组织与岗位。
- 人员与任职。
- 业务角色。
- 权限角色。
- 数据范围。
- 账号生命周期。
- 外部身份映射。

### 权限

- 组织和账号能力受功能开关约束。
- 组织写关闭时页面只读。
- 停用、归档和恢复动作按专项门禁显示。
- 证书变化不自动修改业务角色和系统权限。

## 4. 证书管理

### 页面

- 证书模板。
- 持证记录。
- 颁发、延期和撤销窗口。
- 到期风险。

### 规则

- 证书与业务角色、系统权限解耦。
- 证书撤销后生成权限复核任务，不自动收回权限。
- 证书到期只告警。

## 5. 测试

- 审核动作对应业务类型。
- 消息跳转和范围校验。
- 组织只读与写开关。
- 账号归档、恢复和交接。
- 证书颁发、延期和撤销。
- 角色和数据范围变化。
