# 商机管理模块落地文档

## 1. 目标

商机是销售过程的主上下文，统一展示七阶段，并在同一工作区内承载跟进、报价、订单和审计。

## 2. 七阶段

| 阶段     | 进度    | 退出条件                       |
| -------- | ------- | ------------------------------ |
| 客户建联 | 10%     | 已联系有效客户联系人           |
| 需求挖掘 | 20%-30% | 痛点、规模、预算和技术方向明确 |
| 客户方案 | 40%     | 已形成可评审方案               |
| POC 试用 | 50%     | 已进入或完成产品验证           |
| 立项推进 | 60%-70% | 客户内部完成立项和采购推进     |
| 招投标   | 80%-90% | 进入招标、竞争性谈判或定标     |
| 成单     | 100%    | 已确认成交                     |

输单和项目取消为终止结果。

## 3. 页面

- 商机列表。
- 新建商机。
- 商机详情。
- 跟进。
- 报价。
- 订单。
- 档案与审计。

## 4. 前端阶段模型

- 统一由共享阶段字典提供标签、进度、颜色和顺序。
- 第一阶段保留旧代码到七阶段的映射，只用于展示和兼容。
- 后端代码未迁移前，新建和修改阶段不发送新的不可识别代码。
- 阶段变化只在“记录跟进”中完成，不单独提供推进按钮。

## 5. 权限

- 超管、区域管理员和渠道账号按数据范围查看。
- 阶段推进、编辑和报价动作按权限和状态控制。
- 无权限动作不显示，状态不允许时显示禁用原因。

## 6. 交互

- 列表和看板共享同一数据源。
- 当前阶段使用统一进度条。
- 跟进提交后刷新阶段、概率、下次跟进和预计成交。
- 报价版本和订单摘要只读，不复制金额和明细。

## 7. 测试

- 旧代码到七阶段的映射。
- 阶段和进度显示。
- 跟进后状态更新。
- 报价与订单关联。
- 不同角色、区域和渠道范围。
- 1280px 以下不折行。

## 8. 后续关联预留

- 商机详情预留“来源线索”区域。
- 第一版只显示空状态或“后续开放”，不提供选择线索动作。
- 不允许通过 URL 参数或前端 mock 创建正式关联。
- 后续关联上线后，只建立引用关系，不复制线索正文和附件。
