# 权限、角色与数据范围方案

## 1. 基本原则

前端只做可见性、可操作性和脱敏展示。角色、区域、渠道、对象和字段权限由服务端最终决定。

## 2. 角色

| 角色           | 主要范围                 | 重点限制               |
| -------------- | ------------------------ | ---------------------- |
| 超级管理员     | 全量业务、组织和平台配置 | 不默认代替业务经办     |
| 区域管理员     | 正式绑定区域             | 不得跨区域             |
| 普通管理员     | 权限点指定范围           | 不得使用超管配置能力   |
| 渠道企业管理员 | 本渠道企业及成员         | 不查看内部成本和收益   |
| 渠道员工       | 本人负责或授权数据       | 不查看企业其他成员数据 |

## 3. 权限控制层级

1. 路由权限：不允许进入时跳转 403 或安全首页。
2. 菜单权限：无权限菜单不显示。
3. 页面动作：无权限动作不显示。
4. 状态动作：状态不允许时显示禁用和原因。
5. 字段权限：可查看、脱敏、隐藏。
6. 数据范围：服务端按区域、渠道、组织和本人过滤。

## 4. 路由元数据

建议统一字段：

```text
需要登录
角色
权限代码
数据范围
模块
标题
描述
是否超管专属
无权限行为：隐藏 / 403 / 返回首页
```

页面不得自行解析中文角色名称判断权限。

## 5. 菜单和按钮

- 无权限动作默认不显示。
- 有权限但当前状态不允许时显示禁用，并给出原因。
- 高风险动作只允许在明确权限和状态下显示。
- 批量动作必须显示选中数量和影响范围。

## 6. 字段脱敏

- 手机号默认 `138****6621`。
- 邮箱按权限显示完整、部分或隐藏。
- 统一社会信用代码按业务范围展示。
- 内部成本、底价和收益只对授权内部角色返回。
- 渠道端和 OpenAPI 永不返回内部成本和收益。

## 7. 区域和数据范围

- 超管可切换全量或指定区域。
- 区域管理员只能使用绑定区域。
- 渠道企业管理员只能使用本企业范围。
- 渠道员工只能使用本人范围。
- 前端传参不能扩大服务端范围。

## 8. 测试

每个页面至少测试：

- 超管。
- 区域管理员。
- 普通管理员。
- 渠道企业管理员。
- 渠道员工。
- 未登录和无权限。
- 跨区域、跨渠道和跨企业对象。
