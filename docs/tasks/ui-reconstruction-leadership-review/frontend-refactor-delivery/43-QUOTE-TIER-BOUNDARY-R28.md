## 2. 取价口径（修复后）

1. 区域覆盖优先：命中区域时用区域覆盖的阶梯 / 固定价，区域未覆盖的字段回退到全国配置。
2. 渠道等级价优先：命中区域配置或全国配置里的等级专用价（`priceForPrimary` / `priceForSecondary`）。
3. 等级专用价整组无正价（全 0 或空）时，按「基础阶梯 × 等级比例（一级默认 100%、二级默认 110%）」折算；没有阶梯时按「固定价 × 比例」折算。
4. 阶梯命中：区间内精确命中；数量超出最高档沿用最高档，低于最低档沿用最低档，并在「价格规则命中」面板输出「数量 X 超出渠道等级价最高档（a-b），按最高档 ¥ N 计价」。

- 「文档水印模块」的等级专用价在 `catalog.product_features.extra_json` 中整组为 0（全国与 4 个区域覆盖均如此），代码已按未配置兜底。如业务上需要该模块有独立的渠道等级价，请在产品目录维护 `priceForPrimary` / `priceForSecondary`（或区域覆盖内同名字段）后重新取价，无需改代码。

## 6. 风险与回退

- 风险：阶梯越界沿用最高档会让超量报价维持「量大价低」的单价，不会因超档而跳到高价档；若业务希望超档另行定价，应在产品目录补充更高数量档位。
- 风险：等级专用价整组为 0 时按比例折算，若某模块确实要「免费赠送」，需要显式把该档位配成 0 且保留其他档位正价，或在业务流程中单独处理。
- 回退：把 `compose/.env` 的 `V3_IMAGE_TAG` 改回 `3.0.0-stage10.20261008-protolign20`（前端）或 `3.0.0-stage10.20261008-protolign19`（后端）后执行
  `docker compose up -d --no-deps api-1 api-2 nginx`，即回到本轮修复前的状态。
