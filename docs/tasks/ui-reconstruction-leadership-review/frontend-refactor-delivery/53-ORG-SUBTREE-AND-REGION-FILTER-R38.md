## 1. 用户反馈与结论

| # | 反馈 | 结论 |
| --- | --- | --- |
| 1 | 组织架构点击「联软总部」这种部门，要展示当前用户及子部门用户 | 成立。左侧组织树计数（`节点成员数`）按「直属 + 子部门递归」统计，但右侧成员面板只取节点直属 `members`，导致同一屏两个口径：树上是 21 人，面板只有 10 人。 |

## 2. 实现内容

### 2.1 组织架构：部门成员改为「本部门 + 全部子部门」（`OrganizationWorkspacePage.vue`）

- 新增 `当前部门节点` 计算属性，`当前部门名称 / 当前部门含下级 / 当前部门成员` 共用一次查找。
- `当前部门成员` 改为递归收集：`收集成员(节点) = 本节点 members + children.flatMap(收集成员)`，与左侧组织树计数口径完全一致。
- `组装成员概要(成员, 所属部门)` 增加「所属部门」字段；成员卡片在概要区第一行整行显示所属部门，直属成员与子部门成员一眼可区分。
- 成员面板计数标签在含子部门时显示「共 N 名成员（含子部门）」；空态文案区分「该部门暂无成员 / 该部门及子部门暂无成员」。
- 渠道组织树（渠道侧成员面板）本轮不改，维持原有口径。

### 2.2 渠道商列表区域检索（`ChannelListPage.vue`）

- 新增 `区域文本(row)`：依次取中文键 `区域`、英文历史键 `region / regionName`，避免个别记录缺字段时漏筛。
- `区域选项` 改用 `区域文本` 生成；`过滤后列表` 在标签筛选之后增加区域过滤：`区域文本(row) === 选中区域`。
- `WarLayout` 补传 `:区域列表="区域选项"`、`:选中区域="选中区域"`、`@update:选中区域`，与客户列表完全同款；卡片 meta 与中栏标题的区域展示同步切到 `区域文本`。

### 2.3 商机列表区域检索（`OpportunityCenterPage.vue`）

- 区域取值与筛选改用 `区域文本(row)`（中文键 + 英文历史键兜底），保证区域下拉按真实数据稳定生成。
- 列表卡片 meta 由「阶段 · 客户 · 渠道」调整为「阶段 · 区域 · 客户」，与客户列表「行业 · 区域 · 渠道」的展示位置一致（渠道信息在中栏「档案与审计」完整保留）。
- 「档案与审计 → 所属区域」同步使用兼容取值，与筛选口径一致。

## 5. 口径说明与后续建议

- 「部门成员」统一为「本部门 + 全部子部门」；页面成员卡片标注所属部门，搜索在合并后的集合内生效。若后续希望只看直属成员，可在成员面板加「仅看本部门」开关，而不改变默认口径。
- 区域检索统一依赖 `区域文本` 兼容取值：新数据优先中文键 `区域`，历史数据回退 `region / regionName`；后续新增列表页接入区域检索时直接复用该写法与 `WarLayout` 三个参数即可。
- 渠道侧成员面板（渠道组织树）仍按原口径只显示该渠道商直属成员；如后续确认也要含子级渠道，再单独评估，不影响本轮内部组织口径。
