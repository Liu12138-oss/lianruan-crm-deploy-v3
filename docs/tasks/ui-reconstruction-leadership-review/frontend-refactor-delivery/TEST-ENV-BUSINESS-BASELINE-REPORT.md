## 8. 重构后对比要求

每次重构部署后应重复执行：

1. 同一套账号和路由检查。
2. 1366 / 1440 / 1600 / 1920 分辨率检查。
3. 管理端和渠道端角色范围检查。
4. 商机七阶段映射检查。
5. 报价、订单、渠道和产品字段一致性检查。
6. 消息、提醒、组织和账号异常检查。
7. 截图差异和接口失败对比。
8. 新问题使用 `templates/ISSUE-REPORT.md` 登记，修复后使用 `templates/REWORK-RECORD.md` 回归。

## 10. 结论

测试环境当前版本可以用于重构前的业务基线对比，但存在一个 P1 消息渠道接口错误、一个 P1 商机阶段模型差异和多个需要业务确认的权限及账号问题。重构前基线已可复现，重构后应使用同一套脚本和账号重复扫描，确认无遗漏后再进入最终交付。
