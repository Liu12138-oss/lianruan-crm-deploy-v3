# 客户管理与客户报备模块落地文档

## 1. 目标

客户模块承载客户报备、审核、保护期、客户档案、联系人和跟进聚合。客户跟进仍归属关联商机，不新增独立跟进事实。

## 2. 页面

- 客户列表。
- 新建客户报备。
- 客户详情。
- 编辑客户档案。
- 客户导入。
- 客户跟进。
- 跟进计划。

## 3. 状态

客户报备正式状态：

`草稿 / 待审核 / 已通过 / 已驳回 / 已取消 / 已转商机`

保护期到期是派生展示，不是独立状态。

## 4. 核心字段

- 客户名称、统一社会信用代码、行业和规模。
- 联系人、电话、邮箱和职务。
- 区域、城市、归属渠道和负责人。
- 报备来源、保护期和审核信息。
- 关联商机、报价和订单摘要。

## 5. 权限

- 超管可查看全量并执行管理动作。
- 区域管理员只处理绑定区域。
- 渠道账号只处理本渠道或本人数据。
- 手机号和邮箱按字段权限脱敏。

## 6. 动作

- 创建报备。
- 编辑客户档案。
- 审核、驳回和取消报备。
- 查看关联商机。
- 选择关联商机后记录跟进。
- 导入和导出。

## 7. 规则

- 名称和信用代码查重。
- 同一客户可存在多个商机。
- 客户跟进必须明确商机。
- 跨区域客户返回保护性 404。
- 一个客户记录不能被多个渠道重复占有。

## 8. 验收

- 报备状态和派生保护期准确。
- 客户详情字段可查看、可编辑和只读状态正确。
- 关联商机跳转正确。
- 区域与渠道隔离通过测试。

## 9. 后续关联预留

- 客户详情预留“来源线索”区域，第一版不请求真实线索数据。
- 未关联时显示空状态，不显示可执行按钮。
- 后续启用时需要服务端同时校验客户和线索范围。
- 当前页面不得伪造线索编号、来源或关联结果。
