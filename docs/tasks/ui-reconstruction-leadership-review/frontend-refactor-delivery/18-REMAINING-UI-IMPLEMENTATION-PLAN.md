## 3. 核心销售模块

### 客户

- 客户列表、详情、新建、编辑和跟进。
- 区域、渠道、保护期、联系人和关联业务。
- 权限：区管只查看本区域，渠道用户只查看本渠道或本人。

### 商机

- 列表、看板、详情、跟进和阶段历史。
- 七阶段统一展示。
- 报价页签和订单页签作为上下文入口。
- 旧阶段代码只允许映射，不允许在正式后端未迁移时产生非法写入。

### 报价

- 报价版本、明细、折扣、有效期和预览。
- 报价确认、撤回、过期和转订单。
- 转订单只能从报价上下文发起。

### 订单

- 状态对应的审批和履约动作。
- 一级确认、一级驳回、区管调价、超管确认和退回。
- 回退修订和履约动作。

## 4. 运营与平台模块

### 工作台

- 指标、业务趋势、我的待办和最近业务。
- 角色和数据范围过滤。

### 渠道

- 渠道列表、详情、核心档案、层级和成员。
- 证书与经营报表入口。
- 区管只能查看和维护本区域渠道商。

### 产品与价格

- 产品目录、模块、功能、硬件、套餐。
- 阶梯价、区域价格覆盖、渠道比例、工作量和内部成本。
- 渠道端只显示公开产品和公开价格。

### 审核、消息和组织账号

- 审核列表、详情和处理动作。
- 消息列表、详情、已读、归档和偏好。
- 组织、岗位、成员、角色、数据范围和证书。
- 组织和中账号写操作继续受功能开关约束。

## 5. 开发顺序

1. 核心销售模块：客户、商机、报价、订单。
2. 运营模块：工作台、渠道、产品与价格。
3. 平台模块：审核、消息、组织账号。
4. 公共回归：权限、字段、状态、异常和分辨率。
5. 测试环境发布与前后对比。
