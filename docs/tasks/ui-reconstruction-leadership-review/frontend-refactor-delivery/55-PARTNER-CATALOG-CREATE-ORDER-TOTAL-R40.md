| # | 反馈 | 结论 |

## 2. 实现内容

### 2.1 渠道端产品目录去价格（`ProductCatalogPage.vue`）

- 功能卡片的两处价格标签（阶梯价档数、区域覆盖数）与价格块（阶梯价明细 / 固定单价）改为仅内部管理员可见。
- 硬件卡片价格块改为仅内部管理员可见。
- 渠道端产品卡片保留：产品名称、产品编码、产品说明、模块名称与说明、必选 / 待发布业务标签。
- 超管维护页签（功能管理 / 硬件管理）的价格展示不变。

### 2.2 渠道端顶栏主操作（`PartnerLayout.vue`）

- 新增与 `AdminLayout` 同口径的 `模块主操作`：客户管理 → 新建客户、商机作战 → 新建商机、报价管理 → 新建报价；新建页本身不再显示按钮。
- 模板新增 `.v2-顶部主操作` 链接，样式沿用管理端胶囊按钮。

### 2.3 渠道端新建商机落到新 UI 专用表单（`router/index.ts`）

- 渠道端专项路由新增 `opportunity/new` → `新建商机页面`（与管理端同一套新 UI 表单），避免渠道侧继续落到通用工作区页面。
- 原有 `/partner/registration/new`（新建客户与报备）、`/partner/quote/new`（新建报价单）沿用既有专用页面。

### 2.4 订单明细总价贴底（`OrderCenterPage.vue`）

- 删除表格 `tfoot` 合计行，改为面板底部的「明细合计（总价）」条。
- 明细面板与面板体改为纵向 flex，合计条 `margin-top: auto`，在面板被同排面板拉高时依然固定在方框内最下方；管理端与渠道端同款生效。

## 4. 发布与回退

- 发布方式：`apps/web` 执行 `npm run build` → 上传 `dist-web-protolign37` → 基于 `Dockerfile.nginx-protolign37`（`FROM nginx:1.27-alpine` + `COPY . /usr/share/nginx/html`）构建 `lianruan-crm-v3-nginx:3.0.0-stage10.20261014-protolign37` → 切换 `compose/.env` 的 `V3_IMAGE_TAG` → `docker compose up -d --no-deps nginx`；api / worker 镜像同步打同名标签，保证 compose 口径一致。
- 回退：`cd /opt/lianruan-crm-v3/compose && cp .env.bak-before-r40-protolign37 .env && docker compose up -d --no-deps nginx`，即回到 R39 的 protolign36。

## 5. 口径说明

- 渠道端新建入口只放在顶栏，与老 UI 及管理端一致；列表页内不再重复放按钮，避免同一页出现两个「新建」。
- 渠道端产品目录不再出现任何价格信息（含阶梯价标签与金额）；渠道报价仍由报价单按系统计价自动计算，不受影响。
- 订单明细总价条与管理端「订单总价」字段口径一致，按明细行小计求和。
