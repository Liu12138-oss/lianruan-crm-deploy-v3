## 4. 工程改造

- 新增设计系统：`apps/web/src/styles/visual-ui.css`（由 `visual-designs/assets/visual-ui.css` 自动生成，脚本 `tools/scope-visual-ui.mjs`）。
- 新增共享组件：`WarKpis`、`WarLayout`、`WarRecordCard`、`GenericWarModulePage`。
- 新增数据兼容层：`apps/web/src/shared/format/business-format.ts`（状态/等级/金额/日期映射与空值兜底）。
- 路由修复：专项路由与通用工作区同路径重复定义导致旧页面优先匹配，已改为「专项优先、通用同路径自动剔除」。
- 分页修复：服务端 `pageSize` 上限 100，列表与 KPI 改为分页全量读取，KPI 支持取服务端总数（审计日志 1223 条）。

## 5. 后端修复（API 主线）

| 问题 | 处理 |
| --- | --- |
| 重复转单 | 改为返回 `409 V3_QUOTE_ALREADY_CONVERTED`，提示已有订单号，不再静默返回或覆盖 |
| API 镜像构建失败 | `api.Dockerfile` 补 worker 构建、`worker.Dockerfile` 补 api 构建 |
| 订单编号「不一致」 | 已定位为区管确认后切换正式编号（原编号写入 `pre_region_order_no`），订单中心同时展示两号并支持按两者检索 |
| 报价缺渠道归属时转单 404 | 主线创建报价已从商机继承渠道/区域/负责人，转单链路复验通过 |
