## 2. 修复内容

### 2.1 姓名口径（`OrderCenterPage.vue`、`OrderActionCenterPage.vue`、`business-client.ts`）

- `business-client.ts` 新增 `查询账号目录()`：分页读取 `/api/users?page=N&pageSize=100`（最多 3 页），返回 `{username, name}` 列表；账号目录对渠道账号可读，管理端与渠道端共用。
- 订单中心：新增 `账号名称` 映射与 `姓名()` 转换函数，`负责区管` 用 `regionConfirmedByUsername`、`提报人` 用 `createdByName / submittedByUsername` 转姓名；账号目录读取失败时静默回退用户名，不影响主数据。
- 订单处理页：顶部摘要「审批轮次」小字由账号改为负责人姓名，订单信息新增「签单人员 / 负责区管（仅内部管理员）/ 订单产品类型 / 报备编号」。

### 2.2 渠道层级口径（两份页面文件）

- `分销层级文本`：`primary → 一级分销`、`secondary → 二级分销`、`none → 无分销层级`，其余显示「未设置」；取值优先 `partnerLevel`，回退 `submittedPartnerLevel`。
- 订单中心标签为「渠道层级」，订单处理页顶部摘要同步替换原始值。

### 2.3 订单明细总价（`OrderCenterPage.vue`）

- 明细表新增 `tfoot`：`明细合计（总价）` 跨三列 + 金额列展示合计。
- 新增 scoped 样式 `.vui-table tfoot td`：去掉下边框、`#f4f8ff` 浅蓝底、加粗，与普通明细行区分。

### 2.4 中栏收敛为四区（`OrderCenterPage.vue`）

- 删除 R33 遗留的重复面板：「区域与审批」「交付与联系」「关联单据」以及重复的收益面板。
- 「订单信息」融合区域归属与交付联系：订单编号、前置订单编号、订单状态、订单金额、所属区域、提交区域、负责区管（仅内部）、审批轮次（仅内部）、收货地址、联系人、创建时间、最近更新。
- 「合作伙伴与签单」融合关联单据：合作伙伴、渠道层级、上级一级渠道、签单人员、提报人、订单产品类型、关联报价单、关联商机、合同编号、报备编号。
- 渠道端没有内部收益面板，故「合作伙伴与签单」在渠道端跨满整行（`面板全宽`），第二行不留半格空白。

### 2.5 内部收益核算升级为收益表（`QuoteProfitPanel.vue`、`quote-profit-client.ts`）

- 收益面板由跨两列改为中栏第四格，与「合作伙伴与签单」同排，打开订单即可看到，不需要滚到最底部。
- 四个指标卡改为 `repeat(auto-fit, minmax(150px, 1fr))`：半栏时两列、整栏时四列，数值不挤压。
- 新增「收益构成明细」（8 项）：软件折后价、软件公开价、硬件报价、硬件内部成本、产品税费、服务税费、质保成本、采购维保成本，全部来自服务端 `details`，前端不做推算。
- `quote-profit-client.ts` 修正 `details` 类型（原声明为数组，实际服务端返回对象），新增 `收益构成明细` 接口定义。

### 2.6 订单处理页排版收口（`OrderActionCenterPage.vue`）

- 「订单信息」由「标签左、值右对齐」改为「值紧跟标签左对齐」，解决宽单元格里标签与值左右分离、看起来不成对的问题。
- 字段补齐为 12 项（内部管理员），并按 2 列均分。
