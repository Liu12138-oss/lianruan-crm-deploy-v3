# 报价管理模块落地文档

## 1. 目标

报价保持独立业务实体，在商机报价页签中作为上下文呈现。客户、渠道和商机信息由关联对象带入，金额、折扣和快照由后续服务端提供。

## 2. 页面

- 商机报价页签。
- 报价详情。
- 新建报价。
- 修改报价。
- 报价确认。
- 报价转订单确认。
- 报价动作与收益。

## 3. 状态

`草稿 / 已提交 / 已确认 / 已驳回 / 已转订单 / 已取消`

报价有效期为派生展示，不伪装成独立状态。

## 4. 页面结构

- 关联客户和商机。
- 端点数量、区域和渠道层级。
- 套餐、补充功能和自定义报价。
- 软件、硬件和服务明细。
- 阶梯价和区域覆盖命中。
- 渠道价格比例。
- 报价预览和版本。

## 5. 权限

- 创建、修改、发送、确认、撤回和转订单分别鉴权。
- 渠道端不显示内部成本和收益。
- 已转订单报价只读。
- 跨区域、跨渠道报价不可编辑。

## 6. 规则

- 报价从商机创建。
- 报价转订单只从报价管理或商机报价上下文发起。
- 订单中心不提供报价转订单。
- 金额、折扣、工作量和服务费由后续服务端计算。

## 7. 测试

- 报价版本切换。
- 关联商机预填。
- 报价明细编辑。
- 转订单前置条件。
- 已转订单只读。
- 权限字段脱敏。
