# 设计系统与桌面适配方案

## 1. 目标

统一管理端、渠道端和后续移动端的视觉基础，优先保证 13 至 24 英寸电脑显示器在不同分辨率下稳定展示。

## 2. 设计令牌

| 类别     | 规则      |
| -------- | --------- |
| 主色     | `#2f69ed` |
| 主色悬停 | `#1557d6` |
| 深蓝标题 | `#17345e` |
| 成功     | `#159873` |
| 警告     | `#c58a17` |
| 危险     | `#ce4b58` |
| 流程紫   | `#7254d8` |
| 页面底色 | `#eef4fa` |

颜色只表达状态和操作层级，不用于大面积装饰。禁止以一整套紫色、深蓝、米色或橙色作为唯一视觉主题。

## 3. 字体与密度

- 页面标题：22px，700。
- 区块标题：12px，700。
- 正文与表格：9px 至 11px，400 至 700。
- 关键数字：23px 至 28px，800，使用等宽数字。
- 基础间距：4 / 8 / 12 / 16 / 20 / 24px。
- 表格行高：32px 表头，43px 数据行。
- 表单控件最小高度：34px。

字体大小不随视口宽度变化。

## 4. 布局

桌面布局由顶部导航、业务控制区、内容区和可选右侧决策区组成。

- 顶部导航高度：62px。
- 侧栏宽度：240px 至 272px。
- 列表区固定宽度：304px。
- 右侧决策区固定宽度：342px。
- 中间区域使用 `minmax(0, 1fr)`，避免表格撑破容器。

## 5. 响应式策略

| 逻辑宽度         | 策略                                      |
| ---------------- | ----------------------------------------- |
| 1920px 以上      | 内容居中，最大宽度控制在 1840px 至 1920px |
| 1536px 至 1919px | 完整铺满，扩大中间内容区                  |
| 1440px 至 1535px | 标准布局                                  |
| 1366px 至 1439px | 压缩间距和次要列，保持列结构              |
| 1280px 至 1365px | 最小完整布局，隐藏低优先级辅助信息        |
| 小于 1280px      | 保持最小结构宽度，组件内部横向滚动        |

禁止：

- 使用整页 `zoom` 缩小字体和控件。
- 根据宽度把表格改成长卡片。
- 主按钮、状态和操作列自动换行。
- 缩小浏览器时隐藏关键字段。

## 6. 公共组件

- `AppShell`：顶部导航、侧栏、内容区。
- `PageHeader`：标题、说明、主次操作。
- `MetricGrid`：固定指标卡数量。
- `FilterBar`：搜索、筛选、重置和已选条件。
- `DataTable`：固定列结构、分页、横向滚动和空状态。
- `StatusTag`：统一状态颜色和文案。
- `ActionGroup`：按钮、权限和禁用原因。
- `DetailDrawer`：右侧详情。
- `ActionModal`：审批、状态变更、关联和导入。
- `AsyncFeedback`：loading、empty、error、forbidden 和 conflict。

## 7. 页面级别

- L1：工作台、客户、线索、商机、报价、订单等主页面。
- L2：详情页、编辑页和独立配置页。
- 抽屉：列表上下文详情。
- 弹窗：动作确认和短表单。

页面、抽屉和弹窗使用同一份业务数据，不在每一层重新拼接字段。

## 8. 视觉回归

必须保存 `1366 / 1440 / 1600 / 1920` 四组基线截图，覆盖管理员、区域管理员和渠道用户。截图差异必须经确认后更新，不能自动覆盖基线。
