## 三、修复内容

### 3.1 新 UI 报备审核动作（`RegistrationReviewActions.vue` 新增）

- 待审核报备 + 内部管理员（超管 / 区管）：显示「✓ 通过报备」「✕ 驳回报备」。
- 驳回必须填写原因（留空拦截提示「请填写驳回原因，将记录在审批历史里。」）。
- 已驳回报备 + 内部管理员：显示「↻ 重新提交」，状态回到待审核。
- 已通过报备：显示「🎯 报备商机」，跳转 `${外壳前缀}/opportunity/new?registrationId=...`。
- 渠道端不渲染任何审核按钮；服务端仍会二次校验角色。
- 接入位置：客户跟进页（审核中心「处理」落地页，按钮为大尺寸）与客户管理页中栏（标准尺寸）。

### 3.2 新建商机页支持报备预选（`OpportunityCreatePage.vue`）

- 读取 `registrationId` 查询参数，在已通过报备列表中自动预选对应客户。

### 3.3 后端路由映射修复（`apps/api/src/business-routes.ts`）

- `PUT /api/registrations/:id/status` → `更新报备状态`（状态流转 + 同步 `ops.approvals`），与 `/api/v2` 兼容路由一致。
- `PUT /api/registrations/:id` → `更新报备`（资料更新，未显式传状态时保持当前状态）。
