# 渠道、成员与核心档案模块落地文档

## 1. 目标

渠道管理分为渠道主档、核心档案、层级关系、成员、证书和经营报表。成员、证书和账号身份分开维护，但共享同一企业关系。

## 2. 页面

- 渠道商列表。
- 渠道详情。
- 新增渠道商。
- 编辑渠道商信息。
- 渠道核心档案。
- 渠道画像与层级。
- 成员维护。
- 证书管理。
- 渠道经营报表。

## 3. 核心档案分组

- 工商主体。
- 经营规模与注册地址。
- 联系人与合作区域。
- 产品能力、资质与提醒。

## 4. 字段

- 企业名称、信用代码、法定代表人、成立时间和经营状态。
- 注册资本、实缴资本、年营收、员工和社保人数。
- 注册地址、经营范围、服务区域和数据来源。
- 企业管理员、渠道负责人、电话、邮箱和地市区号。
- 渠道等级、协议编号、上级渠道和分销层级。
- 主要行业、代理品牌、授权产品、资质和典型客户。
- 产品能力、评分、回款周期和授权到期提醒。

## 5. 权限

- 超管可维护全量。
- 区域管理员只维护绑定区域。
- 渠道企业管理员只维护本企业档案。
- 渠道员工无核心档案编辑权。
- 手机号和老板联系方式按字段权限脱敏。

## 6. 规则

- 渠道核心档案与成员、证书、账号分开。
- 层级关系变更保留历史。
- 证书变化不自动修改系统角色。
- 协议到期和续签是风险派生值，不是渠道主状态。

## 7. 测试

- 核心档案四组字段完整。
- 列表、详情、画像页均可进入档案维护。
- 成员添加、编辑、停用、重置密码和证书。
- 渠道区域范围和字段脱敏。
- 层级绑定和多上级关系。
