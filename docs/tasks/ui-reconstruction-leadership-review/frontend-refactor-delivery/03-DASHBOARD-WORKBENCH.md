# 工作台模块落地文档

## 1. 目标

工作台用于展示当前用户可访问的业务概况、待办和最近变化，不复制各业务详情页。指标口径未确认的数据先显示占位，不输出正式转化率。

## 2. 页面结构

1. 页面标题和当前数据范围。
2. 六项指标卡：客户报备、商机、报价、订单、渠道和产品。
3. 业务趋势。
4. 我的待办。
5. 最近业务。
6. 快捷入口。

## 3. 权限

- 管理员看到全量或授权范围。
- 区域管理员只看到绑定区域。
- 渠道企业管理员看到本企业数据。
- 渠道员工看到本人数据。
- 无权限模块不显示指标和入口。

## 4. 交互

- 点击指标进入对应业务列表并带入筛选。
- 待办直接进入对应详情或审批动作。
- 最近业务保留跳转关系。
- 加载失败时显示局部错误，不影响其他区域。

## 5. 指标规则

- 数量指标必须注明统计范围和更新时间。
- 趋势和转化率未确认口径时显示“口径待确认”。
- 金额按服务端返回和统一格式化规则显示。

## 6. 分辨率

- 六项指标在 1280px 以上保持六列。
- 小于 1280px 时缩小间距，不折成两行。
- 趋势和待办面板保持等高、顶部和底部对齐。

## 7. 验收

- 不同角色只看到授权数据。
- 指标、待办和最近业务跳转正确。
- 无数据、加载失败和口径未确认状态完整。
- 1366 / 1440 / 1600 / 1920 宽度不换行。
