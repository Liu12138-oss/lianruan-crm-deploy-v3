## 1. 本轮交付范围

本轮补齐了之前标记为未完成或只有通用工作区的正式前端页面与动作窗口：

- 客户跟进与客户档案编辑。
- 渠道成员新增、编辑、启停和密码重置。
- 订单一级确认、一级驳回、区管确认、区管调价、超管确认、超管退回、修订重新提交和履约状态动作。
- 产品模块价格规则，包含基础阶梯价、一级/二级渠道比例和区域价格覆盖。
- 证书与风险，包含证书模板、持证记录、延期、撤销和到期风险。
- 消息渠道配置和提醒规则与模板页面。
- 商机详情创建报价时自动带入当前商机编号。
- 报价发送、撤回、确认和转订单动作。
- 管理配置中的证书、消息和提醒规则正式入口。

## 7. 已确认的后端接口问题

以下问题属于当前测试环境既有后端能力，不在本轮前端 UI 代码内直接修改，但前端已提供错误提示和结构保留：

- `GET /api/messages/platform/channels` 返回 500。
- `GET /api/messages/rules` 返回 404。

这两个问题已记录在测试结果中。后端接口恢复后，无需改动页面结构即可重新验证配置读取、编辑和保存链路。

## 8. 回滚

如需回滚测试环境 Web：

```bash
cd /opt/lianruan-crm-v3
sed -i 's/^V3_IMAGE_TAG=.*/V3_IMAGE_TAG=3.0.0-stage10.20260923-uirefactor9-backup-r10/' compose/.env
docker compose --env-file compose/.env -f compose/docker-compose.yml up -d --no-deps --force-recreate nginx
```

回滚只影响 Web/Nginx，不影响 API、Worker、数据库、Redis 和业务数据。
