## 1. 用户反馈与结论

| # | 反馈 | 结论 |
| --- | --- | --- |
| 1 | 新建或修改报价单，点了套餐之后勾选的报价模块就消失，变成「桌面管理模块」和「网络准入控制模块」 | 成立。这两块正是默认套餐「远程办公」的 2 个功能：只要触发一次套餐应用，用户已勾选内容就会被整表覆盖。 |
| 2 | 「点了套餐」后套餐没有变成选中的那个 | 成立。套餐卡片的点击只重算了模块，从未写回 `选中套餐`：高亮仍停在第一个套餐，试算与提交带的 `packageId` 也是第一个套餐，与界面显示不符。 |
| 3 | 与旧 UI 报价业务逻辑不一致 | 成立。旧 UI 用三份互不干扰的清单记账：套餐内功能（来自套餐 `featureIds`）、补充功能加选、自定义勾选；切换报价方式只切换入单口径，不会清空用户清单。新 UI 只有一份扁平 `选中产品`，任何一次模式切换/套餐应用都会整表重算。 |

## 2. 修复内容（`QuoteCreatePage.vue`）

### 2.1 按报价方式拆成三份清单

- 新增 `补充功能选择`、`自定义选择` 两个独立清单（外加 `自定义已引导` 标记）。
- 新增派生值：
  - `套餐内产品编号`：套餐 `featureIds`（V2 功能编号）解析到产品目录后的产品 id 列表；
  - `选中产品`（改为 computed）：套餐报价＝套餐内；补充功能＝套餐内＋补充加选（自动去重）；自定义报价＝完全按自定义勾选。
- 效果：切换报价方式只改变入单口径，各模式的勾选互不覆盖，切回即恢复（对齐旧 UI）。

### 2.2 套餐点击真正选中

- `应用套餐(编号)` 现在写回 `选中套餐` 再试算；同时不再重建 `选中产品`（由套餐内清单派生）。
- 效果：高亮跟随点击，试算与提交的 `packageId` 与实际选择的套餐一致；补充加选与自定义勾选保持不变。

### 2.3 模式切换不再重算覆盖

- `切换报价方式(方式)` 只设置模式并试算：进入套餐报价/补充功能时若无套餐则默认第一个（与旧 UI 一致）；首次进入自定义报价时用当前报价内容引导一次，之后完全以用户勾选为准。

### 2.4 移除与勾选按模式落到对应清单

- `切换产品(编号)`：自定义报价写 `自定义选择`，补充功能写 `补充功能选择`，套餐报价下直接忽略（套餐内模块固定）。
- `移除模块(项)`：按模式从对应清单移除；`可移除()` 与 `是否锁定()` 口径统一——补充功能下套餐内模块同样属于标准组合，不允许单独移除（旧 UI 同口径）。

### 2.5 编辑态明细回填 id（连带修复）

- 存档报价的 `items` 只保存名称与金额，没有产品 id，导致编辑态点击「＋/−」提示「模块数量必须是大于 0 的整数。」且数量不变、模块也没有「×」移除按钮。
- 新增 `按名称找产品编号()`：明细缺 id 时按模块名称在产品目录回填 id。
- 编辑态回填位置也改为按模式分派：自定义报价 → `自定义选择`；补充功能 → 套餐外部分进 `补充功能选择`；套餐报价 → 由套餐还原。

## 5. 口径说明

- 套餐报价：只出套餐内功能，套餐内模块固定，不能在报价单里增减；
- 补充功能：套餐内功能 + 手动加选功能，加选可逐个移除；
- 自定义报价：不受套餐约束，全部功能自由增减；首次进入用当前报价内容引导一次；
- 三份清单互不覆盖，切换报价方式或更换套餐都不会清空用户已勾选内容。
