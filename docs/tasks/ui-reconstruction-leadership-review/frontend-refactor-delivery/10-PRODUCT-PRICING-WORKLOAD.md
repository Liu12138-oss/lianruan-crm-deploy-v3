# 产品、价格与工作量模块落地文档

## 1. 目标

统一展示产品目录、套餐、价格规则、区域覆盖、人天规则和成本配置。前端只负责配置和展示，正式金额和规则由后续服务端计算。

## 2. 页面

- 产品目录。
- 产品详情。
- 产品新增和编辑。
- 套餐维护。
- 模块价格规则。
- 区域价格覆盖。
- 工作量配置。
- 硬件成本规则。

## 3. 价格规则

- 固定价。
- 阶梯价。
- 一级渠道价格比例。
- 二级渠道价格比例。
- 区域价格覆盖。
- 价格生效时间和版本。

区域价格优先于全国默认价，渠道比例在区域规则之后应用。

## 4. 权限

- 超管可维护全量产品和价格。
- 区域管理员只查看授权产品。
- 渠道用户只看公开产品和公开价格。
- 内部成本、底价和收益对渠道端与 OpenAPI 永不返回。

## 5. 交互

- 产品类型、产品线、状态和关键词筛选。
- 价格规则直接在产品上下文中查看和维护。
- 区域覆盖显示区域、阶梯、单价、渠道比例和状态。
- 工作量规则与产品、交付标签和数量区间关联。

## 6. 测试

- 产品类型切换。
- 阶梯和区域覆盖展示。
- 渠道比例和区域优先级。
- 工作量规则切换。
- 渠道端公开字段过滤。
