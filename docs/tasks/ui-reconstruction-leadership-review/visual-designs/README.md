# UI 重构视觉稿

本目录是基于原《联软渠道管理平台 UI 重构领导评审稿》和两张业务界面参考图重新制作的视觉稿。每套方案均包含渠道管理、商机管理和订单管理三个完整界面，方案 02 在此基础上补充客户管理、报价管理界面，以及三类新建流程表单。

## 方案

- `versions/01-list-workspace.html`：宽表工作台，参考图 1 的六项指标、筛选栏和高密度表格。
- `versions/02-war-room.html`：三栏作战室，采用参考图 2 的左侧列表、中间流程和右侧决策面板，并在顶部保留参考图 1 的六项指标卡；界面覆盖客户管理、商机作战、报价管理、渠道管理、订单中心，并附加新建客户报备、新建商机、新建报价单三类表单原型。
- `versions/03-brand-hybrid.html`：品牌融合版，保留原评审稿的品牌蓝与侧栏体系，同时吸收参考图的高密度布局。

当前内容仅用于视觉评审，业务字段、数据、权限和状态机均不代表正式实现口径。

导航首项已按评审口径统一为「客户管理」，客户管理、报价管理与新建流程的字段同样为演示数据，仅用于确认交互位置和信息结构。

## 业务链路口径

原型按现有 V3 业务主链路组织：客户报备 → 商机 → 报价单 → 订单，各环节前置条件保持一致：

- 新建客户报备：客户名称支持工商信息查询回填，提交后进入厂商运营审核，审核通过进入报备保护期。
- 新建商机：商机必须关联已审批的报备客户；同一客户可创建多个商机。
- 新建报价单：必须选择已报备客户，并至少关联一个商机；金额、折扣、税费与价格版本由服务端试算，页面不提交金额字段。

参考图的版式拆解与修改依据见 `REFERENCE-ANALYSIS.md`。
