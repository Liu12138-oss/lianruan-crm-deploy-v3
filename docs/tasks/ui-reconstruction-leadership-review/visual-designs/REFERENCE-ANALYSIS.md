# 参考图拆解与原稿修改依据

## 参考图 1

- 页面类型：客户线索/客户列表型工作台，强调大规模数据处理。
- 结构：顶部横向主导航，下方六项核心指标，再向下是视图切换、区域与属性筛选、宽表列表和分页。
- 视觉：近白色到浅蓝的渐变背景，白色内容面板，细边框，弱阴影，蓝色用于选中和关键动作。
- 组件：六等分指标卡、分段切换、横向筛选器、紧凑表格、状态标签、批量操作、分页。
- 可用规律：把“总量、重点、状态和转化”放在首屏；筛选与列表保持同一工作平面；通过列宽和状态色提高扫描效率。

## 参考图 2

- 页面类型：商机作战型工作台，强调单条业务的流程和决策上下文。
- 结构：左侧业务列表，中间流程与详情，右侧业务状态、智能输出和辅助信息。
- 视觉：主背景为白色和浅蓝，蓝色仅用于当前阶段、关键数字和主操作；面板之间使用细边框区分。
- 组件：左侧选中卡片、顶部业务标题、横向七步流程、字段信息卡、跟进说明、AI 建议、案例或辅助信息。
- 可用规律：列表负责切换对象，中间负责推进流程，右侧负责解释当前状态和下一步动作，三层之间不重复信息。

## 对原评审稿的修改

1. 保留原稿的联软品牌蓝 `#2F69ED`、亮蓝 `#55C8FF` 和深蓝 `#17345E`。
2. 将原稿偏展示型的卡片视觉，收敛为更适合业务操作的高密度工作台。
3. 参考图 1 转为宽表工作台方案，统一渠道、商机、订单的指标、筛选和批量处理结构。
4. 参考图 2 转为三栏作战室方案，统一列表、阶段流程和右侧决策信息的结构。
5. 在两种参考方向之间增加品牌融合版，保留原评审稿侧栏体系，同时采用参考图的信息密度。
