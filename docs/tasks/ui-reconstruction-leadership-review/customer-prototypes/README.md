# 客户管理视觉原型

本目录基于现有 `02-war-full.png` 的三栏作战室方向，补充客户管理、客户新增和客户跟进三张桌面端视觉原型。原型复用原有品牌色、顶部导航、六项指标卡、左侧业务列表、中间业务上下文和右侧决策面板。

## 原型文件

- `index.html`：可交互的原型审查页，三张画板连续展示。
- `screenshots/customer-management.png`：客户管理总览。
- `screenshots/customer-create.png`：客户新增与报备表单。
- `screenshots/customer-followup.png`：客户跟进工作台。

## 设计口径

- 客户管理采用“客户列表 + 客户全景 + 状态与建议”的三栏结构，兼顾批量查找和单客户上下文。
- 客户新增按“客户主体信息、联系人与需求、归属与保护、资料附件、确认提交”组织，工商查询结果用于自动回填。
- 客户跟进采用“待跟进列表 + 跟进阶段与历史记录 + 本次跟进录入”的结构，突出逾期提醒、下一步动作和最近跟进结果。
- 金额、折扣、区域、渠道和权限不作为页面自由输入项，正式实现仍应由服务端会话和业务规则决定。

## 待确认边界

当前 V3 的正式跟进记录主要关联商机。本原型为了评审客户运营体验，将“客户跟进”设计为客户级活动记录，并允许后续关联商机、报价和订单。正式开发前必须确认以下事项：

1. 客户级跟进记录是否独立于商机跟进记录。
2. 同一客户多个商机之间是否共享跟进时间线。
3. 客户跟进是否允许没有关联商机时创建。
4. 客户级跟进记录是否参与消息提醒、待办、审计和数据范围计算。

本目录内容仅用于视觉与信息架构评审，不代表接口契约、权限规则、状态机和数据模型已经调整。
