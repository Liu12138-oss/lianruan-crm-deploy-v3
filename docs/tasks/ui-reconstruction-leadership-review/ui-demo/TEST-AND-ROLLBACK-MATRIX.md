# V3 测试、验收与回退矩阵

更新日期：2026-09-21

## 1. 测试门禁

### 1.1 通用命令

在仓库根目录执行：

```bash
npm run build
npm run check
npm test
npm run test:e2e
npm run verify
git diff --check
```

分工作区执行：

```bash
npm run check --workspace=@lianruan/web
npm test --workspace=@lianruan/web
npm run test:e2e --workspace=@lianruan/web
npm run check --workspace=@lianruan/api
npm test --workspace=@lianruan/api
npm run check --workspace=@lianruan/worker
npm test --workspace=@lianruan/worker
npm run check --workspace=@lianruan/mcp
npm test --workspace=@lianruan/mcp
npm run test:protocol --workspace=@lianruan/mcp
npm run test:redclaw --workspace=@lianruan/mcp
npm run check --workspace=@lianruan/contracts
npm test --workspace=@lianruan/contracts
```

### 1.2 强制门禁

1. 认证、权限、数据范围、审计、幂等和状态机必须先通过。
2. 正式页面、渠道端和移动端都要使用同一业务状态和接口契约。
3. 金额、折扣、工作量、收益和订单总额必须由服务端计算。
4. 外部失败不得回滚已提交订单、合同、审批和业务状态。
5. 未完成开关、迁移、回退和监控证据的功能不能开启。

## 3. 权限、字段和拒绝行为

| 用例                             | 角色              | 期望                              |
| -------------------------------- | ----------------- | --------------------------------- |
| 超管访问全量业务                 | 超管              | 允许，但组织写仍受功能开关        |
| 区域管理员访问区域内订单         | 区域绑定管理员    | 允许                              |
| 区域管理员访问其他区域订单       | 区域绑定管理员    | `403` 或保护性 `404`              |
| 普通管理员访问工作量配置         | 普通管理员        | 不允许                            |
| 渠道账号读取内部成本             | 渠道管理员 / 员工 | 字段隐藏或接口拒绝                |
| 渠道账号读取其他渠道成员         | 渠道账号          | 拒绝                              |
| 停用账号使用旧 Cookie 和页面令牌 | 停用账号          | 立即 `401`，不允许失效开放        |
| 账号状态服务异常                 | 任意账号          | 返回 `503`，不得放行              |
| 组织写关闭时调用写接口           | 超管              | 固定拒绝，不能只隐藏按钮          |
| MCP 伪造主体断言                 | 未授权客户端      | `401` / `403`，不泄露对象         |
| MCP 超范围查询                   | 有效用户          | 范围进入 SQL 条件，返回授权内结果 |

## 4. 状态机和幂等测试

| 模块         | 关键用例                               | 通过标准                                 |
| ------------ | -------------------------------------- | ---------------------------------------- |
| 客户报备     | 重复提交、审核、驳回、过期             | 重复被唯一约束或幂等拒绝；驳回原因必填   |
| 商机         | 七阶段映射、阶段切换、负责人变化、关闭 | 旧代码稳定映射；非法跳转拒绝；历史不覆盖 |
| 报价         | 草稿、发送、确认、撤回、过期、转订单   | 已转单不可改；重复转单拒绝；快照稳定     |
| 订单         | 一级、区管、超管、退回、调价、履约     | 每个动作只接受允许的前置状态             |
| 回退修订     | 申请、批准、驳回、重新提交             | 新版本递增；原订单和外部事实保留         |
| 渠道成员     | 编辑、停用、逻辑归档                   | 多渠道关系时账号不误停用                 |
| 渠道核心档案 | 查询、保存、区域和角色权限、字段审计   | 查看和编辑分权；空值不伪造；版本冲突明确 |
| 证书         | 颁发、延期、撤销                       | 重复操作幂等；不联动业务角色             |
| 消息规则     | 保存、保护规则、版本冲突               | 保护规则不可删除；旧版本冲突明确提示     |
| 组织交接     | 重复提交、Worker 重领、租约恢复        | 只执行一次；失败可补偿；历史事实不变     |

并发写请求至少验证：

- 两个请求携带相同 `Idempotency-Key` 和相同请求体，第二个回放第一次结果。
- 同一幂等键携带不同请求体，返回冲突。
- 两个请求携带旧 `expectedRowVersion`，只有一个成功。
- 审批和状态更新使用条件更新，不能覆盖较新的状态。

## 7. 组织和 MCP 测试

### 7.1 组织

- 迁移正向、回退、重复执行和依赖顺序。
- 组织树循环、父子关系、渠道域隔离。
- 组织写开关、只读观察、状态防护和交接开关组合。
- 账号归档、恢复、归并、离职交接和接收人失效。
- 证书不自动修改业务角色、系统权限或数据范围。
- 企微同步只写预览事实，`apply` 和 `pause` 在未授权时固定拒绝。
- 旧 Cookie、正式页面令牌、移动端令牌和 V2 页面令牌的失效一致性。

### 7.2 MCP

- 默认关闭时不注册真实业务工具。
- `server/discover`、`tools/list`、`tools/call` 和协议版本一致。
- 未知字段、未知工具、非法分页和超时范围被拒绝。
- 内部和渠道用户工具列表不同。
- `tools/call` 每次重新校验权限、范围和字段。
- 审计不可用时拒绝业务工具调用。
- MCP 关闭、停止或容器异常不影响 V3 主业务。
- MCP 进程不能访问业务主库、Redis 主状态和 Docker 套接字。
- 关闭总开关后工具不可见，审计记录和诊断信息保留。

## 9. 视觉和可访问性测试

- 1440px、1200px、1920px 截图对比。
- 顶部导航、六项指标、三栏布局和表格不换行。
- 所有按钮、标签和状态在固定容器内不溢出。
- 弹窗、抽屉、表格、筛选和分页具备稳定尺寸。
- 键盘可以完成焦点移动、确认、取消和关闭。

## 11. 模块回退矩阵

| 模块         | 触发条件             | 回退动作                                                      | 数据影响                               |
| ------------ | -------------------- | ------------------------------------------------------------- | -------------------------------------- |
| 管理端 UI    | 页面主链回归失败     | 回退 Web 静态资源或隐藏新入口                                 | 不改业务数据                           |
| 客户与商机   | 权限或范围越界       | 关闭新入口，恢复旧页面                                        | 保留报备和商机事实                     |
| 报价         | 金额、快照或转单异常 | 停止新报价动作，恢复旧报价页                                  | 已生成报价和订单保留                   |
| 报价收益     | 收益计算或冻结异常   | 关闭收益 Worker 和入口                                        | 未冻结记录标 `void`；已冻结快照保留    |
| 订单         | 审批链或快照错误     | 回退订单 UI/API，不自动改状态                                 | 保留状态历史和修订事实                 |
| 订单预审 OA  | 外部调用不确定       | 关闭 Worker，人工确认                                         | 不改订单状态，保留发起事实             |
| 消息 Worker  | 重复、错投或积压     | 关闭消息 Worker，保留站内查询                                 | 保留已投递和失败事实                   |
| 外部消息通道 | 凭据、退信或投诉     | 停用对应通道                                                  | 站内和其他通道不受影响                 |
| 组织只读     | 数据隔离或权限异常   | `V3_ORGANIZATION_ENABLED=false`                               | 组织数据保留，正式主链继续             |
| 组织写入     | 写入一致性异常       | `V3_ORGANIZATION_WRITE_ENABLED=false`                         | 保留已写事实和审计                     |
| 停用交接     | 旧会话或交接异常     | `V3_ORGANIZATION_OFFBOARDING_ENABLED=false`，状态防护保持开启 | 已停用账号不恢复；已完成迁移不自动反转 |
| 企微同步     | 差异或对账异常       | `V3_DIRECTORY_SYNC_ENABLED=false`                             | 只关闭新任务，保留批次事实             |
| MCP          | 越权、泄露或负载异常 | `V3_MCP_ENABLED=false`，关闭 Nginx MCP 路径并停止容器         | 不回退 CRM 数据，保留审计              |
| 合同收款     | 业务规则或财务异常   | 关闭模块入口和写接口                                          | 保留草稿、迁移和审计；不删财务事实     |
| 公海与报备池 | 领取冲突或归属异常   | 关闭领取和入池任务                                            | 客户主档不变，保留池历史               |

## 12. 回退证据

每次回退必须保存：

- 触发原因、时间和操作人。
- 受影响版本、配置和功能开关。
- 回退前后的请求编号和健康状态。
- 四端登录和主业务回归结果。
- 未回退的数据事实和后续处理责任人。
- 是否恢复外部任务领取、定时任务和用户入口。

## 13. 完成定义

模块只有在同时满足以下条件时才能标记完成：

- 代码、契约、迁移和配置齐全。
- 权限、范围、状态、幂等和审计测试通过。
- 四端关键路径回归通过。
- 视觉和可访问性检查通过。
- 目标环境或隔离环境有验收证据。
- 回退开关、脚本、责任人和演练记录齐全。
- 文档、截图、风险和残留项已更新。
