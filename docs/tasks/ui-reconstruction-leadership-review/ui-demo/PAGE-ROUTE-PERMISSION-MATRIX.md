## 2. 角色代码和范围

| 角色           | 代码                                    | 数据范围                                     | 典型限制                             |
| -------------- | --------------------------------------- | -------------------------------------------- | ------------------------------------ |
| 超级管理员     | `superadmin`                            | 全量业务、组织、权限、审计和系统配置         | 不代替法务、财务、销售完成全部经办   |
| 区域管理员     | `admin + region_manager / 正式区域绑定` | 绑定区域的客户、报备、商机、报价、订单和渠道 | 不得跨区域；工作量配置限超管         |
| 普通管理员     | `admin`                                 | 角色权限点和指定范围                         | 不拥有平台级配置能力                 |
| 渠道企业管理员 | `partner_admin`                         | 本渠道企业全部成员及业务数据                 | 不查看成本、收益、组织权限和其他渠道 |
| 渠道员工       | `staff`                                 | 本人负责、创建或参与的业务                   | 不查看本企业其他成员数据             |
| 审核人员       | 显式审批权限                            | 被授权业务类型和审批范围                     | 不能通过列表猜对象是否存在           |

高权限字段：

- `internal_cost`、收益金额和硬件成本规则只允许区管、超管访问。
- `contact.phone`、`contact.email` 按角色字段权限返回；无权限时脱敏或隐藏。
- OpenAPI 和渠道端永不返回成本和收益。
- 组织写、数据范围写、MCP 配置和系统恢复均要求超级管理员及显式权限。

## 10. 路由与权限门禁

1. 页面可见不代表接口有权，接口必须再次校验角色和数据范围。
2. 组织只读、组织写入、状态防护、离职交接和目录同步是五个独立门禁。
3. 组织写入关闭时，所有写动作只能返回预览或固定拒绝，不得只隐藏按钮。
4. 区域筛选只对超管展示并缩小用户主动查询范围。
5. 渠道端和 OpenAPI 不得通过接口字段、导出或附件泄露内部成本。
6. 新页面不得绕过 `entry-target.ts` 的正式落点规则。
7. 路由迁移必须保留旧入口重定向或功能开关回退。
