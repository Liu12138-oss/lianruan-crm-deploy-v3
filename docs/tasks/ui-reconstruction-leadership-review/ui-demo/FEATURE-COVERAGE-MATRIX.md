# V3 全量 UI 功能覆盖矩阵

## 1. 使用说明

本矩阵用于核对当前交互原型、设计文档和现有 V3 正式页面之间的覆盖关系。

状态定义：

- `已覆盖`：仅表示原型中有独立页面或关键窗口，且文档已描述主要交互，不代表代码已实现或生产已启用。

模块成熟度、功能开关和生产门禁以 `MODULE-STATUS-AND-SCOPE-MATRIX.md` 为准。

本矩阵不是业务实现清单，而是 UI 原型补齐清单。当前 201 项已全部标记为 `已覆盖`，并由 56 个主页面截图、96 个关键窗口截图和 `PROTOTYPE-EVIDENCE.json` 作为核对证据。

### 1.1 测试环境核对

核对时间：2026-09-20。

核对对象：`http://10.20.3.10/admin.html`、`http://10.20.3.10/partner.html`、移动一期和移动二期源码。

测试环境确认到的实际管理端菜单：

- 工作台。
- 商机管理。
- 客户报备。
- 报价管理，目标 UI 中改为商机内报价上下文，旧入口保留兼容。
- 订单管理。
- 产品目录。
- 经营报表。
- 渠道商管理。
- 企业管理员。
- 审核中心。
- 账号管理。
- 操作日志。
- OpenAPI 对接。
- 消息渠道配置。
- 提醒规则管理。
- 组织架构：组织与成员、证书管理、角色管理、权限与范围、离职交接、企微同步、外部身份映射。
- 工作量配置。

代码核对确认到的管理端路由还包括：

- 客户、商机、渠道和员工四类导入。
- 组织账号编辑、归档、恢复、归并和企微身份校正。
- 渠道层级管理和渠道画像。
- 消息模板、任务模板、提醒任务和消息渠道投递状态。
- 证书模板、持证记录、证书延期和撤销。
- 产品大类、模块、功能、硬件和套餐的新增、编辑、发布和删除。

上述入口已全部纳入当前交互原型。测试环境只做只读路由和菜单核对，未执行写操作；自动化和测试环境调用均控制在每分钟 30 次以内。
