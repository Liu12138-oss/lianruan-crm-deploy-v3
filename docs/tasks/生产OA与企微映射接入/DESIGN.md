## 导入规则

1. 预检默认执行，输出每个范围内账号的企微和泛微处理结果，且通过事务回滚保证零写入。
2. 企微正式映射写入 `iam.external_identities`，`provider_code='wecom'`。
3. OA 发起人泛微正式映射写入同表，`provider_code='eteams'`；只接受 Excel“姓名、账号”与生产参考表中同一姓名、同一来源账号同时严格匹配的记录。该规则适用于 V3 登录名与外部账号不同的历史账号。
4. 固定群成员只要求企业微信映射；OA 发起人同时要求企微和泛微映射。用户明确指定的 `zhanhuaiyu` 虽非当前 OA 发起人，也同时导入两类映射。
5. 任何姓名缺失、同一 V3 账号多条有效身份、既有映射与来源冲突或外部编号被其他账号占用，均视为阻断项。写入模式拒绝部分导入。
6. 写入必须指定启用的超级管理员作为审计操作者，并逐条写入 `audit.audit_logs`。

## 回退

不删除身份记录。若发现身份录入错误，仅由超级管理员将错误泛微映射按现有受控流程停用，并在核验后建立正确映射；企微映射须先完成影响核对后再做定向修正。订单预审任务保持关闭，直到映射、区域值和外部参数全部通过验证。
