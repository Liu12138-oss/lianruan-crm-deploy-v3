# 工作台待办溢出与客户报备商机失败修复方案

## 问题陈述

测试环境发现两个直接影响新 UI 基本可用性的缺陷：

1. 工作台“我的待办”中的客户名称过长时，待办卡片向右撑出左侧面板，状态标签和后续内容被挤出可视区域。
2. 客户列表点击“报备商机”并填写端点数量后提交，页面提示 `端点数量.trim is not a function`，没有发出 `/api/opportunities` 请求。

## 根因

1. 客户报备商机弹窗的端点数量使用 `<input type="number">`，Vue 会把输入值转换为数字；提交代码仍按字符串调用 `.trim()`，因此运行时抛错。
2. 待办卡片处于弹性布局中，标题和卡片没有设置 `min-width: 0`，长标题无法进入省略号收缩路径，实际宽度超过父面板。

## 修复方案

1. 报备商机提交时按数值字段处理端点数量，空值按 `0` 处理，不再对数字调用字符串方法。
2. 仅在 `DashboardPage.vue` 收紧待办卡片及其父级的可收缩约束；标题保持单行省略，状态标签保持不收缩。样式作用域限制在工作台，不影响其他页面。
3. 增加静态回归断言和真实浏览器布局断言，防止同类运行时错误和溢出再次出现。

## 影响范围

- `apps/web/src/features/customer/CustomerManagementPage.vue`
- `apps/web/src/features/dashboard/DashboardPage.vue`
- `apps/web/tests/`

老 UI、V2、生产环境、接口契约和数据库表结构均不修改。

## 验收标准

- 端点数量填写数字后提交，不再出现 `.trim is not a function`，请求正常到达 `/api/opportunities`。
- 端点数量留空时仍可提交，不出现前端异常。
- 超长待办标题不会撑破左侧面板，标题显示单行省略号，状态标签完整可见。
- Web 单元测试、类型检查、构建和 Playwright 用例通过。
- 修复版本部署到测试环境后，真实页面复测通过，并完成渠道管理、产品目录、消息中心与全业务链检查。

## 回滚方案

发布前备份测试环境部署配置和当前镜像标签；如复测失败，仅将测试环境 Web/Nginx 镜像切回发布前标签，不修改数据库与生产环境。
