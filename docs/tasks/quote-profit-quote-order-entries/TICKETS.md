## 2. 任务

### QP-OE-01：方案与决策记录

状态：已完成。

产物：

- `docs/tasks/quote-profit-quote-order-entries/DESIGN.md`
- `docs/tasks/quote-profit-quote-order-entries/docs/DECISION-LOG.md`

### QP-OE-02：共享收益面板

状态：已完成（2026-09-18）。

实施内容：

1. 在 `apps/web/public/admin-app.js` 中新增共享 `QuoteProfitPanel` 组件。
2. 封装角色显隐、收益加载、状态标签、缺失规则、错误降级和草稿/重算操作。
3. 支持只读模式和非正式快照提示。

验收标准：

- 组件支持报价详情和订单详情两种上下文。
- 订单只读模式不渲染编辑和冻结操作。
- 现有接口与金额展示口径不变。

### QP-OE-03：报价管理详情接入

状态：已完成（2026-09-18）。

实施内容：

1. 在 `QuoteList` 报价详情弹窗打印区域外接入共享收益面板。
2. 以当前报价单编号加载收益。

验收标准：

- 超管和所属区域区管可见。
- 打印预览不包含收益区块。
- 未转单和已转单报价均可查看当前收益状态。

### QP-OE-04：订单详情只读接入

状态：已完成（2026-09-18）。

实施内容：

1. 在 `OrderList` 订单详情接入共享收益面板。
2. 使用订单关联报价编号请求收益，`readonly` 固定为真。
3. 冻结前展示“非正式快照”，冻结后展示“正式快照”。

验收标准：

- 订单详情不出现年限输入和收益修改按钮。
- 订单未确认或收益不完整时仍能展示当前结果和缺失原因。
- 收益接口失败不影响订单详情和订单操作。

### QP-OE-05：商机报价详情复用

状态：已完成（2026-09-18）。

实施内容：

1. 用共享收益面板替换商机报价详情中的重复内联收益状态、模板和函数。
2. 保持原入口、操作和展示文字兼容。
3. 管理员页面启动时静默刷新 `/api/v2/auth/me`，修复旧缓存区域为空导致区管收益面板隐藏的问题。

验收标准：

- 现有商机报价详情功能不回归。
- 页面不再维护两套收益加载逻辑。
- 旧区管缓存能在接口成功后恢复区域信息并显示收益。

### QP-OE-06：自动化与功能验证

状态：已完成（2026-09-18）。

实施内容：

1. 扩展 `apps/web/tests/quote-profit-entry.test.ts`，覆盖三个入口、只读订单和非正式提示。
2. 新增 Playwright 静态管理员页面测试，使用模拟接口验证报价管理、订单详情入口和旧区管缓存刷新。
3. 执行 Web 测试、类型检查、构建和 Playwright 专项测试。

验收标准：

- 自动化断言能区分报价可编辑模式和订单只读模式。
- 模拟接口返回成功后，两个详情弹窗均展示内部收益核算。
- 构建产物包含共享组件和正确入口。

验证证据见 `docs/VERIFICATION-RECORD.md`。

## 3. 阻塞与回退

- 后端接口、数据库和 Worker 不在本轮修改范围。
- 若发现接口权限或订单报价关联异常，停止前端继续扩展并单独记录。
- 回退仅需撤回前端组件与接入，不影响历史收益和正式快照。
