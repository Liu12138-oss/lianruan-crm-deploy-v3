# H5移动端一期商机跟进与报价转订单交付验收记录

## 一、交付范围

本次仅交付移动端一期能力，不改动电脑端业务流程，不开放移动端新建报价、编辑报价、报价试算、报价确认、调价、取消、退款等二期能力。

已纳入一期：

1. 渠道账号在手机端商机详情中新增商机跟进。
2. 渠道账号在手机端将已确认报价转为订单。
3. 管理员手机端保持审批和业务查看，不提供上述渠道写入入口。

## 二、访问和角色

同一移动端入口按账号角色展示不同界面：

- 渠道账号：`mobile.html?scope=partner#/login`
- 管理员账号：`mobile.html?scope=admin#/login`

渠道账号可看到商机跟进和已确认报价转订单操作。管理员账号只看到业务详情和审核能力，不显示渠道侧写入表单。

## 三、后端交付内容

新增一期接口：

1. `POST /api/mobile/opportunities/:id/follow-ups`
   - 仅渠道员工、渠道管理员可调用。
   - 复用移动端登录令牌识别当前账号。
   - 校验当前账号是否有权查看该商机。
   - 跟进内容必填，最长五百字。
   - 写入商机跟进记录，并更新最后跟进时间。

2. `POST /api/mobile/quotes/:id/convert-order`
   - 仅渠道员工、渠道管理员可调用。
   - 仅允许状态为“已确认”的报价转订单。
   - 已转单或已有订单的报价禁止重复转单。
   - 手机端只填写交付联系人、联系电话、交付地址、发票抬头、订单备注。
   - 订单金额、产品、终端数量等信息全部来自已确认报价快照，手机端不允许改价或改产品。
   - 转单成功后报价状态更新为“已转订单”，并记录转订单编号。

## 四、前端交付内容

1. 商机详情新增“新增跟进”表单。
2. 报价详情在“已确认且未转单”状态下显示“转为订单”表单。
3. 报价已转订单后显示已转单提示和订单编号。
4. 订单详情补充展示联系人、联系电话、发票抬头、订单备注。
5. 管理员业务详情保持只读，不出现渠道写入表单。

## 五、二期收敛状态

二期写入能力当前不纳入本次上线范围。

当前收敛方式：

1. 二期接口默认仅查询开放，写入默认关闭，必须服务端显式配置功能开关才会开放。
2. 订单调价、取消、退款在移动端继续关闭。
3. 新建报价、报价试算、折扣审批、报价确认等能力不进入一期移动端入口。
4. 本次新增能力走一期 `/api/mobile/*`，不依赖二期页面和二期写入接口。

## 六、验收结果

已完成以下验收：

1. 语法检查通过：`backend/server.js`、`frontend/mobile-app.js`。
2. 接口隔离测试通过：使用临时数据库，不污染现有数据。
3. 渠道账号商机跟进通过：新增跟进后，商机详情能立即看到跟进记录。
4. 渠道账号已确认报价转订单通过：转单后进入订单详情，订单保留报价金额和关联报价。
5. 重复转单保护通过：同一报价再次转单返回冲突，不会重复创建订单。
6. 管理员写入权限拦截通过：管理员调用商机跟进接口返回无权操作。
7. 管理员手机端只读验收通过：业务详情不显示新增跟进和转订单表单。
