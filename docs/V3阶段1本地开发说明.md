# V3阶段1本地开发说明

## 环境要求

- Node.js 22长期支持版。
- npm 10。
- 可选：Docker或兼容容器运行时，用于启动PostgreSQL和Redis。

## 安装和验证

```bash
npm install
npm run check
npm test
npm run test:e2e
npm run build
```

## 启动骨架

```bash
cp .env.example .env
npm run dev
```

接口默认端口为 `3100`，前端默认端口为 `5173`。
`.env.example` 不保存密钥；如需连接本地容器，请只在自己的 `.env` 中填写 `DATABASE_URL`、`REDIS_URL` 和不少于 32 位的 `SESSION_SECRET`。

## 本地依赖容器

```bash
docker compose -f deploy/local-dev/docker-compose.yml up -d
```

阶段1默认使用 `HEALTH_DEPENDENCY_MODE=mock`，即使本机Redis不可用也可以跑完检查和测试。需要验证真实依赖时，把该值改为 `real`。
使用随仓库提供的本地容器时，可在本机 `.env` 中填入本地隔离开发值；这些值不得提交为真实环境配置。
