# 价格折扣功能修复方案

## 问题诊断

### 问题一：价格比例理解错误
**当前逻辑**：价格比例是加价率
- 100% = 基础价格 × 1.0 = 原价
- 110% = 基础价格 × 1.1 = 加价10%
- 30% = 基础价格 × 0.3 = 原价的30%

**用户需求**：价格比例是折扣率
- 30% = 基础价格 × 0.3 = 打3折
- 100% = 基础价格 × 1.0 = 原价
- 折扣率范围：0%-100%

**问题根源**：
1. 前后端数据格式不一致（百分比 vs 小数）
2. 概念理解错误（折扣率 vs 加价率）
3. 缺少优惠金额显示

### 问题二：缺少优惠金额
**需求**：
- 显示原价（基础价格）
- 显示折扣后价格（实际支付）
- 显示优惠金额（原价 - 折后价）

**示例**：
- 基础价格：¥150
- 折扣率：30%
- 折后价格：¥45（¥150 × 30%）
- 优惠金额：¥105（¥150 - ¥45）

## 修复方案

### 方案A：折扣率模式（推荐）

**数据模型**：
```javascript
{
  "priceDiscountPrimary": 100,    // 一级渠道商折扣率（%）
  "priceDiscountSecondary": 30,   // 二级渠道商折扣率（%）
  "priceOriginal": 150,           // 原价
  "priceActual": 45,              // 实际价格（原价 × 折扣率 / 100）
  "discountAmount": 105           // 优惠金额（原价 - 实际价格）
}
```

**价格计算**：
```
实际价格 = 原价 × (折扣率 / 100)
优惠金额 = 原价 - 实际价格
```

**示例**：
| 原价 | 折扣率 | 实际价格 | 优惠金额 |
|------|--------|---------|---------|
| ¥150 | 100%   | ¥150    | ¥0      |
| ¥150 | 30%    | ¥45     | ¥105    |
| ¥150 | 50%    | ¥75     | ¥75     |

### 方案B：保留加价率模式

**数据模型**：
```javascript
{
  "priceRatioPrimary": 100,    // 一级渠道商加价率（%）
  "priceRatioSecondary": 130,  // 二级渠道商加价率（%）
  "priceBase": 150,            // 基础价格
  "priceActual": 195,          // 实际价格（基础价格 × 加价率 / 100）
  "extraAmount": 45            // 额外金额（实际价格 - 基础价格）
}
```

**价格计算**：
```
实际价格 = 基础价格 × (加价率 / 100)
额外金额 = 实际价格 - 基础价格
```

**示例**：
| 基础价格 | 加价率 | 实际价格 | 额外金额 |
|---------|--------|---------|---------|
| ¥150    | 100%   | ¥150    | ¥0      |
| ¥150    | 130%   | ¥195    | ¥45     |
| ¥150    | 80%    | ¥120    | -¥30    |

## 推荐方案

**采用方案A：折扣率模式**

### 理由
1. 符合用户直觉：折扣率 = 实际支付比例
2. 行业惯例：渠道商价格通常用折扣表示
3. 清晰明了：30%折扣 = 打3折 = 支付30%

### 实施步骤

#### 1. 后端修复

**数据迁移**：
- 将现有数据中的 `priceRatioPrimary` 和 `priceRatioSecondary` 重命名为 `priceDiscountPrimary` 和 `priceDiscountSecondary`
- 将现有值直接作为折扣率使用（无需转换）

**API修改**：
```javascript
// PUT /api/features/:id
app.put('/api/features/:id', (req, res) => {
  const { id } = req.params;
  const { priceDiscountPrimary, priceDiscountSecondary, ...otherFields } = req.body;

  const feature = db.features.find(f => f.id === id);
  if (!feature) {
    return res.status(404).json({ success: false, error: '产品不存在' });
  }

  // 保存折扣率（百分比格式）
  if (priceDiscountPrimary !== undefined) {
    feature.priceDiscountPrimary = Math.max(0, Math.min(100, parseFloat(priceDiscountPrimary)));
  }
  if (priceDiscountSecondary !== undefined) {
    feature.priceDiscountSecondary = Math.max(0, Math.min(100, parseFloat(priceDiscountSecondary)));
  }

  // 计算渠道商价格
  if (feature.priceType === 'fixed') {
    // 固定价格
    const basePrice = feature.priceFixed;
    feature.priceForPrimary = Math.round(basePrice * feature.priceDiscountPrimary / 100);
    feature.priceForSecondary = Math.round(basePrice * feature.priceDiscountSecondary / 100);
  } else {
    // 阶梯价格
    feature.priceForPrimary = feature.tiers.map(t => ({
      min: t.min,
      max: t.max,
      price: Math.round(t.price * feature.priceDiscountPrimary / 100)
    }));
    feature.priceForSecondary = feature.tiers.map(t => ({
      min: t.min,
      max: t.max,
      price: Math.round(t.price * feature.priceDiscountSecondary / 100)
    }));
  }

  feature.updatedAt = new Date().toISOString();
  saveData();

  res.json({ success: true, data: feature });
});
```

#### 2. 前端修复

**报价创建界面**：
```javascript
// 计算价格时添加优惠金额
function calcFeatureTotal(features, endpoints, partner) {
  let total = 0;
  let originalTotal = 0;  // 原价总计
  let discountAmount = 0; // 优惠金额

  features.forEach(feat => {
    const partnerLevel = partner?.partnerLevel || 'none';
    let priceToUse, originalPrice;

    // 获取原价
    originalPrice = feat.priceFixed || getTierPrice(feat.tiers, endpoints);

    // 根据渠道商等级获取折扣价格
    if (partnerLevel === 'primary' && feat.priceForPrimary) {
      priceToUse = feat.priceForPrimary;
    } else if (partnerLevel === 'secondary' && feat.priceForSecondary) {
      priceToUse = feat.priceForSecondary;
    } else {
      priceToUse = originalPrice;
    }

    const itemTotal = priceToUse * endpoints;
    const itemOriginal = originalPrice * endpoints;

    total += itemTotal;
    originalTotal += itemOriginal;
    discountAmount += (itemOriginal - itemTotal);
  });

  return {
    total,           // 实际总价
    originalTotal,   // 原价总计
    discountAmount   // 优惠金额
  };
}
```

#### 3. 数据迁移脚本

```javascript
// scripts/migrate-to-discount.js
const fs = require('fs');
const path = require('path');

const DATA_FILE = path.join(__dirname, '../backup_20260413_193150/data.json');
const BACKUP_FILE = path.join(__dirname, '../backup_20260413_193150/data.json.backup_before_discount');

// 加载数据
const data = JSON.parse(fs.readFileSync(DATA_FILE, 'utf8'));

// 备份
fs.writeFileSync(BACKUP_FILE, JSON.stringify(data, null, 2));

// 迁移产品数据
data.features.forEach(feat => {
  // 将 priceRatio 字段重命名为 priceDiscount
  if (feat.priceRatioPrimary !== undefined) {
    feat.priceDiscountPrimary = feat.priceRatioPrimary;
    delete feat.priceRatioPrimary;
  } else {
    feat.priceDiscountPrimary = 100; // 默认100%折扣
  }

  if (feat.priceRatioSecondary !== undefined) {
    feat.priceDiscountSecondary = feat.priceRatioSecondary;
    delete feat.priceRatioSecondary;
  } else {
    feat.priceDiscountSecondary = 100; // 默认100%折扣
  }

  // 重新计算渠道商价格
  if (feat.priceType === 'fixed') {
    const basePrice = feat.priceFixed;
    feat.priceForPrimary = Math.round(basePrice * feat.priceDiscountPrimary / 100);
    feat.priceForSecondary = Math.round(basePrice * feat.priceDiscountSecondary / 100);
  } else if (feat.tiers) {
    feat.priceForPrimary = feat.tiers.map(t => ({
      min: t.min,
      max: t.max,
      price: Math.round(t.price * feat.priceDiscountPrimary / 100)
    }));
    feat.priceForSecondary = feat.tiers.map(t => ({
      min: t.min,
      max: t.max,
      price: Math.round(t.price * feat.priceDiscountSecondary / 100)
    }));
  }
});

// 保存
fs.writeFileSync(DATA_FILE, JSON.stringify(data, null, 2));

console.log('✅ 数据迁移完成');
console.log(`✅ 备份文件：${BACKUP_FILE}`);
```
