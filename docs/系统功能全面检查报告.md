### 问题1：设置渠道商等级403无权限错误 ✅

**问题描述**：
- 点击"等级"按钮设置渠道商等级时，API返回403错误"无权限操作"

**根本原因**：
- 前端调用API时未传递 `operatedBy` 和 `operatedByRole` 参数
- 后端权限校验失败

**修复方案**：
```javascript
// 在 savePartnerLevel 方法中添加用户信息
const res = await apiRequest('PUT', `/partners/${levelForm.partnerId}/level`, {
  partnerLevel: levelForm.partnerLevel,
  parentPartnerId: levelForm.partnerLevel === 'secondary' ? levelForm.parentPartnerId : null,
  operatedBy: store.user.id,           // ✅ 新增
  operatedByRole: store.user.role      // ✅ 新增
});
```

### 问题2：审核中心审批按钮无反应 ✅

**问题描述**：
- 超管在审核中心审批"渠道企业管理员"时，点击"同意"或"拒绝"按钮无反应

**根本原因**：
- 审核中心的员工审批方法未区分 `partner_admin` 和 `staff` 类型
- 对于 `partner_admin` 类型，应使用 `/pending-approvals/:id` 接口
- 前端错误使用了 `/users/:id/status` 接口

**修复方案**：
```javascript
// 区分处理不同类型的审批
async function approveStaff(s) {
  let res;
  if (s.type === 'partner_admin') {
    // 企业管理员审批：使用 pending-approvals 接口
    res = await apiRequest('PUT', `/pending-approvals/${s.aprId}`, { 
      action: 'approve',
      approvedBy: store.user?.name
    });
  } else {
    // 普通员工审批：使用 users 接口
    res = await apiRequest('PUT', `/users/${s.id}/status`, { 
      status: 'active',
      approvedBy: store.user?.id
    });
  }
  ...
}
```

**修复文件**：
- `frontend/admin-app.js` 第7891-7924行

**验证方法**：
1. 以超级管理员登录管理后台
2. 进入审核中心
3. 切换到"员工"标签页
4. 找到企业管理员账号，点击"通过"或"拒绝"
5. 确认操作成功且列表刷新
