## [2.2.0] - 2026-04-12

### 新增
- 统一登录入口（login.html）：自动识别设备类型
- 渠道伙伴手机版（partner-mobile.html）：移动端优先设计
- 设备自动适配功能：桌面/移动端智能切换
- 报价单状态流转：草稿→已发送→已确认→已转单
- 商机-订单闭环：报价单可直接转订单
- 管理员指派数据 enrichment 修复
- API 客户端用户同步修复

### 优化
- 产品目录重构：1个类别、4个模块（桌面安全管理/防泄密/防勒索/准入控制）
- 报价单明细展示：从后端 API 加载产品数据
- 企业管理员管理功能完善
- 渠道伙伴报价单分页功能

### 修复
- 员工 ID 格式不一致问题
- 报价单单价隐藏（员工角色不显示单价明细）
- 数据隔离逻辑优化

## 版本说明

### 版本号规则
- **主版本号**：重大功能更新，可能包含破坏性变更
- **次版本号**：功能新增，保持向后兼容
- **修订号**：Bug 修复，完全兼容

### 升级路径
- 1.x → 2.0：需要数据迁移
- 2.0 → 2.1：自动迁移，无需干预

### 兼容性
| 版本 | 数据版本 | 兼容性 |
|------|---------|--------|
| 1.x  | 1       | 仅向前兼容 2.x |
| 2.0  | 2       | 向后兼容 1.x |
| 2.1  | 2       | 完全兼容 2.0 |
