## [未发布]

### 新增

- 升级包构建脚本 v2.0（适配 Vue 3 + Node.js 新架构）
- 渠道产品订单预审独立任务：订单状态机自动投递、泛微双附件流程发起与只读回查、企微应用自动建群；默认关闭、独立部署 Profile、超时转人工确认且不改写订单状态
- 组织架构渠道商同步接口：`GET /api/org/channel-sync/preview` 与 `POST /api/org/channel-sync/execute`（v1 单向：channel.partners → org.regions，DEC-0011）；管理端"组织与岗位"栏目新增"渠道商同步"按钮与预览弹窗
- 渠道组织范围选择器改 `el-tree-select`：默认展示一级、点击展开二级三级、父子严格不联动，避免误选父级导致区域范围虚增
- 渠道商信息简介企业基本信息新增"合作背景"字段（展示+编辑+保存，存储于 `partner_profiles.extra_json`，无需结构变更）；简介编辑权限收紧为超级管理员与区域管理员
- 客户报备审核列表新增"合作伙伴"与"提报人"两列（取后端已有 `partnerName`/`assignedStaffName` 字段，便于管理员审批时识别来源）

### 修复

- 组织架构：内部组织树父级节点成员计数重复累加（成员聚合与计数口径统一）
- 组织架构：RBAC 角色渠道范围提交时渠道商节点被误标为 `region`，现按节点实际类型分别提交 `region`/`partner`
- 部署：`migrate-db.sh` 与 `prepare-postgresql-test.mjs` 中 R 系列迁移执行顺序错误（会在 S10 建表前执行 R02，全新环境迁移中断；测试准备脚本还会重复执行）
- 配置：`.env.example` 补充组织架构、企微目录同步与消息工作进程开关（与生产模板对齐）
- 订单预审：模板停用不再继续外呼；企微建群异常按群任务记录，不误记为 OA 创建失败；外部编号和字符串错误码均保持兼容

### 优化

- 管理用户抽屉居中放大：`.组织抽屉` 改 `min(880px, 94vw)` × `min(86vh, 880px)`，去右贴边、加圆角
- 用户编辑抽屉打开时主动重取证书模板，确保"颁发证书"下拉最新
- 业务角色显示统一移除：侧栏业务角色导航栏目移除，用户编辑抽屉内的业务角色区块隐藏（接口与后端保留）

## 版本说明

### 版本号规则

- **主版本号**：重大功能更新，可能包含破坏性变更
- **次版本号**：功能新增，保持向后兼容
- **修订号**：Bug 修复，完全兼容

### 升级路径

- 1.x → 2.0：需要数据迁移
- 2.0 → 2.1：自动迁移，无需干预

### 兼容性

| 版本 | 数据版本 | 兼容性         |
| ---- | -------- | -------------- |
| 1.x  | 1        | 仅向前兼容 2.x |
| 2.0  | 2        | 向后兼容 1.x   |
| 2.1  | 2        | 完全兼容 2.0   |
