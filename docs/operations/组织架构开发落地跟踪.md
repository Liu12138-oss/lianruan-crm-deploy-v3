## 6. 领取与更新规范

### 6.1 领取任务

1. 在对应任务行的"责任人"列填上你的标识（姓名 / 工号 / git 用户名）
2. 在"状态"列把 ⚪ 改为 🟡
3. 提交 PR 时把 PR 链接作为备注贴到该行（格式：🟡 进行中 @张三 #PR-123）

### 6.2 完成交付

1. 通过验收后，把"状态"改为 ✅
2. 在文档底部"变更日志"追加一条记录
3. 复杂任务（如 TASK-E07 全局门禁迁移）需要在 PR 描述里列出**所有改动的文件路径**

### 6.3 阻塞处理

1. 状态改 🟠，在备注列写明阻塞原因（如"依赖 TASK-A05 未完成"或"需与用户确认 X 决策"）
2. 当日同步给项目负责人
3. 解除阻塞后改回 🟡 继续推进

### 6.4 取消任务

1. 仅在确认业务规则变更或方案决策调整时取消
2. 状态改 ⚫，备注列写"取消原因 + 决策依据文件链接"
3. 同步更新对应的方案文档和落地文档
