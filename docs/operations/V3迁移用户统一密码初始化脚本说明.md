# V3迁移用户统一密码初始化脚本说明

适用场景：V2用户数据已经迁移到V3，但迁移用户无法使用旧密码登录，需要统一设置临时初始密码。

## 1. 脚本位置

```text
deploy/single-server/scripts/init-migrated-user-passwords.sh
```

安装到生产或测试服务器后，对应路径为：

```text
/opt/lianruan-crm-v3/scripts/init-migrated-user-passwords.sh
```

## 2. 默认策略

| 项目 | 默认值 |
| --- | --- |
| 初始化密码 | `LrCRM@2026!` |
| 初始化范围 | 仅 `iam.users.v2_source_id` 不为空的启用账号 |
| 数据库 | 更新 PostgreSQL 正式表 `iam.password_credentials` |
| 登录配置 | 更新 `/opt/lianruan-crm-v3/config/v3.env` 的 `V3_DELIVERY_AUTH_USERS_JSON` |
| 生效方式 | 自动重启 `api-1` 和 `api-2` |
| 备份 | 先备份 `v3.env`，并调用安装目录下的 `backup.sh` 做本机备份 |

## 3. 执行前预览

```bash
cd /opt/lianruan-crm-v3
INSTALL_ROOT=/opt/lianruan-crm-v3 ./scripts/init-migrated-user-passwords.sh --dry-run
```

## 4. 正式执行

```bash
cd /opt/lianruan-crm-v3
INSTALL_ROOT=/opt/lianruan-crm-v3 ./scripts/init-migrated-user-passwords.sh --yes
```

执行完成后，V2迁移用户可以使用下面的临时密码登录：

```text
LrCRM@2026!
```

## 5. 全部启用账号统一初始化

如果需要把非迁移账号也统一设置为该密码，执行：

```bash
cd /opt/lianruan-crm-v3
INSTALL_ROOT=/opt/lianruan-crm-v3 ./scripts/init-migrated-user-passwords.sh --all-users --yes
```

## 6. 注意事项

1. 脚本会更新登录配置并重启API，当前在线用户的会话可能需要重新登录。
2. 默认只处理启用账号，停用账号不会被初始化。
3. 正式上线前建议要求用户首次登录后修改密码。
4. 如果执行后需要回退，可以用脚本输出的 `v3.env.*.password-init.bak` 恢复登录配置，并用发布前备份恢复数据库。
5. 该脚本不恢复V2旧密码，只设置统一临时密码。
