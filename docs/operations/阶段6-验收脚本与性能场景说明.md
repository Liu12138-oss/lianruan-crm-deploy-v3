# 阶段6 验收脚本与性能场景说明

## 1. 目标

本文件说明阶段6新增的无业务副作用脚本和后续性能压测场景。当前脚本只输出场景模板和资源预算校验，不连接生产服务、不写数据库、不写 Redis、不产生任务。

脚本位置：

```text
tests/performance/阶段6-Redis任务化性能场景模板.js
```

执行方式：

```text
node tests/performance/阶段6-Redis任务化性能场景模板.js
```

## 2. 脚本输出内容

- 12 核 32GB 单机资源预算。
- Redis 职责和键命名示例。
- BullMQ 队列并发和连接预算。
- 阶段6性能场景模板。
- 备用服务器接管演练检查项。

脚本退出码为 0 表示模板自检通过。若资源预算超过 12 核或 32GB，脚本会返回非 0 并输出中文错误。

## 3. 后续真实压测要求

真实压测应在阶段6开发完成后执行，不能用当前模板替代实测。压测必须记录：

- 服务器配置、容器版本、数据库版本、Redis版本。
- 数据规模、客户数量、渠道数量、订单数量和审计日志数量。
- 脚本版本、场景权重、并发、持续时间。
- 请求成功率、错误率、P50、P95、P99、最大耗时。
- PostgreSQL 慢查询、锁等待、连接池等待。
- Redis 内存、大键、热键、慢命令。
- 队列等待、运行、失败、重试、停滞任务数。
- Node 进程内存、处理器占用和重启次数。

## 4. 阶段6退出证据

阶段6完成时必须归档：

- 队列清单和任务事实模型。
- 缓存清单和失效策略。
- Redis 大键、热键和无过期键扫描报告。
- 核心查询执行计划和索引证据。
- 目标、峰值、长稳、导出并行、队列积压、缓存失效测试报告。
- Redis 故障恢复和任务补投演练报告。
