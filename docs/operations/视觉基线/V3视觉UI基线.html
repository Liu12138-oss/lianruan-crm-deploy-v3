🎨 V3 视觉关键要点（开发必须遵守）

主色：#007AFF（苹果蓝）
侧边栏：#1D1D1F（深灰近黑）
背景：#F5F5F7（极浅灰）
卡片：白底 + 圆角 16px + 微阴影
侧边栏宽度：240px（固定）
顶栏高度：52px（毛玻璃 backdrop-filter）
圆角：8 / 12 / 16 / 20 / 9999px（full）
字体：SF Pro / PingFang SC / Microsoft YaHei
状态标签：6 套官方色（蓝/绿/橙/红/紫/灰）
卡片标题：左 4px 蓝色竖条
按钮：primary 蓝底 / default 白底 / text 纯文字 / danger 红底
阴影：极淡多层（Apple 风），不是传统卡片阴影
导航激活：蓝底白字 + 蓝色光晕阴影
表格：白底、无外边框、行间淡分割线、hover 浅灰底
统计卡：图标底色用 10% 透明度的同色系
弹窗：圆角 20px + modalIn 弹性动画
