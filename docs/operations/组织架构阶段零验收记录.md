## 已交付的受控能力

- 独立 `/api/org` 路由与组织、岗位、内部任职、业务角色、证书、离职交接的首批服务端接口。
- 新增组织/岗位/任职/业务角色/证书/离职交接数据表；写操作使用事务、乐观锁和审计日志。
- 证书撤销不会撤销业务角色；离职交接仅创建待办和发件箱事件，不会自动停用账号或迁移客户、商机、报价、订单。
- 企业微信同步表已就绪，但同步总开关默认关闭，尚未获得生产启用资格。

## 生产启用前的后续门禁

1. 为组织接口接入正式的权限码与数据范围计算，替代阶段零的“超级管理员专用”门禁。
2. 完成正式管理端受控入口、组织编辑页面及端到端测试；移动端和渠道端保持不开放。
3. 完成企微回调验签解密、令牌缓存、独立任务进程、全量校准、差异审批及回退演练。
4. 保持企微同步至少 7 天只读观察，并完成两轮全量对账后，才评审开启受控应用。
5. 所有生产配置保持下列默认值，未经变更评审不得修改：

```dotenv
V3_ORGANIZATION_ENABLED=false
V3_ORGANIZATION_WRITE_ENABLED=false
V3_DIRECTORY_SYNC_ENABLED=false
```
