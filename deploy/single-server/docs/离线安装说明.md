# V3阶段7离线安装说明

## 1. 目标环境

| 项目 | 当前约定 |
| --- | --- |
| 操作系统 | 欧拉 Linux |
| 处理器架构 | x86_64 |
| 安装目录 | `/opt/lianruan-crm-v3` |
| 访问方式 | 先使用 `http://服务器IP` |
| 镜像方式 | ZIP离线镜像安装包 |
| 异机备份 | 暂不启用，保留配置位 |

## 2. 构建机生成安装包

构建机必须安装Docker，并能构建 `linux/amd64` 镜像。

```bash
npm ci
npm run verify
deploy/single-server/scripts/download-runtime.sh
deploy/single-server/scripts/build-images.sh
deploy/single-server/scripts/save-images.sh
deploy/single-server/scripts/package-offline.sh
```

构建机访问Docker Hub不稳定时，可指定等价镜像源：

```bash
V3_NODE_IMAGE=public.ecr.aws/docker/library/node:22.13.1-bookworm-slim \
V3_NGINX_IMAGE=public.ecr.aws/docker/library/nginx:1.27-alpine \
deploy/single-server/scripts/build-images.sh

V3_POSTGRES_IMAGE_SOURCE=public.ecr.aws/docker/library/postgres:16.4-alpine \
V3_REDIS_IMAGE_SOURCE=public.ecr.aws/docker/library/redis:7.2.5-alpine \
deploy/single-server/scripts/save-images.sh

deploy/single-server/scripts/package-offline.sh
```

如果本地已经存在标准标签镜像，可跳过基础服务镜像拉取：

```bash
V3_SKIP_PULL=1 deploy/single-server/scripts/save-images.sh
```

跨平台构建机如遇旧Docker构建器无法处理Nginx多架构镜像，`build-images.sh` 会默认启用Web镜像应急构建；如需强制标准Dockerfile构建，可设置 `V3_WEB_FALLBACK_ENABLED=0`。

生成物默认在：

```text
tmp/phase7-package/
├── lianruan-crm-v3-offline-版本号.zip
└── lianruan-crm-v3-offline-版本号.zip.sha256
```

## 3. 生产服务器安装

把安装包上传到欧拉服务器后执行：

```bash
sha256sum -c lianruan-crm-v3-offline-版本号.zip.sha256
unzip lianruan-crm-v3-offline-版本号.zip
cd lianruan-crm-v3-offline-版本号
sudo SERVER_HOST=服务器IP ./scripts/install-all.sh
sudo /opt/lianruan-crm-v3/scripts/health-check.sh
```

如果服务器缺少 `unzip` 命令，需要先由系统管理员安装 `unzip`，或在构建机临时使用 `V3_PACKAGE_FORMAT=tar.gz deploy/single-server/scripts/package-offline.sh` 生成 `tar.gz` 备用包。

openEuler 24.03 最小化安装可能缺少 `tar` 命令。阶段7.1安装包会携带 `runtime/docker-bin/docker/` 预解压Docker二进制目录，一键安装会优先使用该目录安装Docker，不要求目标服务器预装 `tar`。

一键安装脚本会自动执行安装前检测、安装Docker运行时、安装Docker Compose、创建目录、生成初始密钥、加载离线镜像、写入 `v3.env` 模板、启动服务并执行健康检查。

安装日志默认写入：

```text
/opt/lianruan-crm-v3/logs/install/
```

重复执行安装时，脚本不会覆盖既有 `docker-compose.yml`、Nginx配置、部署变量和 `v3.env`。如安装包内模板有更新，会在目标目录生成 `.new` 文件或 `nginx.new` 目录，便于人工比对后合并。

## 4. 配置文件

| 文件 | 说明 |
| --- | --- |
| `/opt/lianruan-crm-v3/config/v3.env` | 应用生产环境变量，包含数据库和Redis连接串 |
| `/opt/lianruan-crm-v3/config/deploy.env` | 部署变量和备份留口 |
| `/opt/lianruan-crm-v3/secrets/` | PostgreSQL、Redis、会话和备份密钥 |
| `/opt/lianruan-crm-v3/compose/docker-compose.yml` | 单机容器编排 |

密钥目录权限必须保持 `700`，密钥文件权限必须保持 `600`。

## 5. 常用命令

```bash
sudo /opt/lianruan-crm-v3/scripts/start.sh
sudo /opt/lianruan-crm-v3/scripts/stop.sh
sudo /opt/lianruan-crm-v3/scripts/health-check.sh
sudo /opt/lianruan-crm-v3/scripts/backup.sh --type manual
sudo /opt/lianruan-crm-v3/scripts/backup.sh --dry-run
sudo /opt/lianruan-crm-v3/scripts/rollback.sh --dry-run
sudo /opt/lianruan-crm-v3/scripts/collect-diagnostics.sh
```

## 6. 上线边界

- 当前无域名和证书，只能按HTTP和IP做预生产验证。
- 正式公网开放前必须补HTTPS、证书续期和证书告警。
- 当前无异机备份，不能承诺整机故障恢复时间。
- 阶段7不执行V2正式数据迁移，不切换正式用户。
- 阶段7.1默认集成Docker官方静态运行时和Compose插件二进制；如正式生产要求RPM审计闭包，需要按实际欧拉版本补充运行时包。
