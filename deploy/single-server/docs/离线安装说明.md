# V3阶段7离线安装说明

## 1. 目标环境

| 项目 | 当前约定 |
| --- | --- |
| 操作系统 | 欧拉 Linux |
| 处理器架构 | x86_64 |
| 安装目录 | `/opt/lianruan-crm-v3` |
| 访问方式 | 先使用 `http://服务器IP` |
| 镜像方式 | 离线镜像安装包 |
| 异机备份 | 暂不启用，保留配置位 |

## 2. 构建机生成安装包

构建机必须安装Docker，并能构建 `linux/amd64` 镜像。

```bash
npm ci
npm run verify
deploy/single-server/scripts/build-images.sh
deploy/single-server/scripts/save-images.sh
deploy/single-server/scripts/package-offline.sh
```

生成物默认在：

```text
tmp/phase7-package/
├── lianruan-crm-v3-offline-版本号.tar.gz
└── lianruan-crm-v3-offline-版本号.tar.gz.sha256
```

## 3. 生产服务器安装

把安装包上传到欧拉服务器后执行：

```bash
tar -xzf lianruan-crm-v3-offline-版本号.tar.gz
cd lianruan-crm-v3-offline-版本号
sudo SERVER_HOST=服务器IP ./scripts/install.sh
sudo /opt/lianruan-crm-v3/scripts/start.sh
/opt/lianruan-crm-v3/scripts/health-check.sh
```

安装脚本会自动创建目录、生成初始密钥、加载离线镜像、写入 `v3.env` 模板。

## 4. 配置文件

| 文件 | 说明 |
| --- | --- |
| `/opt/lianruan-crm-v3/config/v3.env` | 应用生产环境变量，包含数据库和Redis连接串 |
| `/opt/lianruan-crm-v3/config/deploy.env` | 部署变量和备份留口 |
| `/opt/lianruan-crm-v3/secrets/` | PostgreSQL、Redis、会话和备份密钥 |
| `/opt/lianruan-crm-v3/compose/docker-compose.yml` | 单机容器编排 |

密钥目录权限必须保持 `700`，密钥文件权限必须保持 `600`。

## 5. 常用命令

```bash
sudo /opt/lianruan-crm-v3/scripts/start.sh
sudo /opt/lianruan-crm-v3/scripts/stop.sh
/opt/lianruan-crm-v3/scripts/health-check.sh
sudo /opt/lianruan-crm-v3/scripts/backup.sh --type manual
sudo /opt/lianruan-crm-v3/scripts/backup.sh --dry-run
sudo /opt/lianruan-crm-v3/scripts/rollback.sh --dry-run
sudo /opt/lianruan-crm-v3/scripts/collect-diagnostics.sh
```

## 6. 上线边界

- 当前无域名和证书，只能按HTTP和IP做预生产验证。
- 正式公网开放前必须补HTTPS、证书续期和证书告警。
- 当前无异机备份，不能承诺整机故障恢复时间。
- 阶段7不执行V2正式数据迁移，不切换正式用户。
