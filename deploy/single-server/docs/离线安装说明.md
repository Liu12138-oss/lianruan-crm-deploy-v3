# V3阶段9离线安装说明

## 1. 目标环境

| 项目 | 当前约定 |
| --- | --- |
| 操作系统 | openEuler x86_64 |
| 安装目录 | `/opt/lianruan-crm-v3` |
| 访问方式 | `http://服务器IP` |
| 镜像方式 | ZIP离线安装包 |
| 数据库 | PostgreSQL |
| 缓存和任务 | Redis |

## 2. 安装包内容

ZIP包内已经包含业务镜像、PostgreSQL镜像、Redis镜像、Docker离线运行时、Docker Compose二进制、安装检测脚本、安装日志记录、迁移脚本、备份脚本、回退脚本和诊断脚本。

## 3. 安装步骤

```bash
sha256sum -c lianruan-crm-v3-offline-3.0.0-stage9.20260727.zip.sha256
if command -v unzip >/dev/null 2>&1; then
  unzip -q lianruan-crm-v3-offline-3.0.0-stage9.20260727.zip
else
  python3 -m zipfile -e lianruan-crm-v3-offline-3.0.0-stage9.20260727.zip .
fi
cd lianruan-crm-v3-offline-3.0.0-stage9.20260727
sudo SERVER_HOST=服务器IP ./scripts/install-all.sh
sudo /opt/lianruan-crm-v3/scripts/migrate-db.sh
sudo /opt/lianruan-crm-v3/scripts/health-check.sh
```

一键安装日志：

```text
/opt/lianruan-crm-v3/logs/install/
```

## 6. 全量手工备份与还原

全量手工备份用于服务器故障、迁移或重大变更前的人工灾备。它会备份安装目录、生产配置和密钥、上传与导出文件、PostgreSQL 逻辑数据、Redis 持久化数据，以及当前 Compose 使用的 Docker 镜像。系统文件与 Redis 数据均使用 ZIP 归档，不依赖 tar；Docker 运行时数据目录不进入 ZIP，由镜像归档和 Compose 在恢复时重建。备份目录固定为 `/home/lianruan-crm-v3-system-backups`，其中含有生产密钥，仅允许 root 读取。

创建备份：

```bash
sudo /opt/lianruan-crm-v3/scripts/system-backup-restore.sh backup
```

先校验，再还原指定备份：

```bash
sudo /opt/lianruan-crm-v3/scripts/system-backup-restore.sh verify \
  --backup /home/lianruan-crm-v3-system-backups/20260817-120000-manual

sudo /opt/lianruan-crm-v3/scripts/system-backup-restore.sh restore \
  --backup /home/lianruan-crm-v3-system-backups/20260817-120000-manual \
  --confirm RESTORE
```

还原会先自动备份当前环境，再停止服务、加载备份镜像、恢复安装目录与数据，并启动健康检查。当前环境不能正常备份时，才可在确认已有其他回退副本后追加 `--skip-pre-restore-backup`。还原后的原安装目录会保留为 `/opt/lianruan-crm-v3.pre-restore-时间戳`，在验收完成前不得删除。

## 7. 注意事项

- 重复执行安装不会覆盖既有关键配置，新增模板会以 `.new` 文件或目录保留。
- 没有域名证书时只建议内网或测试环境使用HTTP。
- 回退脚本只回退应用镜像和配置，不自动回滚数据库。
- 正式上线前必须重置默认账号密码、初始化正式用户、重新签发OpenAPI密钥。
