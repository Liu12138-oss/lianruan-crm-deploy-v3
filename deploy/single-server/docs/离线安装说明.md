# V3阶段9离线安装说明

## 1. 目标环境

| 项目 | 当前约定 |
| --- | --- |
| 操作系统 | openEuler x86_64 |
| 安装目录 | `/opt/lianruan-crm-v3` |
| 访问方式 | `http://服务器IP` |
| 镜像方式 | ZIP离线安装包 |
| 数据库 | PostgreSQL |
| 缓存和任务 | Redis |

## 2. 安装包内容

ZIP包内已经包含业务镜像、PostgreSQL镜像、Redis镜像、Docker离线运行时、Docker Compose二进制、安装检测脚本、安装日志记录、迁移脚本、备份脚本、回退脚本和诊断脚本。

## 3. 安装步骤

```bash
sha256sum -c lianruan-crm-v3-offline-3.0.0-stage9.20260727.zip.sha256
if command -v unzip >/dev/null 2>&1; then
  unzip -q lianruan-crm-v3-offline-3.0.0-stage9.20260727.zip
else
  python3 -m zipfile -e lianruan-crm-v3-offline-3.0.0-stage9.20260727.zip .
fi
cd lianruan-crm-v3-offline-3.0.0-stage9.20260727
sudo SERVER_HOST=服务器IP ./scripts/install-all.sh
sudo /opt/lianruan-crm-v3/scripts/migrate-db.sh
sudo /opt/lianruan-crm-v3/scripts/health-check.sh
```

一键安装日志：

```text
/opt/lianruan-crm-v3/logs/install/
```

## 4. 登录测试

```text
http://服务器IP/login
```

默认账号：

```text
admin / LrCRM@2026!
```

建议先验证 `/unified`，再验证 `/admin/registration`、`/admin/opportunity`、`/admin/quote`、`/admin/order` 和 `/mobile/partner/home`。

## 5. 常用命令

```bash
sudo /opt/lianruan-crm-v3/scripts/start.sh
sudo /opt/lianruan-crm-v3/scripts/stop.sh
sudo /opt/lianruan-crm-v3/scripts/health-check.sh
sudo /opt/lianruan-crm-v3/scripts/backup.sh --type manual
sudo /opt/lianruan-crm-v3/scripts/collect-diagnostics.sh
```

## 6. 注意事项

- 重复执行安装不会覆盖既有关键配置，新增模板会以 `.new` 文件或目录保留。
- 没有域名证书时只建议内网或测试环境使用HTTP。
- 回退脚本只回退应用镜像和配置，不自动回滚数据库。
- 正式上线前必须重置默认账号密码、初始化正式用户、重新签发OpenAPI密钥。
