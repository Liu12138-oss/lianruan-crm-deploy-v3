# 人工验收清单

1. 升级日志应显示 7 项发布安全开关已临时关闭且配置原值已恢复；使用 `docker inspect` 确认升级后的 API 和 Worker 容器中这 7 项开关均为 `false`，且脚本未自动重启服务重新启用功能。确认服务器 `/admin.html` 中实际引用的带版本号 `admin-app.js` 与 `style.css` 均可访问，脚本同时包含 `/api/org/status`、“只读观察”和组织架构内嵌路由。
2. 使用超级管理员登录 `/admin.html`，点击左侧“组织架构”后页面不整页跳转，侧边栏与顶栏保持不变，内容区显示组织架构页签并可切换七个栏目；普通管理员和渠道账号不得出现该入口。
3. 经批准仅开启 `V3_ORGANIZATION_ENABLED=true`，保持组织写入、企微目录同步、账号状态防护和停用归档交接为 `false`；确认入口显示“只读观察”，工作区只读取组织数据。
4. 未登录访问组织接口应返回 `401`，普通管理员和渠道账号应返回 `403`；任一组织写接口应返回 `403 ORG_WRITE_DISABLED`，且不得新增审计、发件箱或同步批次。
5. 回归登录、退出以及管理员、渠道和两个移动端正式页面；客户报备、商机、报价、订单、渠道和账号主链路不得因组织只读开启而变化。
6. 打开统一消息管理页，确认可维护企业微信机器人、自建应用和 SMTP 配置，并能使用指定测试对象试发。
7. 仅在完成渠道审批、密钥托管和测试投递验收后，按页面提示启用外部通道；不要直接手工开启自动投递。
8. 执行 `bash tests/smoke.sh`，并确认 `/health/live`、`/health/ready`、`/health/dependencies` 均正常。
9. 升级前确认预检查输出的 API、Worker、Nginx 源镜像分别与包元数据一致；升级后七个应用容器必须全部使用目标 SP 镜像，回退演练必须恢复升级前各自真实镜像和摘要。
10. IAM 配置接口必须返回 `enabled:true`，并包含 `entries`、`requestIsaidByEntry`、`timeoutMs`；不得复用历史 `enabled:false` 或 `pcEnabled` 断言。
11. 组织只读和普通写入验收通过后，先单独灰度 `V3_AUTH_ACCOUNT_STATUS_CHECK_ENABLED=true`；`V3_ORGANIZATION_OFFBOARDING_ENABLED` 继续保持 `false`，直到交接任务、真实账号、回退演练和负责人签字全部完成。
12. 回退前必须先关闭停用归档交接；如果目标快照没有开启账号状态防护，回退脚本必须拒绝执行，不能让已停用账号的旧会话恢复。
