# SP-APP 变更说明

- 包编号：`__PACKAGE_ID__`
- 包型：`SP-APP`
- 源版本：`__SOURCE_VERSION__`
- 目标版本：`__TARGET_VERSION__`

本次交付包含 API、Worker、Nginx 三类业务镜像，组织架构正式管理入口、统一消息提醒平台页面与接口、企业微信自建应用及 SMTP 测试投递能力，以及配套的数据库扩展迁移和运维脚本修复。

本包同时包含区域管理员 IAM 手机端和 UniSDP 门户用户名匹配修复，并将测试环境当前 API、Worker、消息 Worker、Nginx 的混合运行版本统一收口为目标 SP 版本。

不会更新 Docker、Docker Compose、PostgreSQL、Redis 或现有密钥文件。组织架构写入、目录同步、账号状态防护、停用归档交接和消息自动投递仍默认关闭，须按功能门禁在页面与配置中分阶段启用；账号状态防护必须先于停用归档交接独立灰度。

数据库迁移仅增加兼容性结构、索引和配置数据；`S10_009` 必须先于 `S10_010`。升级失败时自动回退范围仅限应用文件与镜像引用，数据库备份恢复必须由负责人确认后人工执行；若目标快照不具备账号状态防护，回退脚本会拒绝恢复旧配置。
