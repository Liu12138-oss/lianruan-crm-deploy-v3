# 源代码变更说明

本补丁只修改 V3 工程：

- `apps/api/src/auth-routes.ts`：认证响应增加正式业务页面会话。
- `apps/web/src/api/auth-client.ts`：保存管理员或渠道页面会话。
- `apps/web/src/router/entry-target.ts`：统一映射四套正式业务页面并校验跳转地址。
- `apps/web/src/pages/LoginPage.vue`：登录成功后采用浏览器整页跳转。
- `apps/web/src/pages/SingleSignOnPage.vue`：单点登录成功后采用浏览器整页跳转。
- `apps/web/src/router/index.ts`：已有 Cookie 会话恢复后整页进入正式业务页面。
- `deploy/single-server/config/nginx/default.conf`：恢复 `/admin`、`/partner` 到正式页面。
- `apps/api/tests`、`apps/web/tests`、`apps/web/e2e`：补充会话桥接与四端分流回归。
- `AGENTS.md`、`README.md`：固化 V3 统一入口维护规则。

根目录历史 V2 的 `frontend`、`backend` 未修改。
