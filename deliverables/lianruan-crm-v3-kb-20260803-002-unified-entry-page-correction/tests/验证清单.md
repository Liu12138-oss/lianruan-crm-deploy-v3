# 验证清单

## 自动检查

- `scripts/precheck.sh` 通过。
- `scripts/upgrade.sh` 执行完成。
- `scripts/verify.sh` 通过。
- 升级日志显示升级前数据库、上传目录、导出目录和配置备份位置。
- `api-1`、`api-2`、`nginx` 均使用 `3.0.0-stage9.24.20260803-kb002` 镜像标签。
- `/health/live` 返回目标版本。
- `/`、`/login` 返回 V3 统一登录页面，状态码为 200。
- `/admin` 返回 302，跳转目标为 `/admin.html`。
- `/partner` 返回 302，跳转目标为 `/partner.html`。
- `/admin.html` 包含 `admin-app.js`。
- `/admin-mobile.html` 指向 `mobile.html`。
- `/partner.html` 包含 `partner-app.js`。
- `/partner-mobile.html` 指向 `mobile.html`。
- IAM H5 配置接口返回成功，并包含管理员和渠道端请求标识。

## 人工检查

- 清理浏览器中该站点的旧缓存和登录态后访问 `/`，看到统一账号密码登录页。
- 使用管理员账号在电脑端登录，最终进入 `/admin.html#/dashboard`。
- 使用渠道账号在电脑端登录，最终进入 `/partner.html#/dashboard`。
- 使用管理员账号在手机端登录，最终进入 `mobile.html?scope=admin#/admin/home`。
- 使用渠道账号在手机端登录，最终进入 `mobile.html?scope=partner#/partner/home`。
- 四种登录均不再次显示账号密码登录页，也不自动发起无关的 IAM 登录。
- 管理员不能因恶意 `redirect` 进入外站；渠道账号不能通过 `redirect` 进入管理员页面。
- IAM H5 管理员入口进入管理员正式页面。
- IAM H5 渠道入口进入渠道正式页面。
- 原报备、商机、报价、订单、渠道管理、账号管理页面可正常打开和查询。
