# 验证清单

## 自动验证

1. 执行 `sudo bash scripts/precheck.sh /opt/lianruan-crm-v3`。
2. 执行 `sudo bash scripts/upgrade.sh /opt/lianruan-crm-v3`。
3. 执行 `sudo bash scripts/verify.sh /opt/lianruan-crm-v3`。

## 业务验证

1. 企业管理员登录 `/partner.html`，确认可看到所属渠道企业范围内的客户、商机、报价、订单。
2. 渠道员工登录 `/partner.html`，确认只能看到本人跟进的客户、商机、报价、订单。
3. 超管登录 `/admin.html`，创建账号时使用已有联系电话，确认保存被拒绝并显示中文提示。
4. 超管登录 `/admin.html`，修改账号联系电话为其他账号已使用号码，确认保存被拒绝。
5. 超管登录 `/admin.html`，创建企业管理员时可输入渠道商名称检索并选择。
6. 区域管理员登录 `/admin.html`，创建企业管理员时只能检索和提交本区域渠道商。

## 不影响范围

1. 统一入口仍从 `/` 或 `/login` 进入登录页。
2. 超管和管理员仍可查看全量业务列表。
3. 既往客户检索和导入回填保持原行为。
4. 渠道商员工禁用和删除后刷新行为保持原行为。
