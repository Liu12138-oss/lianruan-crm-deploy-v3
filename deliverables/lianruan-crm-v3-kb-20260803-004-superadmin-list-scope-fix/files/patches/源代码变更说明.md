# 源代码变更说明

## 变更文件

1. `apps/api/src/business-store.ts`
2. `apps/api/tests/business.test.ts`
3. `docs/V3缺陷修复与功能开发前置阅读指南.md`

## 变更要点

1. `查询列表` 不再把旧页面传入的 `operatorId` 直接作为超管、管理员、企业管理员的数据范围条件。
2. 新增渠道商和账号列表的服务端范围计算，保证渠道账号仍只能看到授权范围内数据。
3. 补充回归用例，覆盖超管携带 `operatorId` 时仍可看到报备、渠道商、账号、报价、订单。
4. 文档补充缺陷修复规则：渠道范围问题必须检查报备、商机、渠道商、账号、报价、订单，且不能信任前端参数替代服务端会话。
