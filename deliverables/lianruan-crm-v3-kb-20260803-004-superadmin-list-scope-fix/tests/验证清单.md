# 验证清单

## 自动验证

1. 执行 `sudo bash scripts/precheck.sh /opt/lianruan-crm-v3`。
2. 执行 `sudo bash scripts/upgrade.sh /opt/lianruan-crm-v3`。
3. 执行 `sudo bash scripts/verify.sh /opt/lianruan-crm-v3`。

## 业务验证

1. 超管登录 `/admin.html`，确认区域管理员、超管、企业管理员列表不为空。
2. 超管登录 `/admin.html`，确认渠道商列表不为空。
3. 超管登录 `/admin.html`，确认报价和订单列表不为空。
4. 渠道企业管理员登录 `/partner.html`，确认只能看到本渠道企业范围内数据。
5. 渠道员工登录 `/partner.html`，确认只能看到本人范围内数据。

## 不影响范围

1. 登录入口仍从 `/` 或 `/login` 进入统一登录页。
2. 退出登录仍回到 `/login`。
3. 既往客户检索和回填保持 KB003 行为。
