# KB-20260803-003 验证清单

## 自动验证

1. 执行 `sudo bash scripts/precheck.sh /opt/lianruan-crm-v3`。
2. 执行 `sudo bash scripts/upgrade.sh /opt/lianruan-crm-v3`。
3. 执行 `sudo bash scripts/verify.sh /opt/lianruan-crm-v3`。

## 人工业务验证

1. 使用统一登录入口 `/login` 登录渠道员工账号，进入渠道电脑端，只能看到本人跟进的客户报备和商机。
2. 使用同企业渠道管理员账号登录，能看到本渠道企业下员工的客户报备和商机，看不到其他渠道企业数据。
3. 使用管理员或超管账号登录，在客户报备详情中可模糊搜索渠道商并选择跟进员工，保存后刷新仍保留。
4. 使用管理员或超管账号登录，在商机新建或编辑中可模糊搜索渠道商并选择跟进员工，保存后刷新仍保留。
5. 在新建客户报备中输入既往客户关键字，可搜索到历史客户；选择后客户名称、统一社会信用代码、法人、地址、行业等字段可回填。
6. 管理端、渠道端、手机端点击退出登录后，均回到 `/login`。
7. 使用原有报价、订单、产品、工作量配置页面做只读巡检，确认入口和列表仍正常。
