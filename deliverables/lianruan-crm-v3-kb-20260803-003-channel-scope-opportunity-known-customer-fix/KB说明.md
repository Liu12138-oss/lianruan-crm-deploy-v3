# KB-20260803-003 修复说明

## 问题范围

1. 渠道员工登录后可看到不属于自己的客户报备。
2. 商机管理缺少渠道商和跟进员工指派能力。
3. 既往客户未进入 V3 正式客户表，报备时无法按客户名称模糊检索并回填。
4. 退出登录会回到角色旧入口，而不是统一登录页。

## 修复内容

1. 服务端统一解析当前账号身份，客户报备、商机、报价、订单等列表和详情按账号角色限制数据范围。
2. 报备和商机共用渠道归属解析：渠道员工强制本人和绑定渠道；渠道企业管理员限制本企业；区域管理员限制本区域；管理员和超管可指派渠道商及跟进员工。
3. 管理端商机新增和编辑增加渠道商模糊搜索、渠道员工选择和保存字段。
4. V2 兼容接口和旧静态业务页面请求统一携带 Cookie 和页面令牌，避免正式页面绕过统一会话。
5. 导入既往客户 SQL 到 `crm.customers`，并让企业搜索从正式客户表读取可回填字段。
6. 管理端、渠道端、移动端退出登录统一调用 `/api/auth/logout` 后跳转 `/login`。
7. 修复问题文档已补充渠道数据范围专项检查和升级包制作检查规则。

## 数据库变更

新增迁移：

```text
database/migrations/20260803_S9_015_KB_003_导入既往客户.sql
```

迁移会把上传的既往客户数据导入 `crm.customers`，按客户名称归一值去重，并在 `extra_json` 中写入来源标记。
