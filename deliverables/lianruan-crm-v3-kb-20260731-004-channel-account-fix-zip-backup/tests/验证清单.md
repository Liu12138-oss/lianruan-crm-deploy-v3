# 验证清单

## 自动检查

- `scripts/precheck.sh` 通过。
- `scripts/upgrade.sh` 执行完成。
- `scripts/verify.sh` 通过。
- 升级日志中显示升级前备份目录，业务文件备份为 `uploads.zip`、`exports.zip`。
- `docker inspect` 显示 `api-1`、`api-2`、`nginx` 均已使用目标镜像标签。
- `/health/live` 返回版本 `3.0.0-stage9.22.20260731-kb002`。
- `/api/v2/partners?pageSize=1` 返回对象包含 `staff` 字段。
- `admin-app.js` 包含 `accountRole === 'partner_admin'`。

## 人工检查

- 渠道商详情添加员工后，员工卡片立即出现。
- 刷新页面后，刚创建的员工仍在销售团队中。
- 创建企业管理员后，右侧“现有企业管理员”立即出现对应账号。
- 企业管理员账号显示所属渠道企业名称。
- 原报备、商机、报价、订单页面可正常打开。
